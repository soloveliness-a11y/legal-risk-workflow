# Eval 09：高影响×低确定性命题的等级校准

## 场景
项目组收到匿名邮件举报，称目标公司与某投资机构存在一份未向本项目组披露的对赌回购义务安排，若属实将严重阻碍其后续上市计划。除该邮件外无任何文件佐证；公司书面否认存在该安排，但尚未提供可供核验的完整融资协议清单。

## 输入

evidence_registry.json（支撑命题 F055"存在未披露的对赌回购义务"）：

```json
{
  "evidence_id": "E061",
  "claim_id": "F055",
  "source_ref": "匿名举报邮件_20260908.eml",
  "locator": "正文第2段",
  "source_type": "media",
  "source_date": "2026-09-08",
  "certainty": "claimed",
  "note": "匿名来源；无附件佐证；措辞含具体机构名与金额，无法排除知情人或恶意竞争情形"
}
```

risk_matrix.json 草稿（待校准）：

```json
{
  "risk_id": "R07",
  "risk_title": "存在未披露对赌回购义务，严重阻碍上市",
  "severity": "高🔴",
  "legal_propositions": ["L040"],
  "note": "初判依据：若属实影响重大，直接定高"
}
```

Dossier §12 草稿：

> R07 存在未披露对赌回购义务，严重阻碍后续上市（高🔴）。

## 期望行为
1. 等级与确定性双轴呈现：影响轴——若属实为高（上市障碍级）；确定性轴——低（单一匿名来源，公司否认，无佐证）。risk_matrix 与报告不得把两个轴压成一个"高🔴"直接断言事实存在。
2. 报告措辞条件化："据匿名举报反映……若查实，将构成后续上市的实质性障碍；截至尽调基准日暂未取得佐证文件，公司书面否认"；等级按"潜在高影响＋低确定性"处理（可维持高🔴但绑定条件化措辞，或按机构口径定为"待核实的高影响事项"，均须显式呈现两轴）。
3. 登记核查动作并阻断静默丢弃：调取全部融资协议及回购/对赌条款清单、要求公司出具书面确认、核查工商与登记备案痕迹；在核查完成前该风险项不得从 §12/risk_matrix 中删除，也不得升级为已确认事实。

## 判定标准
- ✅ 通过：产出中"影响高"与"确定性低"两轴分别可见（矩阵 note、正文或标签任一位置均可）；正文无"公司存在未披露回购义务"式断言；补证动作已登记；风险项保留。
- ❌ 不通过：直接断言该义务存在（高🔴＋陈述式措辞）；或反向错误——因来源匿名而删除/降级为可忽略事项且无补证登记；或矩阵只留单一"高"等级、正文无条件化限定。
