# dd-prep — 尽调准备（4 步 DAG）

## 定位

- 遵循 [CONTRACT](../risk-workflow/CONTRACT.md)：工作区与数据衔接 §1、Dossier §2、output.json §3、检查点 §4、验收契约 §6、外部依赖适配器 §7、项目日志与启动自检 §9。本文件只写 dd-prep 特有逻辑。
- dd-prep 是全流程起点：初始化 Dossier、生成风险假设（全流程锚点）、产出尽调清单与访谈提纲。
- 核心原则：① 17 模块标准清单为基底，但**不发全量，做补充**——投资经理已有基础尽调、多数有前轮报告，清单基于"已知 + 待核实 + 行业特殊"增补；② 访谈提纲只列法律方向问题，与投资团队分工；③ 清单阶段不做风险分级，分级在 risk-report 撰写时进行。

## 输入与启动

前提：投资经理已通过小预审，风控资源已分配。**本节必填字段与"路径缺失则询问"的要求适用于尽调启动场景**；材料报告模式（risk-workflow 场景判断：基于现有材料出报告、未开展尽调）不执行本技能主流程，其材料归档与预处理仍遵循本文件「材料预处理规则」与 CONTRACT §7.2。输入字段——必填：project_name（被投企业工商全称）、investment_stage（天使/Pre-A/A/B/C/Pre-IPO/定增/基石/二轮）、industry（细分赛道）、project_type（直投/投顾/S基金/子基金）、im_report（投资经理小预审材料路径）；可选：prior_dd_report（前轮融资尽调报告）、company_docs（PPT/官网等）、qcc_screenshot（工商预查截图）。启动时向投资经理收集，路径缺失则询问，不绕过。**字段值未明示时的缺省规则**：按可获信息标签化预判（📌待核实），无法预判的按「成长期 + 直投」默认档执行，缺省选择连同依据列入 CP1 呈报项由审批人确认，确认后回填 Dossier §0；不得静默编造轮次或类型。

收集完毕后按 CONTRACT §9 执行一页启动自检；Dossier 不存在时按「Dossier 初始化」时点规则处理。流程：Step 1.1 知识积累 → 1.2 风险假设 → 1.3 尽调清单 → 1.4 访谈提纲 → CP1（§4.1，阻断性）→ Phase 2，信息不足时回 Step 1.1（标准见 1.4.2）。每个 Step 独立可调用；分支决策写 project_log 一行（日期/分支点/决策/理由），不设模板。

## Step 1.1 知识积累

### 1.1.1 项目特征解析

| 解析维度 | 关键指标 | 对清单的影响 |
|----------|----------|-------------|
| 轮次 | 天使/成长期/Pre-IPO | 决定范围和深度 |
| 成立时间 | <2年 vs >5年 | <2年简化沿革，>5年看历史瑕疵 |
| 行业赛道 | 芯片/AI/医疗/新能源等 | 触发专项模块 |
| 有无前轮报告 | 有/无 | 有：问题跟进；无：全量清单 |
| 特殊标签 | 高校/VIE/国资/境外架构 | 触发专项核查 |
| 核心产品 | 软/硬/服务 | 资质核查重点 |
| 上市计划 | 有/无/板块 | 审核红线 |
| 前轮投资人权利 | 回购/对赌/反稀释/一票否决/最惠国 | 标记已触发/即将到期权利 |

### 1.1.2 工商数据采集 → 调用 [qcc-scan](../qcc-scan/SKILL.md)

调用参数：company_name（**必须工商全称，简称返回空**）、scope="basic"、output_dir=`{workspace}/projects/{project_name}/01_dd_prep`。产出契约见 CONTRACT §7.1：`qcc_cache.json`（数据源无关原始缓存）+ `findings_summary.json`（每项 `{category, item, severity, fact, source_ref}`；severity 表示数据层面关注程度，**不是最终风险评级**——评级是 risk-report 职责）。缓存一次查询多次读取，Step 1.2/1.3 及下游 Skill 直接复用；超过 7 天需复查，可增量 diff，差异回填 Dossier（§7.1 新鲜度规则）。

**董监高画像扩展（scope=extended，满足任一即触发）：** 天使/Pre-A 轮创始人竞业核查是核心尽调项；findings 中核心人员有多家关联企业；投资建议书明确关注创始人背景/同业竞争；代持/复杂股权结构需穿透人员关系。从 qcc_cache.json 的 key_personnel 提取核心人员名单，对每位追加 executive 模式扫描，结果并入 qcc_cache.json（executives 字段）。

### 1.1.3 行业研究 → 调用 [industry-research](../industry-research/SKILL.md)

调用参数：industry、output_dir=01_dd_prep、risk_hypotheses 路径、investment_stage；crossborder_trigger 基于特殊标签判断，esg_trigger 基于轮次+行业判断。产出：`research_01_ipo_and_risks.md`、`research_02_regulation.md`、`research_03_*.md`（舆情/社区补强，检索渠道不限）及各自 `sources_*.json`；跨境触发时 `research_04_crossborder.md`。研究成果无 sources 落盘不通过（CONTRACT §7.4 + AC3）。

> **轻量模式**（industry-research 技能不可用或材料已足时）：dd-prep 内自行完成 2-4 次公开检索，按同一产出契约落盘 `research_01_*.md`/`research_02_*.md` + `sources_*.json`；研究 3（实操/舆情）路可豁免，AC5 登记即可。

### 1.1.4 已有资料轻扫描（dd-check T1 代理执行）

在 dd-prep 内部执行 dd-check 的 T1 轻扫描（不单独调用 dd-check Skill）：反向匹配已有材料覆盖的清单项，输出 `available_materials.json` 存放 `02_dd_check/`（该文件是 dd-check T1 触发点的标准产出，后续 T2/T3 基于它增量追加）。边界：T1 仅做材料清单登记 + 反向匹配，不做深度内容核查（留给 T2），不产生 pending_items.json。Step 1.3 必须读取此文件做去重。

**第三方尽调报告使用规则（存在外部律所/会所报告或领投方尽调报告时必过）：**
1. 机构资质：出报告机构须在机构认可清单内；被监管机构重大处罚或正被调查的机构（负面清单）所出报告不可单独依赖；报告由标的公司聘请时须独立评估中介独立性；
2. 时效：财务尽调报告距本复核开始 ≤6 个月（超期补最近年度/半年度数据）；法律尽调报告早期项目 ≤6 个月、成长/成熟期 ≤12 个月，超期须更新；
3. 覆盖面：应查未查或提示不足的事项补充核查；报告与本次尽调发现严重不符或分析明显不当的，可要求重新尽调。
> 高质量第三方报告（知名所无保留审计/并购 FDD）可与执行会计师交流其程序细度与覆盖面后酌减我方细节测试量（子基金 GP 报告仅早期/小额项目可依赖）。

### 1.1.5 风险初筛卡（risk_screener.py 确定性预筛）

```bash
python3 {workspace}/scripts/tools/risk_screener.py --qcc-cache {workspace}/projects/{project_name}/01_dd_prep/qcc_cache.json --output {workspace}/projects/{project_name}/01_dd_prep/risk_screening_card.json --format json --project-name "{公司全称}"
```

初筛卡只落盘这一个 JSON 文件（结构化、可 diff、供 Dossier §12 提取与 CP1 呈报复用）；需要阅读版时按 JSON 渲染摘要即可，不另存 md 副本。脚本按固定阈值检查 7 项指标：股权出质/冻结、诉讼风险、行政处罚、被执行人/失信、IPO 历史、实缴比例、股权集中度，自动打标 🔴/🟡/🟢，零 token 消耗、结果确定，替代 LLM 隐式判断。脚本输出后 LLM 在同一 JSON 内补充两项：**行业专项指标**（脚本仅覆盖通用指标，按行业追加 1-3 项，如 AI→算法备案、医疗→集采、半导体→出口管制）；**综合判断 overall_impression**（结合风险假设与行业研究做最终定性）。脚本失败时按异常表处理。

### 材料预处理规则

- 已知盖章扫描件（外部律所报告、工商档案等）直接判定为扫描版 PDF；遵循 CONTRACT §7.2 先试读，扫描件才 OCR——**外部律所/会所报告与投资建议书属 S1 敏感材料，只能本地 OCR 或人工转录，禁止上传外部服务**（工商公示档案可外传）；OCR 结果存 `01_dd_prep/` 复用，命名：投资建议书→`im_report_ocr.md`、前轮法律报告→`legal_dd_report_ocr.md`、前轮财务报告→`fin_dd_report_ocr.md`、其他→`{简称}_ocr.md`；
- 大文件（>30 页或 >5MB：前轮尽调报告、审计报告、招股书等）先经 doc_preprocessor.py 预处理（`--mode legal_risk` 法律聚焦 / `full_text` 全文）；复杂表格：xlsx/csv → xlsx Skill 读取，PDF 复杂表格禁止 OCR、截图标注「需人工确认」；财务报表/员工花名册/合同/资产/IP 清单一律禁止 OCR。

**Step 1.1 输出**：`01_dd_prep/` 下 qcc_cache.json、findings_summary.json、research_*.md + sources_*.json、risk_screening_card.json；`02_dd_check/available_materials.json`。确定性标签：工商数据 → ✅已确认；行业研究/公开检索 → [推断] 或 📌待核实（需后续验证）。

## Step 1.2 风险假设

基于项目特征 + 工商数据生成初步风险方向假设：为行业研究提供聚焦方向、为清单生成提供 CoT 映射输入，并作为 dd-check 核查优先级与 risk-report 假设验证的全流程锚点。输入 = 项目特征解析 + qcc_cache.json / findings_summary.json（含董监高画像，如有）。

**输出**：`{workspace}/projects/{project_name}/01_dd_prep/risk_hypotheses.md`

```markdown
# {项目名称} - 风险假设

## 生成依据
- 项目特征：{轮次}/{行业}/{特殊标签}；工商扫描发现：{findings_summary 关键项}

## 风险假设

### H1: {风险方向标题}
- **优先级：** 高/中/低 ｜ **假设依据：** {基于工商数据/行业特征/项目标签的判断}
- **建议核查深度：** {专项调研/清单重点项/常规核查} ｜ **关联清单模块：** {模块编号} ｜ **建议行业研究方向：** {应重点检索的领域}

### H2: ...（3-5 个）

## 假设间关联
> 多个假设指向同一风险源时，标注关联关系
```

**生成原则：** ① 以完整覆盖工商数据与项目特征指向的方向为准，避免发散，数量不设参考区间；② 来源透明：每个假设必须追溯到工商数据或项目特征；③ 优先级分级：按对交易与上市影响的判断区分高/中/低，聚焦核查资源到最关键方向（分级不设数量配额，依据不足时宁可不设"高"）；④ 建议具体：不是「关注税务」，而是「外资转内资过程中的税务合规风险」；⑤ **不做结论**：假设是方向性预判，不替代后续核查和报告结论。

天使项目简化：聚焦创始人 / IP / 前轮条款三类方向，数量按实际信号决定。同时更新 `project_dossier.md` §12（预填风险信号——来自假设而非确认风险）。

假设充分性不单独停顿确认（CONTRACT §4.2）：假设摘要（数量 / 优先级分布 / 已覆盖与未覆盖方向）随 CP1 呈报一并审批。机械性的信息回补由 Step 1.4.2 最低信息集判断把关——三文件不齐或高优先级假设无任何来源支撑时回 Step 1.1 补充，不依赖人工确认。

## Step 1.3 尽调清单

### 1.3.1 CoT 映射（清单生成前置）

> 目的：防止多步推理遗漏和幻觉关联——每条来源发现都有清单去处，每个清单项都有来源支撑。输出 `{workspace}/projects/{project_name}/01_dd_prep/analysis_log.md`。

| 1 | 前轮报告 | 关联交易定价偏高 | 关联交易定价公允性专项核查 | 模块11 | 高 | ⭐⭐⭐⭐⭐ | 有前轮报告 |

| 排除 | {明确不核查的清单项} | — | 排除 | {法规/行业依据} |

## 四、整体置信度评估
- **清单整体置信度**：{高/中/低}（基于映射数量和置信度分布）
- **最大不确定项**：{来源最弱、需重点核实的清单项}

自洽检查全部通过后进入 1.3.2；未通过则补充映射或修正逻辑后重新校验。

### 1.3.2 标准清单模板（17 模块，基底参考）

| 3 | 公司治理情况 | 三会决议、组织架构图、核心团队简历及兼职（executive 数据辅助）、高管变动、股权激励 |
| 4 | 主要资产 | 自有/租赁物业、知识产权（附表）、在建工程、设备、资产受限 |

| 8 | 环保/质量/安全生产 | 排污/环保设施、三同时、环保检测、**安全生产及整改**、**危废**、**碳排放/ESG** |
| 9 | 劳动和社会保障 | 劳动合同及保密竞业、社保公积金、**劳务派遣/外包合规**（≤10%）、**竞业有效性** |

| 15 | 国资/外资/VIE专项 | **国资：32号令/评估备案**；**外资：安全审查/负面清单**；**VIE：37号文** |

### 1.3.3 补充清单生成（含去重）
