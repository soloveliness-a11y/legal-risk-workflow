**V4.0（2026-04-14）— 条款分类体系重构**
- 新增3.0节"条款分类决策树"：每项风控发现必须先经决策树归位（陈述保证/先决条件/交割后承诺/特殊权利/治理条款），再写入对应文件
- 新增分类边界说明：9个常见混淆场景对照表，明确哪些放增资协议、哪些放股东协议
- 重写3.1映射规则：按文件类型拆分为3.1.1增资协议映射规则和3.1.2股东协议映射规则
- 重写3.2风控发现类型→条款类型速查表：增加归属文件列，标注每类风险的默认映射
- 重写4.2风控条款落实表：从单一JSON结构改为两份落实表（增资协议+股东协议），增加条款类型/分类依据/具体条款数组结构
- 核心原则强化：先决条件通常不超过10项，绝大多数整改事项放交割后承诺；一项风控发现可映射到多个条款类型
- 根因：实战中暴露陈述保证/先决条件/交割后承诺概念混淆，清单未按文件类型拆分
