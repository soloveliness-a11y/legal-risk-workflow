# 条款分类决策树与映射规则

> 本文件包含条款分类决策树、分类边界说明、增资协议/股东协议映射规则、风控发现→条款类型速查表、轮次差异化重点。
> **读取时机**：执行风险→条款映射（核心功能）时，生成风控条款落实表时必须读取。

AI取得风控报告后，将所有风控发现在交易文件中映射，输出**风控条款落实表**供用户审阅确认。

> 分类流程：逐项读取 risk_matrix 的 `clause_mapping_hints`（risk-report 产出）作为初始建议 → 每项风控发现**必须经下方决策树复核归位** → 处理混合类型拆分与"无法映射"项 → 写入落实表。规则化配置见 `templates/clause_mapping_rules.json`。

### 条款分类决策树

> ⚠️ **每项风控发现必须先经此决策树归位，再写入对应文件。**

```
风控发现 → 性质判断
│
├─ 是"确认现状为真"的声明？ → 陈述与保证（Representation & Warranty）
│  例：已取得IDC牌照 / 股权权属清晰 / 无未披露诉讼
│  归属：增资协议（附件二/第六条）
│
├─ 是"交割前必须完成/满足"的硬性条件？ → 先决条件（Conditions Precedent）
│  例：可转债清理完毕 / 统一股东协议签署 / 前轮解除质押
│  归属：增资协议（附件一/第三条）
│  ⚠️ 先决条件通常不超过10项，绝大多数整改事项应放交割后承诺
│
├─ 是"交割后未来要做"的承诺？ → 交割后承诺（Post-closing Covenants）
│  例：IDC牌照续期（6个月内）/ 关联交易管理制度建立 / 核心人员协议签署
│  归属：增资协议（第五条投资后义务）
│
├─ 是投资人特殊权利？ → 特殊权利条款
│  归属：股东协议（第七条）
│
└─ 是公司治理安排？ → 治理条款
   归属：股东协议（第三/四/五条）
```

**分类边界（常见混淆）：**

| 易混淆情况 | 正确分类 | 错误分类 | 归属文件 |
|-----------|---------|---------|---------|
| "已取得IDC牌照" | 陈述保证（确认现状） | ❌交割后承诺 | 增资协议 |
| "正在申请IDC牌照，承诺6个月内取得" | 拆为：陈述保证"正在申请"+交割后承诺"6个月内取得" | ❌先决条件 | 增资协议 |
| "股权质押需交割前解除" | 先决条件（对交易非常重大） | 交割后承诺 | 增资协议 |
| "实控人承担兜底回购义务" | 交割后承诺（未来承诺） | ❌先决条件 | 增资协议 |
| "未分配利润/未实缴" | 陈述保证确认现状+交割后承诺"IPO前完成" | ❌全部放先决条件 | 增资协议 |
| "关联交易确认为关联方并充分披露" | 陈述保证（确认现状） | 交割后承诺 | 增资协议 |
| "建立关联交易管理制度、逐年降低" | 交割后承诺（未来行动） | ❌陈述保证 | 增资协议 |
| "投资人享有回购权" | 特殊权利条款 | ❌交割后承诺 | 股东协议 |
| "董事会中投资人有权任命1名董事" | 治理条款 | ❌特殊权利 | 股东协议 |

### 增资协议映射规则

```python
# 一、陈述与保证（确认现状为真）
if 性质 == "确认现状为真":
    add(陈述保证, 归属="增资协议-附件二")
    if 风险需要缓释: add(赔偿, 归属="增资协议-第十条")
    # 例："代持"→陈述保证"无代持"+赔偿"创始人兜底"
    # 例："税务瑕疵"→陈述保证"已依法纳税"+赔偿"税务损失补偿"

# 二、先决条件（交割前必须完成）——通常不超过10项
elif 性质 == "交割前必须完成":
    add(先决条件, 归属="增资协议-附件一")

# 三、交割后承诺（未来要做）——一项风控发现可能同时需陈述保证+交割后承诺
elif 性质 == "交割后未来要做":
    add(交割后义务, 归属="增资协议-第五条")
    # 例："IDC续期中"→陈述保证"正在申请"+交割后承诺"6个月内取得"

# 四、业绩承诺/对赌条款
elif 性质 == "业绩承诺或对赌":
    add(对赌条款, 归属="增资协议-补充条款/附件")
```

### 股东协议映射规则

```python
# 五、投资人特殊权利
if 性质 == "投资人特殊权利":
    add(特殊权利, 归属="股东协议-第七条")

# 六、公司治理条款
elif 性质 == "公司治理":
    add(治理条款, 归属="股东协议-第三/四/五条")
```

### 风控发现→条款类型速查表

> 以下为常见风控发现的默认映射，实际处理时仍需经决策树判断。

| 风控发现类型 | 默认映射 | 条款类型 | 归属文件 |
|-------------|---------|---------|---------|
| 股权代持 | 陈述保证"无代持"+先决条件"代持解除函"（如影响交割）+赔偿 | 陈述保证+先决条件+赔偿 | 增资协议 |
| 股权不清晰 | 陈述保证"股权权属清晰"+赔偿 | 陈述保证+赔偿 | 增资协议 |
| 税务瑕疵 | 陈述保证"已依法纳税"+交割后承诺"补缴时间表" | 陈述保证+交割后承诺 | 增资协议 |
| 社保不足 | 陈述保证"正在补缴"+交割后承诺"限期内完成" | 陈述保证+交割后承诺 | 增资协议 |
| IP权属争议 | 陈述保证"IP权属完整"+交割后承诺"IP归属协议"+赔偿 | 陈述保证+交割后承诺+赔偿 | 增资协议 |
| 诉讼未披露 | 陈述保证"无未披露重大诉讼"+赔偿 | 陈述保证+赔偿 | 增资协议 |
| 关联交易不规范 | 陈述保证"关联交易公允"+交割后承诺"建立制度"+保护性规定 | 陈述保证+交割后承诺+保护性规定 | 增资+股东协议 |
| 资质缺失 | 陈述保证"正在申请"+交割后承诺"限期内取得" | 陈述保证+交割后承诺 | 增资协议 |
| 可转债/关联借款 | 先决条件"清理完毕"（如影响交割）或交割后承诺"限期内清理" | 先决条件或交割后承诺 | 增资协议 |
| 回购到期/对赌触发 | 前轮权利处理：展期/清理/延期+回购顺位调整 | 特殊权利 | 股东协议 |
| 投资人权利保障 | 回购/反稀释/一票否决/优先清算等 | 特殊权利 | 股东协议 |
| 公司治理 | 董事会席位/股东会表决/监事安排 | 治理条款 | 股东协议 |

### 不同轮次的文件重点

| 轮次 | 交易文件重点 | 特殊关注 |
|------|------------|---------|
| **天使** | 基础增资协议+简单股东协议 | 创始人股权锁定、IP归属、竞业、回购权 |
| **A/B轮** | 完整增资/股东协议+股权转让协议（如有老股） | 回购、反稀释、优先购买/共售、保护性规定、前轮权利协调 |
| **C轮+（Pre-IPO）** | 组合式投资协议 | 回购顺位（本轮优先）、锁定期、对赌清理、上市配合 |
