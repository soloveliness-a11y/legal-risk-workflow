# 风险等级体系与评级原则

> 本文件包含风险评级核心规则，撰写 Ch.5 重点问题和 Ch.7 风险总结时必须读取。

## 二、风险等级体系（五级分类）

### 2.1 五个等级

| 等级 | 标识 | 判定标准 | 典型示例 |
|------|------|---------|---------|
| **高** | 🔴 | **潜在影响重大（直接作用于交易可行性、上市审核或退出），发生可能性已实质化或无法忽略，且现有缓释手段不足以覆盖**。须作为优先核查事项或交易前置条件处理。 | 股权代持未还原、实控人认定争议、核心IP权属不清、出资不实未补足、涉及核心技术的未决诉讼 |
| **中高** | 🟠 | **影响较大，交割前需解决或形成明确整改计划，非致命但不可忽略**。 | 历史税务瑕疵需补缴、ODI/外汇登记缺失、关联交易定价公允性存疑、对赌/回购已触发未处理 |
| **中** | 🟡 | **存在合规瑕疵，现阶段实际影响有限，监管问询风险存在但不致命**。需持续关注、可能升级。 | 部分员工未缴社保公积金、个别资质即将到期已有续期计划、董事会决议轻微瑕疵 |
| **中低** | 🔵 | **实务中常见的合规瑕疵，实际影响极低**。 | 物业租赁未办备案、少量社保基数不足、劳动合同版本未更新、轻微行政处罚（已整改） |
| **低** | 🟢 | **无实质障碍或影响极有限，属于常规管理范畴。** | 档案管理不规范但不影响实质权利、历史小瑕疵已彻底规范、行业惯例性事项 |

> **等级与事实状态分离**：风险是否已实质化、证据是否充分，由确定性标签（✅已确认 / 📌待核实 / [BP声称] / [推断]）表达，不由等级表达。"高影响×低确定性"的事项照影响评级、照证据标确定性，两轴并列呈现，不得混同为"已确认的高风险事实"，也不得因证据不足把等级压低。
> **暂缓定级**：证据不足以支撑任何定级时，暂缓定级并列出需要什么信息（衔接重大判断五问第 5 问）；暂缓不替代识别——事项照常进报告与待核实清单。
> **无分布配额**：不设各等级数量或占比约束。评级唯一依据是逐项证据与下述原则；禁止为了分布形态增删、合并或调整任何风险项的等级。历史分布仅用于事后诊断——某项目评级分布显著偏离历史区间时，应复核是否存在系统性高估/低估，复核结论只能落在证据层面，不得以"凑分布"方式回调等级。

### 2.2 风控提示语气规则（严格绑定风险等级）

| 等级 | 语气模板 |
|------|---------|
| 🔴高 | "风控提示：该事项可能直接导致{具体后果}，存在重大不确定性。建议作为交割前提条件或申报前解决。" |
| 🟠中高 | "风控提示：建议要求目标公司{具体整改要求}，作为交割前提条件或申报前完成整改/制定明确的整改计划。" |
| 🟡中 | "风控提示：建议持续关注该事项的后续发展，必要时要求公司采取{具体措施}。" |
| 🔵中低 | "风控提示：建议进一步完善{具体规范}，该事项在同类行业中属常见情况。" |
| 🟢低 | "风控提示：基于上述核查情况，理解{事项}对公司本次投资/未来上市没有实质障碍。" |

### 2.2.1 风险评级核心原则

**原则一：区分"现实风险"与"潜在风险"——它是可能性的输入，不是评级的封顶**

| 维度 | 现实风险 | 潜在风险 |
|------|---------|---------|
| 定义 | 已实际发生、正在造成实际影响 | 理论上可能存在、尚未实际发生 |
| 评级含义 | 发生可能性已确定，按影响评级 | 发生可能性需单独评估：可能性高且影响重大的可评高/中高；可能性或影响有限的按实际评估 |

**不设机械上限**：证据不足、事件尚未发生、影响不重大是三件不同的事。风险尚未实质化只降低"发生可能性"这一项输入，不单独封顶等级；评级必须写明所依据的事实状态（确定性标签）与影响判断，两轴分离呈现（见 2.1）。

**原则二：评估对上市审核（及交易、退出）的实际影响**

| 影响程度 | 典型评级区间 | 判断标准 |
|---------|---------|---------|
| 审核红线 | 高/中高 | 可能直接导致不予受理或否决 |
| 问询重点 | 中 | 大概率被问询，但解释空间较大 |
| 常规关注 | 中低/低 | 问询概率低 |

区间是影响评估的参考锚点，不是映射规则：非审核红线的事项若对交易可行性或退出构成重大影响（如回购可执行性、核心资产权属），仍按其自身影响评级；不属于任何审核维度的事项按交易/退出影响评级。

**原则三：未上市企业常见不合规事项的影响背景**

以下事项在未上市企业中普遍存在，通常意味着实际影响与问询概率较低——这是影响评估的背景输入，**不是降级规则**，评级仍逐项按证据判断：

- 物业租赁未办理备案登记（实务中大量存在，通常不构成实质经营障碍）
- 少量员工社保/公积金缴纳不足（非全员，非系统性，非恶意逃避）
- 劳动合同版本未及时更新至最新版（实质权利义务约定完备）
- 轻微行政处罚（已缴纳罚款、已整改完毕、非重大违法行为）
- 董事会/股东会决议存在轻微程序瑕疵（实质决策合法有效、股东无异议）
- 一般性工商变更未及时办理（不影响实际经营）

> 涉及核心资产或大面积欠缴等情形（主要经营场所租赁关系不稳定、社保大面积欠缴引发集体追缴风险），影响判断相应上升，评级随证据上调。
> **社保基数行业校准**：非劳动密集型科技企业影响通常有限；劳动密集型产业可能引发集体追缴，按实际影响评级。

**原则四：行业特异性事项不受"普遍存在"背景稀释**

行业高频风险事项（下表）即使在该行业普遍存在，其影响评估也不因"行业惯例"打折，按个案证据评级：

| 行业 | 高影响事项 | 原因 |
|------|-----------------|------|
| 医疗/医药 | 推广服务商合规、学术会议赞助、营销费用率 | 商业贿赂认定风险 |
| 新能源/储能 | 财政补贴合规、国补回款 | 补贴依赖度高 |
| AI/大模型 | 算法备案、数据出境、训练数据合规 | 监管快速升级 |
| 半导体/芯片 | 出口管制、EDA授权、关键设备依赖 | 供应链安全 |
| 商业航天 | 军工资质、出口管制 | 国家安全审查 |
| 教育/培训 | 办学资质、预收费监管 | 政策风险极高 |

**原则五：风险趋势校准——收窄中的风险不应机械上调**

| 趋势 | 判断条件 | 调整规则 |
|------|---------|---------|
| 收窄 | 缓释措施执行中 + 解除路径明确 + 指标改善 | **不应上调** |
| 稳定 | 无明显变化 | 维持 |
| 扩大 | 负面新信息 + 无缓释 + 趋势恶化 | 可上调 |

**典型场景：**
- 实控人资金占用已归还 + 质押比例低 + 解除路径明确 → 即使核查中发现"质押"新信息，不应上调
- 税务补缴已在进行中 + 补缴金额可控 + 无处罚迹象 → 不应上调
- 对赌已触发但回购协议已签署 + 资金到账中 → 可考虑下调
- 知识产权诉讼已和解 + 赔偿金额不大 → 可考虑下调

### 2.2.2 评级校准注记

> **以下为评级校准的倾向性注记，非绝对规律**——用途是校准评级假设与报告动作，不能替代个案证据。

**（一）按既有方法评级的类型**

- 政策/监管窗口类：收紧方向预判与路径切换建议按既有方法评级即可
- 上市时间表类：关注申报时点受业务结构变化的影响；"为上市而融资"项目的时间表审慎采信
- 业务成长性受限类：大客户依赖、市场规模、账期结构对退出的制约按证据评级

**（二）普遍低估的三类**（评级时应主动上调或补充维度）

1. **回购条款可执行性**：纸面化高发——回购触发或临近触发后难以顺利执行是常见情形，共同瓶颈是回购人支付能力而非条款文本。可顺利执行的情形，其要素=回购人有偿付安排与违约金约束+固定价格公式+可过户的证券通道。**条款"存在"与"可执行"必须分开评级。**
2. **管理层时间表系统性滑期**：上市/盈利时间表应按显著延后进入基准情形（考虑申报延期与盈利滑期）。
3. **实缴/回款类现金流风险**：典型校准失误模式=一轮定"低"（作为交割后义务）后未跟踪实质变化（实缴义务可恶化为协议违约与法定义务叠加）；追加轮应对前轮定级为低的事项重新验证；回款结构（ToG 占比、账期、验收款兑现率）是流动性压力的共同根因。

**（三）普遍容易高估的类型**（可维持较低评级，但注意各自边界）

1. **创始人竞业与 IP 历史瑕疵**：天使阶段的竞业/IP/代持清单事项在经上市或诉讼检验前多停留在潜在状态；职务发明权属属"上市前风险"；前雇主书面同意通常具有持续效力——**协议约定+确认函一般可形成充分缓释**。
2. **关联交易占比**：有硬约束时通常可按期下降。**边界**：前轮仅作软承诺（无对价机制）时不降反升——下降预判的前提是约束可执行。
3. **分拆语境下的实体法律瑕疵**：母子公司共同上市诉求驱动下几乎全部修复；同类瑕疵在无上市主体配合动机的项目中长期滞留——"高估"仅适用于有上市诉求配合的情形。

**（四）校准操作建议**（写入报告的动作）

1. **退出保障强度独立评级**：可执行性 = 回购人偿付能力 × 顺位位置 × 公司回购现金可行性 × 转让/减资通道；多轮持仓须防轮间顺位自我冲突。呼应**原则二**——退出维度与上市审核影响并列进入评级。
2. **盈利/上市预测强制附滑期敏感性**：显著延后情形（两年以上）下的回购触发时点与基金久期影响。呼应**原则一**——时间表落空后的回购执行已实质化，按现实风险的事实状态与影响评级。
3. **追加轮必须重验前轮"低风险"内控项**：二轮报告设"前次预测 vs 实际"对照章节并制度化。呼应**原则三**——常见不合规的影响背景不改变逐项验证要求，背景≠免检。
4. **创始人资金类承诺（实缴/跟投/补偿）优先转化为交割前置条件或附条件分期出资**，不依赖交割后义务。同时按"损失风险"与"回报不达预期风险"双轴定性（回购+过户通道兜底时，"高"资金往来风险的实际损失可能仅为机会成本）。呼应**原则五**——收窄趋势验证了"不应机械上调"，但其前提是缓释路径可执行。

**（五）情景校准注记**

1. **涉外 IP 风险的救济速度**：域外法院临时禁令可较快生效并波及多国市场——涉外 IP 风险定级应考虑域外禁令救济速度，"FTO 低风险"不能替代"再诉概率"的压力测试。
2. **"完成上市≠合格退出"**：上市市值低于协议约定的合格 IPO 门槛时赎回权未必消灭——退出条款评估须含市值门槛落差情形，估值门槛按保守情形校准。
3. **"无高风险项≠可投"**：中风险同向叠加（退出周期×收入持续性×条款劣势的乘积）可构成实质障碍——乘积效应应显性化评估，而非各自孤立评级。
4. **结构性风险识别正确与投资回报可以并存背离**——风险报告的职责边界是揭示风险而非预测商业成败，建议报告中明示这一边界。
5. **回购权集中到期**：多轮融资回购权存在集中到期风险（滞后于融资潮数年出现），公司偿付可能依赖新一轮融资"以新还旧"——在后投资人进入前先锁定"在先投资人延期同意"落纸。

### 2.3 风控结论与映射

| 风险分布 | 建议结论 | 说明 |
|---------|---------|------|
| 1个及以上高风险且无法缓释 | 不建议 | 存在无法通过整改/承诺/合同条款消除的重大风险 |
| 1个及以上高风险但可缓释 | 有条件通过 | 需要明确的缓释方案作为条件 |
| 2个及以上中高风险 | 有条件通过 | 多项中等风险叠加需关注 |
| 1个中高风险 | 有条件通过（轻度） | 单项风险需整改但整体可控 |
| 仅中及以下 | 通过 | 风险在可控范围内 |

> 此映射为参考规则，非硬性约束。偏离需在报告中说明理由。

**可缓释性判断：** 整改可消除（补缴社保等）→可缓释；承诺/赔偿可转移（创始股东兜底）→可缓释；无法补救（核心IP权属不清且无法解决）→不可缓释。

## 四、投资机构关注要点（五大核心关切）

| 关切 | 子问题 | 为何重要 |
|------|--------|---------|
| **① 能否上市？** | IPO路径、审核障碍、时间表、锁定期 | 退出渠道 |
| **② 股权是否干净？** | 代持、权属争议、历史瑕疵、国有程序 | IPO审核红线 |
| **③ 业务是否独立可持续？** | 关联交易、同业竞争、客户集中度、核心资产权属 | 持续经营能力 |
| **④ 技术/资产是否清晰？** | IP归属、职务发明、合作研发、核心技术来源 | 核心资产价值 |
| **⑤ 投资是否有保障？** | 回购/对赌、信息权、兜底责任 | 投资人保护底线 |

### 阶段差异

| 阶段 | 核心关切 | 示例 |
|------|---------|---------|
| **Pre-IPO** | 上市可行性、突击入股锁定期、审核红线 | 如：未盈利上市路径、突击入股36个月锁定 |
| **成长期** | 业务独立性、公司治理、可持续性、投资保障 | 如：关联交易、特别表决权、保障条款 |
| **天使/早期** | 团队背景、技术来源、IP、商业模式验证 | 如：IP权属、中美架构、竞业限制 |

## 六、深层逻辑：投资机构的决策框架

### 6.1 终极问题：钱怎么出去？怎么回来？

评估框架：上市可行性 → 股权干净度 → 业务独立性 → 投资保障

### 6.2 可缓释性思维

- 可通过整改消除 → "有条件通过" + 整改要求
- 可通过承诺/赔偿转移 → "有条件通过" + 创始股东兜底
- 无法补救 → "不建议" 或 "终止"

### 6.3 "解释空间"的利用

1. **承认风险存在**
2. **列举解释逻辑**（如军工vs民用业务的同业竞争论证）
3. **提示监管态度**（可能不认可解释）
4. **给出应对建议**

### 6.4 投资保障条款评价逻辑

- **完备性**：回购、对赌、信息权、知情权、清算优先权、反稀释…是否齐全？
- **触发条件**：回购触发条件是否合理？是否与上市冲突？
- **兜底责任**：创始股东对交割前事项的赔偿责任是否覆盖？
