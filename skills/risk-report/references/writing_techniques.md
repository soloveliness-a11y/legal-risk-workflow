## 五、写作技巧

### 5.2 措辞原则

| 原则 | ✅ 正确 | ❌ 错误 |
|------|--------|--------|
| 客观中立 | "存在...风险"、"建议..." | "这个风险太大了" |
| 有据可依 | "根据《广告法》第X条..." | "法律上可能有问题" |
| 留有余地 | "原则上...但存在不确定性" | "肯定..." |
| 明确建议 | "建议在交易文件中要求..." | "需要注意一下" |

### 5.3 引用规范

| 引用对象 | 格式 |
|---------|------|
| 法律法规 | 《名称》第X条 |
| 监管指引 | 《监管规则适用指引——发行类第X号》 |

### 5.4 clause_mapping_hints 规则

每项风险在输出 risk_matrix.json 时，必须增加 `clause_mapping_hints` 字段，经过"条款分类决策树"判断：

1. 确认现状为真 → type="陈述保证"，归属增资协议-附件二
2. 交割前必须完成 → type="先决条件"，归属增资协议-附件一/第三条
3. 交割后未来要做 → type="交割后承诺"，归属增资协议-第五条
4. 投资人权利保障 → type="特殊权利"，归属股东协议-第七条
5. 公司治理安排 → type="治理条款"，归属股东协议-第三/四/五条

**重要：** 一项风险可映射多个类型（如"IDC牌照续期中"同时需陈述保证+交割后承诺），primary_type 标注所有适用类型。

**映射执行要点（决策树直接执行，不走脚本）：**
1. 混合类型必须拆分（如"牌照正在续期"= 陈述保证【确认现状】+ 交割后承诺【限期完成续期】）
2. `suggested_clauses` 的具体条款措辞由撰写者基于项目情况拟定——决策树只给类型和方向
3. 无法映射的风险发现不得静默丢弃：在 `rationale` 中说明并交由 txn-docs 环节人工判断
4. 配套规则表（关键词→条款类型）保留于 `templates/clause_mapping_rules.json`，可作决策树结论的交叉校验参考

**字段结构：**
```json
{
  "risk_id": "R03",
  "risk_description": "IDC牌照续期中，存在业务合规风险",
  "risk_level": "中高🟠",
  "clause_mapping_hints": {
    "primary_type": "陈述保证+交割后承诺",
    "rationale": "现状（正在续期）+未来承诺（限期完成续期）",
    "suggested_clauses": [
      {
        "type": "陈述保证",
        "content": "公司陈述并保证，截至交割日，公司正在按照适用法律申请IDC牌照续期",
        "target_file": "增资协议-附件二"
      },
      {
        "type": "交割后承诺",
        "content": "公司承诺交割后6个月内完成IDC牌照续期，逾期未完成则创始人承担兜底责任",
        "target_file": "增资协议-第五条"
      }
    ]
  }
}
```
