# docx_engine 变更日志

## 2026-04-29 — 三个格式bug修复

### Bug 1：连字符被转为破折号
- **文件**：`constants.py`
- **现象**：`Pre-A` → `Pre—A`，ASCII连字符`-`(U+002D)被中英文标点转换无差别转为破折号`—`(U+2014)
- **根因**：`PUNCTUATION_MAP`中`'-': '—'`无差别转换；`PUNCTUATION_RESTORE_PATTERNS`仅恢复`—数字`（如`—500`→`-500`），未处理`—字母`
- **修复**：新增2条恢复规则
  - `[—]([A-Za-z])` → `-\1`
  - `([A-Za-z])[—]([A-Za-z])` → `\1-\2`
- **验证**：`Pre-A`/`A-B`/`2025-2026`全部正确保留连字符；`成本—收益`（中文间）保留破折号

### Bug 2：中文标点后多余空格
- **文件**：`text_utils.py`
- **现象**：`**风控提示：** 后文` → Word中显示`风控提示： 后文`（冒号后多1个空格）
- **根因**：`parse_inline_formats`将`**风控提示：** 后文`拆成2个segments（`('风控提示：', True)` + `(' 后文', False)`），空格在第2段开头。`convert_punctuation`只处理单段内部，跨段空格无法清理
- **修复**（两处）：
  1. `convert_punctuation`：增加后处理正则`([：；，。！？）】》])\s+` → `\1`
  2. `parse_inline_formats`：增加清理逻辑——加粗段末尾是中文标点时，去掉下一段开头的空格
- **验证**：16处冒号+空格全部消除

### Bug 3：落款区部分行左对齐
- **文件**：`converter.py`
- **现象**：落款区"复核人："和"日期"行显示为左对齐（JUSTIFY），而非右对齐（RIGHT）
- **根因**：落款检测逻辑在找到`风险控制部`后，跳空行取下一行当"日期"→`撰稿人`被当成日期（碰巧RIGHT），`复核人`和`日期`未被处理→走普通段落（JUSTIFY）
- **修复**：重写落款逻辑——从"风险控制部"开始，持续收集到日期行（匹配`\d{4}年\d{1,2}月\d{1,2}日`），所有行统一RIGHT对齐；遇到`---`分隔线或斜体免责声明时停止
- **验证**：4行落款全部RIGHT（风险控制部/撰稿人/复核人/日期），免责声明保持JUSTIFY
