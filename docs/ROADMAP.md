# 开源路线图（ROADMAP）

> 项目目标：将开发于 PE/基金风控一线任职期间的法律风控 Agent 技能系统重新审议、优化、整合、脱敏后，开源给法律工作者。
> 历史阶段记录（Phase 0-5 审议/整合/回归/发布/发布范围整改）与三轮发布安全整改的过程细节不在本文件展开；过程文档见 [docs/DESIGN_DECISIONS.md](./DESIGN_DECISIONS.md)、[docs/EXCLUSIONS.md](./EXCLUSIONS.md) 与维护者私有档案。

## 三条已定的基本原则

1. **方法优先**：开源的核心是方法论（尽调框架、核查维度、确定性标注、写作规范），不是数据。真实项目数据永不出库。
2. **平台无关**：技能以 SKILL.md 为核心载体（对齐 Agent Skills 规范），不绑定单一 Agent 宿主。仓库只维护一份核心逻辑 + 适配说明，不做宿主分支。
3. **回归测试收口**：技能实质变更后用「项目材料 + 现有模型」跑回归，以历史项目材料为基准比对质量。公开层聚合口径见 [EVALUATION.md](./EVALUATION.md)。

## 铁律

1. 敏感数据永不进入 git 历史（宁可晚入库，不可带名入库；提交前跑 `scripts/tools/release_scan.py`，发布前加 `--history` 扫历史）
2. 安全整改期间不产生公开历史：本地修改 → 终扫 → 干净树单 commit → 一次性重建推送
3. 回归测试不通过不得发布
