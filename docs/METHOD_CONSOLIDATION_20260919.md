# 报告写作与复核方法整理记录（2026-09-19）

> 背景：外部复核指出两类问题。其一，规则以"发现 A 有错即禁止 A"的禁令形式不断叠加——四段式、五问、负面清单、复核标准重复规定同一件事，且三条场景禁令把专业任务删成了措辞限制。其二，验收把"报告里复述了规则原句"当作行为通过的证据。本轮把规则改回正向方法，并用同一关键问题的三种证据状态实测判断行为。改动范围限定 risk-report、评级参考、report-review 三处（commit 47860a7 + edfd818，版本 risk-report 7.0 / report-review 6.0）。

## 一、技能差异

| 位置 | 改动 |
|------|------|
| risk-report SKILL | Ch.5 以五步分析主线（确定问题、整理事实与证据、形成分析、给出当前判断、提出行动）取代"四段式强制 + 五问表格 + 七条负面清单"的叠加；四段式降为组织参考（模板移入 writing_techniques §5.1）；五问移为复核视角（归 report-review 持有）；负面清单瘦身为五条写作底线；新增两条：正文不引用技能规则原文、判断变更标注须说明缺口留下哪项不确定性及为何影响交易判断 |
| writing_techniques §5.6（新增） | 四类常见事项的正向分析方法：实缴与承诺履行（分别整理公示记录、出资凭证、承诺内容与期限，比较证据支持的事实再判断履行状态）、投资条款缺失（列明已取得安排、识别待评估权利、提出文件及其作用，附表述示例）、风险尚未发生（事件与触发条件、可能性证据及缺口、影响、缓释，据此评级或暂缓）、期限相关判断（义务发生、履行、到期、争议处理时间线，分别分析当前义务与历史责任）；附判断质量写法对照 |
| 评级参考 | 原则一补"潜在风险评估路径"；暂缓定级口径补"须说明缺口留下哪项重大不确定性、为何影响交易判断，评级始终由分析得出" |
| report-review SKILL | 第一层第 5 项改为"重大判断质量（五问视角）"——五问的单一归属处；底线核对从六条场景禁令改为"分析未完成"诊断（把未知写成确定的问题，退回时指出应补的分析环节：事实整理、义务识别、履行比较、时间线）；新增规则复述检查（正文出现技能规则原句，须提供项目分析，仅复述不算通过）；处理流程第 3 步残留的旧评级口径（"潜在风险是否过高评级、常见瑕疵是否已降级"）同步修正 |

## 二、规则合并说明（保留了什么能力）

每组规则的"原目标、新方法如何实现、合并项、保留边界"详述于两技能 CHANGELOG（risk-report V7.0、report-review V6.0 条目）。要点：

- 修正"把未知写成确定"三类错误时，对应专业任务未被删除：违约认定仍需义务识别与履行比较（§5.6 实缴方法），条款评估仍需权利清单识别（§5.6 条款方法），竞业责任仍需时间线分析（§5.6 期限方法）——从禁令改为路径。
- 反向约束收缩到少数关键底线：来源可回溯、单方陈述不充作已确认事实、未决冲突如实呈现（含已裁决按裁决结果保留依据）、缺口不作不利推定、通用提示不填充。
- 五问不再在写作层与复核层重复定义；四段式只在 writing_techniques §5.1 定义一处。

## 三、三状态实测（同一关键问题：王某 10% 股权代持）

方法：全新执行代理、同一冻结基础材料、统一任务指令；状态 2、3 使用虚构《代持解除与还原套件》（文件头含虚构声明）。验收只看报告正文与矩阵，不看执行者自述。产出存于运行档案（仓库外）`../方法验证_v030/`。

| 状态 | 输入 | 报告对 R01 的判断 | 判据核对 |
|------|------|------------------|---------|
| 1 证据不足 | 基础材料（BP + 工商快照） | 高🔴。事实整理完成（代持仅 BP 单方陈述、无协议无还原、平台层面未披露）；影响具体（权属、控制权两口径、IPO 清理、举证不能后果）；补证具体（协议、出资凭证、还原变更、王某配合承诺，含时限与责任方）；明确"暂缓终局判断"并说明缺口留下的不确定性是什么、为何影响 | 通过：不是"建议关注"式空转，分析完整 |
| 2 证据充分 | 基础材料 + 解除套件（协议、登记回执、股东确认函、公司说明、税务说明） | 中高🟠。**作出明确正面判断**："解除协议＋全体股东确认＋公司专项说明＋变更登记，四要件齐备，方向上应予肯定"；剩余三点风险各带补足路径（原件核验、税务收尾、历史外部效力反向核验）；交割先决条件与陈保设计落到条款；判断变更条件具体到三项核验结果 | 通过：证据齐时敢下结论，残余风险不回避 |
| 3 新证据改变判断 | 状态 1 项目 + 解除套件（增量） | R01 由高🔴降为中低🔵，**三项原定级依据逐一说明消除**；实控人口径更新为张某 65%+平台 15%；条款映射由"先决条件"改为"陈保+交割后承诺"；总体结论维持、收敛条件 2 项减 1 项；变更说明列明受影响章节，其余章节未动 | 通过：更新有解释、范围有边界 |

一票否决判据：三种状态下若都只输出"待核实、建议关注"则本轮失败——未出现该情形，三种状态各有明确判断。规则复述全扫：四份报告正文对"只能表述为/不得只算期限/写作底线/分析主线"等技能规则原句零命中。

复核层表现：状态 1 的 report-review 抓掉初稿一处内部方法论引用（修改意见 M1：删除）——规则复述检查在复核层生效，写作层偶发复述由复核拦截，分工符合设计。

## 四、计划外观察

1. 解除套件第一版含一处真实算术矛盾（协议写 10% 对应认缴 20 万元，与增资后注册资本 1,000 万元下 10% 应为 100 万元不符），两个执行代理独立抓出，均拒绝在矛盾文件上下结论：登记未裁决冲突组、双口径并列、指明裁决所需的增资决议与认缴明细。证据纪律有效；同时说明"证据充分"状态的测试材料必须先过自洽检查（套件已修正后重跑）。
2. 套件文件形成日期晚于基础快照采集日，三个执行代理分别以"真实性前提""原件核验事项""来源注记"处理，无一静默采信——时点处理一致偏审慎，未误当作登记滞后冲突静默选边。
3. 状态 2 报告对文件链条"真实性不作认定、按材料记载如实呈现"并以此作为判断前提——在有前提的明确判断与拒绝判断之间取得了合理位置。

## 结论

本轮整理达成三点：专业能力保留（三状态判断实测达标）、规则重复减少（负面清单 7 条并 5 条底线、五问单一归属、四段式单处定义）、报告判断有效（片段见第三节）。技能层本轮起不再随个案追加规则：个别措辞问题在报告层修改，跨场景复现的缺陷经确认后再进技能。
