# 设计决策摘要

> 本仓库从内部交付版精简为开源版的关键设计决策；过程性审议底稿不随仓库分发。

- **合并重复规范**：各技能中语义重复的约束统一收敛到 `skills/risk-workflow/CONTRACT.md` 单一契约，消费方按契约执行，避免多处口径并存。
- **将关键质量要求转为交付检查**：从事前流程管控（签名、检查点、后验约束）转向事后验收契约（AC1-AC5、实体比对、覆盖度、来源标注），由 `scripts/validate_delivery.py` 统一机械验收。
- **保留人工风险决策**：确定性标签、信息保真检查、稳定编号等保障语义的机制保留；风险定级与结论始终保留人工复核位。
