# 法律方向访谈提纲模板

> 供 dd-prep Skill 生成访谈提纲时参考。仅列法律方向问题，与投资团队分工。

## 天使项目提纲结构

1. 公司设立与股权结构 — 代持安排、ESOP、决策机制
2. 创始团队背景与劳动关系 — 前雇主竞业限制、职务发明、离职手续
3. 知识产权与核心技术 — 技术来源、前雇主关联性、开源、FTO
4. 商业模式与运营合规 — 资质许可、数据隐私、跨境合规
5. 财务与负债 — 个人负债、已产生债务、前轮特殊条款
6. 诉讼与仲裁 — 已决/未决/潜在纠纷

## 成长期/Pre-IPO 提纲结构

1. 股权与历史沿革（重点） — 历史沿革时间线追问、代持还原进展、前轮特殊条款
2. 业务合规与资质 — 行业资质/许可证、关联交易定价公允性、商业贿赂合规
3. 重大合同关键条款 — 排他性/独家/竞业禁止、CoC、终止和违约金
4. 知识产权与研发 — IP权属、核心技术来源、FTO/开源、职务发明风险
5. 公司治理与内控 — 董监高变动、三会规范性、内控体系
6. 诉讼/仲裁/行政处罚 — 未决案件、潜在纠纷
7. 上市相关（仅Pre-IPO） — 上市计划/板块、对赌清理、审核红线
8. 行业特殊问题 — 根据行业定制

## 每题标注维度

| 字段 | 说明 |
|------|------|
| question | 具体问题 |
| rationale | 提问意图/风险来源 |
| source | 企查查发现 / 前轮报告 / 行业研究 / 公开信息疑点 |
| target_audience | 创始人 / 法务 / 财务 / 业务负责人 |
