# 风控报告结构模板

> 供 risk-report Skill 撰写风控报告时使用。
> 结构与方法论来自法律风控报告实务的提炼；文中示例为通用化示意结构，主体与数字均为占位字段。

## 报告结构（标准 8 章）

> 与 risk-report SKILL.md §7 的标准 8 章定义一致：封面→开场白→前提→基本情况→重点问题→投资方案→风险总结→落款。篇幅配比见 SKILL.md §7。

### 1. 封面/标题
```
{公司全称}
重大事项及核心法律问题风控报告
```
> 注：标准标题格式为"重大事项及核心法律问题风控报告"，非"法律风控报告"

### 2. 致投委会开场白
```
各位投委会委员：

根据公司安排，风险控制部就{公司全称}（以下简称"{简称}"、"公司"或"目标公司"）投资项目所涉及的重大事项及核心法律问题，出具本报告如下，供各位委员投资决策时参考。
```

### 3. 报告出具的前提说明
- 投资建议书（投资经理提供）
- 法律尽调报告（律所名称 + 出具时间）
- 财务尽调报告（会所名称 + 出具时间，如有）
- 目标公司提供的基础材料和相关说明
- 对目标公司管理层的访谈纪要
- 行业/IPO研究报告
- 保荐人代表的访谈（如适用，Pre-IPO项目需特别注明）

> **写作要点：** 简明说明本次尽调依赖的材料来源，不做展开分析。Pre-IPO项目应特别注明是否访谈了保荐人代表。

### 4. 目标公司的基本情况及投资方案

#### 4.1 股权架构
- 公司简介（主营业务、成立时间、注册地、股改情况、子公司/分公司）
- 股权架构图（文字描述，含控股股东、实际控制人、员工持股平台）
- 控股关系说明（直接/间接控股路径、持股比例）

#### 4.2 实际控制人认定
- 控股股东的股权结构（如涉及多层架构）
- 实控人认定的监管口径（引用同系企业在监管问询中的认定）
- 无实控人的特殊说明（如适用）

#### 4.3 历史沿革
- 按时间线梳理重大历史事件
- **重点关注事项：**
  - 集团重整/重组对目标公司的影响
  - 原管理层个人事件的影响
  - "资产来自上市公司"vs"分拆上市"的认定
  - 国有股权程序的合规性（评估、备案、审批）

#### 4.4 投资方案（可在此处概述，详细评价在第6节）
- 投资方式、估值、融资额
- 本轮投资金额

### 5. 重点问题分析（核心章节）

> **这是报告的核心，按风险识别步骤确认的分析框架逐条分析。**
> 17大类风险分类体系是参考框架（详见 `knowledge-base/reference/risk_classification_framework.md`），具体报告根据项目实际情况选取。

**每个风险点的四段式IRAC论述结构：**

```
【{N}、关于{风险主题}】

1、背景/事实情况
   → 客观描述，引用尽调材料或访谈内容
   → 数据精确：金额、比例、时间、文件号
   → 使用表格展示财务数据对比

2、监管规则/法律依据
   → 引用具体法规条款（注明法规名称和条款号）
   → 引用监管指引（《监管规则适用指引——发行类第X号》）
   → 引用市场案例（可比公司、审核问询案例）
   → 引用行业数据（同业可比公司的情况对比）

3、风险分析/论证
   → 结合目标公司具体情况分析
   → 定量分析：占比、倍数、阈值对比
   → 同行业对比（说明在行业中的相对位置）
   → 说明解释空间（如有）

风控提示：{明确的风险判断 + 具体建议}
   → 语气根据风险等级严格匹配
```

**Pre-IPO项目的常见重点问题：**
- 未盈利企业上市可行性
- 突击入股锁定期
- 国资相关风险（股权权属、程序瑕疵）
- 同业竞争与关联交易
- 客户/供应商集中度
- 政府补助依赖
- 供应链风险（EDA断供、先进制程产能）
- 投资保障条款评价（回购/对赌/信息权）

**成长期项目的常见重点问题：**
- 从大企业分拆的独立性论证（技术、人员、业务、财务）
- 关联交易全面性核查（研发、采购、资金、人员）
- 特别表决权与投资人保护
- IP受让限制条款
- 核心人员全职情况
- 制裁/出口管制传导风险

**早期项目的常见重点问题：**
- 多轮融资回购集中触发
- 虚拟股/代持ESOP清理
- 股权收益权/收益权安排
- 关联借款/资金占用
- 历史股权转让税务合规
- 新业务合规性（如AI/数据出境）

### 5.5 其他关注事项（可选）

> **写作模式：** 对于风险等级为中低/低但不应遗漏的事项，可使用三列表格替代正文段落，保持报告紧凑。

| 其他事项 | 具体情况 | 风控建议 |
|---------|---------|---------|
| {事项1} | {具体情况} | {建议} |
| {事项2} | {具体情况} | {建议} |

### 6. 关于本次投资方案评价
- 投资方式、估值、融资额（详细）
- 回购/对赌安排（或无安排的风险分析）
- 股东权利条款（优先认缴权、优先收购权、信息权等）
- 目标公司对协议修改的态度（是否接受修改）
- 风控综合评价

> **写作要点：** 此节应结合前面重点问题的风险分析，综合评价投资方案的风险收益比。如无回购/对赌，需明确提示退出不确定性。

### 7. 项目投资法律风险总结
- 风险矩阵汇总表

| 风险事项 | 内容 | 风险级别 |
|---------|------|---------|
| {风险事项1} | {具体内容描述} | 高/中高/中/中低/低 |

> 完整版风险矩阵字段（大类/风险点/等级/缓释措施/报告位置/clause_mapping_hints）及 `risk_matrix.json` 规范见 risk-report SKILL.md §7、§9。

- 总体风控结论（通过/有条件通过/不建议）

### 8. 落款
```
风险控制部
撰稿人：{姓名}
复核人：{姓名}
{日期}
```

## 风险等级与语气对应

| 等级 | 标识 | 风控提示语气 |
|------|------|-------------|
| 高 | 🔴 | "该事项可能直接导致{具体后果}，存在重大不确定性。建议作为交割前提条件或申报前解决。" |
| 中高 | 🟠 | "建议要求目标公司{具体整改要求}，作为交割前提条件或申报前完成整改/制定明确的整改计划。" |
| 中 | 🟡 | "建议持续关注该事项的后续发展，必要时要求公司采取{具体措施}。" |
| 中低 | 🔵 | "建议进一步完善{具体规范}，该事项在同类行业中属常见情况。" |
| 低 | 🟢 | "基于上述核查情况，理解{事项}对公司本次投资/未来上市没有实质障碍。" |

## 投委会版结构变体

> 当用户触发"投委会版"/"投委版"转写时使用此结构变体。
> 详见 `writing_patterns.md §10.5` 逐章转写守则和 risk-report SKILL.md §10 / `references/iteration_and_handoff.md` 转写流程。

### 标准版 vs 投委会版结构对照

| 章节 | 标准版（底稿·四段式） | 投委会版（两段式） | 关键差异 |
|------|-------------------|------------------|---------|
| **一、报告前提** | 素材依据逐项列表（表格） | 素材依据合并为1-2段叙述 | **唯一可简化的章节**——合并同类项 |
| **二、基本情况** | 全部展开（含全部表格） | **保持与底稿一致** | 不删减、不压缩 |
| **三、重点问题** | 四段式：事实→法律→风险→建议 | **两段式**：综合分析与风险判断→风控提示 | 综合分析需**比底稿更丰满**（因不分四段重复） |
| **四、投资方案** | 投资概要+逐条保护条款列表 | 投资概要（待投资建议书）；保护条款按**4方向**概括 | 4方向（先决条件/交割后承诺/陈述保证/赔偿）**缺一不可** |
| **五、风险总结** | 矩阵+总结 | 矩阵（简化列）+总结含**正面因素** | 正面因素**不得删除** |
| **六、收尾** | 落款 | 落款+两版关系版本说明 | 新增版本说明 |

### 三、重点问题的两段式写法

**综合分析与风险判断**（替代原来的四个小节）：
- 选用叙事模式：递进式（因果链）/ 分层式（多维度）/ 论证式（可行性）
- 数据即分析：量化影响紧接数据后直接判断
- 表格后紧接判断：不让读者翻找
- 跨节引用必须内联结论（禁止无结论的"见上文不赘述"）
- 财务数据必须多年对比（≥2年）
- 辩证收束：既提示风险也承认缓释

**风控提示**（替代原来的风控建议）：
- 1-3条，聚焦核心动作
- 按风险等级选措辞力度
- 不逐条指定交易文件条款（映射留在底稿版）

### 四、投资人保护条款的4方向概括写法

```
### （一）交割先决条件
{概括列出3-5项核心交割前提，每项一句话+对应风险编号}

### （二）交割后承诺
{按时间表概括列出承诺事项，每项一句话+期限}

### （三）陈述与保证
{概括列出核心陈保方向，每方向一句话}

### （四）赔偿条款
{概括列出赔偿触发情形，每情形一句话}
```

> **注意**：4个方向必须全部出现。删除任何一个方向都会导致总结段自相矛盾。

## 写作风格参考（通用化示例）

> 以下示例为通用化示意：主体与数字均为占位字段或独立构造的示意值；写法结构、分析框架和措辞风格可直接套用。

### 引用法规的写法
```
根据《监管规则适用指引——发行类第 4 号》，发行人部分资产来自于上市公司，
保荐机构和发行人律师应当针对以下事项进行核查并发表意见：1.发行人取得上市
公司资产的背景、所履行的决策程序……
```

### 引用案例的写法
```
{可比公司}于{日期}向{交易所/板块}提交{申报文件}，监管问询关注{关注点}，
处理结果为{受理/问询/过会/注册/撤回等状态}（来源：{官方披露文件名称、
链接及定位}）。
```
> 引用公开申报案例时逐项标注可核验出处；案例用于说明监管关注点，不与目标公司情况混同表述。

### 引用访谈的写法
```
根据访谈了解，目标公司计划{年份/时点}申报{板块}。
根据访谈了解，该事项主要系当事人个人行为，不涉及到目标公司层面。
```

### 引用公开信息的写法
```
我们查阅了关于目标公司控股股东集团重整及原董事长相关事项的公开报道，
暂未发现提及到有关目标公司的负面报道。
截至{日期}媒体报道：（1）有报道称{公开事件概述}……
```

### 同行业对比的写法
```
某同行业已上市公司：{报告期}，其对前五大客户的销售收入合计约{金额}，
占年度销售总额约{比例}，公司对大客户存在一定的依赖；{报告期}第一大客户
占总营收的比例约{比例}，第二大客户占比约{比例}。
（来源：{公司年报/招股书及页码}）
```

### 风控提示的写法
```
风控提示：同行业可比上市公司同样存在客户集中度较高、大客户依赖的特征，
但目标公司在指标上更为突出。客户集中度高并不一定会构成企业上市的实质性障碍，
通常被否是因为更深层次的原因——公司盈利能力不足和抗风险能力不强。目前科创板
对客户集中度较高的企业审核趋严，需向监管充分证明业务独立性及抗风险能力，
论证该等情形对发行人的持续经营能力不构成重大不利影响。建议团队结合目标公司
前五大客户各自情况以及相关行业情况，综合判断目标公司盈利能力和抗风险能力。
```

### 客户-推广商对照表的写法
```
| 客户名称 | 销售合同编号 | 合同金额（万元） | 推广商名称 | 推广合同编号 | 合同金额（万元） |
|---------|------------|----------------|-----------|------------|----------------|
| {客户} | {合同编号} | {金额} | {推广商} | {合同编号} | {金额} |
| ... | ... | ... | ... | ... | ... |
| 小计 | / | {金额} | / | / | {金额} |
```
> 适用场景：销售费用合规性分析，一表展示客户销售与推广费用的对应关系

### IP许可合同分析表的写法
```
| 合同名称 | 许可方 | 被许可方 | 权利清单 | 许可性质 | 期限 | 费用及计价方式 |
|---------|-------|---------|---------|---------|------|-------------|
| {合同名称} | {许可方} | {被许可方} | {权利清单} | {许可性质} | {期限} | {费用及计价方式} |
```
> 适用场景：知识产权许可约束分析，逐条列示许可条件，评估"掏空"程度。许可期限异常长的（如数十年），须评估替代成本与解除安排

### 交割前提可实现性分析的写法
```
风控提示：当前时点距约定交割日已不足{期间}，能否实现{金额}量级的回款
存在不确定性。建议将上述股权转让的顺利完成，以及相应的工商变更登记手续的
及时办理，作为本次投资交割的先决条件。
```
> 适用场景：有明确时间节点的交割前提条件，需评估时间压力和实现概率

### 高新资质双重量化分析的写法
```
风控提示：公司此前税务核算不规范，截至{时点}需补缴税款及滞纳金约{金额}。
若研发费用占比不满足监管要求导致高新企业资格被撤销，则补缴税款时需
按照25%税率（而非15%优惠税率）。建议要求公司和创始股东尽快完成税务补缴，
并就交割前事项引发的税务责任对目标公司造成损失的，由创始股东承担兜底赔偿责任。
```
> 适用场景：涉及高新技术企业资质维持和税务补缴的双重风险

### 回购条款原文摘录+评价的写法
```
条款：回购义务方：{义务方} | 回购触发情形：（1）{时限}前未完成{合格上市/
估值/退出条件}...（共{N}种情形） | 回购价格：{投资价款+收益率-已分红等计算方式}
风控评价：{触发情形覆盖面、义务主体范围（是否含创始股东、是否以股权为限）、
保障力度评价}
```
> 适用场景：投资方案评价中的回购条款分析，原文摘录+保障力度评价

### ESOP行权条件达标分析的写法
```
约定的行权条件包括公司应在每次考核期完成业绩考核目标
（按约定节奏在连续三个年度分别完成第1/2/3轮融资，逐轮递进）。
截至最近一次考核期，公司仅完成第1轮融资，因此该等已授予的期权均处于未满足行权条件的状态。
```
> 适用场景：股权激励行权条件与实际进展的对比分析

### 客户-供应商重叠多维分析的写法
```
1、客户集中度过高：近两个报告期，第一大客户集团{名称}（含其关联主体）
合计对公司贡献的收入占比分别约{X}%和{Y}%（按项目数据计算），集中度处于高位。
同时，对{该客户}的应收账款余额占总应收账款比例与其收入占比是否基本相当，一并核查。

2、核心部件通过客户代采：公司终端产品所需的关键部件由{供应方}集中或独家供应，
且{其销售渠道限制}，公司选择通过大客户{名称}代采（由其提供关键部件及配套物料），
导致{该客户}既为公司的核心客户又为核心供应商（采购占比约{X}%/{Y}%，与收入端双向依赖）。

风控提示：通常要求企业说明对第一大客户/供应商是否构成重大依赖，
是否符合行业特征、该等交易安排的合理性及必要性、定价公允性。
若定价偏离市场公允水平，可能存在被认定为交易不公允、双方存在利益输送的嫌疑。
```
> 适用场景：关键部件单一来源依赖叠加客户代采的"双头依赖"场景，需从收入、采购、应收账款三个维度拆解（占比数字按项目实际填列）

### 招商引资协议条款对照表的写法
```
| 条款 | 主要内容 |
|------|---------|
| 项目投资 | 总投资约{金额}，其中固定资产投资不少于{金额} |
| 产业引导基金 | 甲方协调投资平台给予总额不少于{金额}的产业引导基金支持 |

风控提示：由于公司本次融资同时涉及{架构调整/重组未完成等事由}，建议考虑以可转债方式进行投资。
```
> 适用场景：公司存在重大重组未完成或风险尚待确认时，风控报告可主动建议以可转债替代直接增资。简短有力，一句话说清理由。

## 二轮/追加投资报告的特殊结构

> **适用场景：** 对已投项目追加投资（二轮、三轮等），报告侧重增量风险和前次风险追踪。

### 结构调整
1. **前提说明**：注明"本报告系对前次风控报告的更新和补充"
2. **基本情况**：简明更新股权架构变化、最新融资进展
3. **前次风险追踪更新表**（核心新增）：

| 序号 | 类别 | 风险事项 | 前次情况 | 当前情况 | 当前状态 |
|------|------|---------|---------|---------|---------|
| 1 | {类别} | {事项} | {前次描述} | {当前进展} | 已解决/风险较小/详见下文/持续关注 |

4. **新增重大问题分析**：仅对新增或未解决的风险展开详细分析
5. **投资方案评价**：可省略（条款沿用前轮），仅需说明TS变化
6. **风险总结**：仅列新增和未解决的风险项

### 写作要点
- 前次已解决事项简要确认即可，不重复分析
- 新增风险需与首轮报告的分析深度一致
- 风险矩阵仅包含当前仍存在的风险项
- 篇幅通常为首轮报告的1/2到2/3

## 境外架构/多司法管辖区运营报告的特殊结构

> **适用场景：** 目标公司注册在境外（开曼/BVI等），在多个司法管辖区持牌运营。

### 结构调整
1. **基本情况**：重点描述境外架构（开曼→BVI→香港→各地运营主体）、创始人持股路径
2. **监管风险独立成章**（核心新增）：
   - 各司法管辖区监管概况
   - 业务运营主体和持有牌照清单
   - 合规vs非合规竞争对手的成本差异分析
3. **重点问题分析**：按法律合规/运营风险/财务税务/投资人保障四大维度组织
4. **投资方案评价**：保护性条款分"有利/不利"两栏分析

### 写作要点
- 境外架构需说明资金和利润流转路径的核查受限性
- 多司法管辖区需逐一分析各地监管要求和持牌状态
- 代币/虚拟资产业务需评估证券属性认定风险
- 中国大陆关联业务需分析"穿透审查"风险
- 投资人保护条款需区分主要投资人和非主要投资人的权利差异
- 回购条款需评估实际可执行性（现金流+监管约束）

## 从原任职企业分拆设立公司报告的特殊结构

> **适用场景：** 目标公司由实控人自原任职企业分拆设立，核心IP自原企业受让，业务上存在对原企业的关联依赖。

### 结构调整
1. **基本情况**：重点描述分拆设立过程（原企业业务调整→资产/IP转让→新公司设立）、核心IP受让背景
2. **关联交易与独立性**：
   - 关联采购对比表（项目/合同金额/占比/总投资），展示占比变化趋势
   - 独立性四维度分析（场地/技术/人员/业务）
   - IP转让背景与定价公允性
3. **高管任职一致性**：工商登记/花名册/股东协议三方对比

### 写作要点
- 分拆设立需审查原企业决策程序合规性（股东大会决议、评估报告）
- 对原企业的采购依赖需设定自建能力或替代供应时间表，作为交割后承诺
- 高管任职不一致反映治理瑕疵，建议作为交割后承诺
- 风险总结可采用"项目定性+三要点"格式（如"高技术壁垒、强资源依赖、伴随阶段性治理瑕疵"）

## 涉外知识产权诉讼报告的特殊要点

> **适用场景：** 目标公司（或创始团队）涉及跨法域知识产权诉讼。

### 核查维度
1. **纠纷背景**：争议主张概述（按专利侵权/权属争议等主张类型归纳，不展开具体指控情节）
2. **多法域平行诉讼进展**：按国别分别列示立案与审理状态
3. **第三方专业意见汇编**：多份境外法律意见书逐一摘录主要结论
4. **诉讼成本与时间表评估**

### 写作要点
- 跨国IP诉讼需汇编多份专业意见，综合评估但注明不确定性
- 采用谨慎定调："受限于专业知识和尽调手段，无法完全排除"
- 建议上市前完成FTO分析，并沿用历史融资文件的知识产权陈述保证
- 外部顾问持股公允性可引用证监会境外上市备案反馈标准

## 保密协议纠纷核查要点

> **适用场景：** 创始团队与前雇主之间存在保密义务争议，或已发生保密协议（NDA）相关纠纷。

### 核查维度
1. 前雇主保密协议/NDA条款的覆盖范围与存续期
2. 涉诉或争议状态（如已立案，列示程序进展）
3. 与职务发明、知识产权归属风险的交叉分析
4. 公司侧抗辩与缓释措施（技术来源独立性论证、专业意见）

### 写作要点
- 保密纠纷与IP权属风险需分别定性，避免混同
- 无法完全排除时保留谨慎表述，并在交易文件中要求专项陈述与保证

## 未盈利硬科技企业Pre-IPO报告的特殊结构（以港股18C路径为例）

> **适用场景：** 某未盈利硬科技企业申请港股18C章上市，核心技术人员存在同行业前雇主背景与IP权属风险，供应链存在单一来源依赖，并可能伴有历史股东退出遗留问题。

### 结构调整
1. **港股18C章上市条件对照表**：9维度（行业/市值/收入/公司定位/未商业化市值/研发占比/领航投资者/营运资金/IP权属），逐项对标
2. **核心技术人员与前雇主关系**：
   - 前雇主背景与竞业限制/保密协议审查
   - 知识产权归属风险（离职后一年内职务发明条款）
   - 谨慎定调："受限于专业知识和尽调手段，无法完全排除"
   - 建议上市前FTO分析
3. **关键供应链依赖分析**：
   - 供应商集中度（单一来源vs多来源）
   - 产能/供货锁定协议条款（期限/数量/浮动机制/违约处罚刚性）
   - 全周期风险分析（上行周期供给受限风险+下行周期保障失效风险）
4. **历史股东退出遗留问题**（四要素）：
   - 支付进度（已付/未付/与上市挂钩）
   - 担保措施（个人保证/抵质押）
   - 惩罚性条款（违约金/不退还款项）
   - 历史纠纷（知情权/劳动争议/名誉权/决议效力诉讼）
5. **政府合作协议**：考核指标+补贴金额+返还风险+国家政策清理趋势+退回案例
6. **投资方案与保障条款**：估值+金额+保障条款（回购权/最惠待遇/特殊权利）表格

### 写作要点
- Pre-IPO项目风险定调以逐项证据与评级原则为准，不为"整体积极"的项目诉求调高或压低等级
- 港股18C需区分"已商业化"和"未商业化"公司，分别适用不同市值/收入门槛
- 前雇主IP风险不可完全排除，建议FTO+沿用历史融资文件陈述保证
- 供应链依赖分析需覆盖全周期场景（上行+下行）
- 历史股东退出遗留建议在IPO申报前提前解决，避免被视为实控人债务不清
- 政府补贴返还风险需引用同类公司退回案例增强说服力
- 每个风控提示后直接建议交易文件条款，增强实用性
- 行业周期与IPO排队时间错配是Pre-IPO项目特有风险维度

## 二轮投资报告（Pre-IPO）的特殊结构

> **适用场景：** 对已投资项目的追加投资/二轮投资，项目处于Pre-IPO阶段，存在前次投资对赌/回购条款，业务可能发生转型。

### 结构调整
1. **前次风险追踪表**（二轮报告标志性结构）：
   - 格式：序号/具体事项/前次报告情况/最新（进展）情况/是否解决
   - 逐项更新前次报告发现的风险，标注解决状态（是/否/部分解决/不涉及）
   - 前次风险已解决的简要说明解决方式，未解决的关注进展和影响
2. **前次投资对赌及回购条款梳理**（二轮特有）：
   - 业绩对赌条款约定情况（承诺业绩/触发条件/补偿方式）
   - 业绩完成情况（实际数据vs承诺数据，量化偏差）
   - 踩线达标风险分析（冗余空间百分比+审计调整影响）
   - 收入确认合规性（年末集中度/验收单据完整性/第三方审计必要性）
   - 回购条款约定及触发条件
   - 当前上市计划及回购期限临近风险
3. **业务转型/新业务分析**（如适用）：
   - 新业务模式三层拆分（底层→中间层→上层）
   - 资质需求逐层分析（判断表+分类表）
   - 收入确认方式争议（年审vs IPO审计标准差异）
   - 税率适用风险（合同表述对税率的影响）
4. **产业基金"投资+业务合作"模式分析**（如适用）：
   - 折价优先认购权（如与业务贡献挂钩的估值折扣及其稀释影响）
   - 关联方认定双向论证（认定为关联方 vs 不认定，各列案例和理由）
   - 本公司差异点分析
   - 独立性论证（关联交易占比超30%需专项论证）
5. **可转债融资分析**（如适用）：
   - 分级转股估值条件（三时点三估值方式）
   - 现有投资人态度（反对票/弃权票）
   - 优先权利条款
6. **投资方案及保障条款评价**（大预审版特有）：
   - 投资方案（估值/金额/同轮投资人）
   - 保障条款对比表（回购权/其他特殊权利 vs 市场惯例）
   - 统一股东协议建议

### 写作要点
- 二轮报告的双层结构：前次风险追踪+新风险发现
- 业绩对赌踩线风险必须量化（冗余空间百分比+具体金额）
- 关联方认定采用双向论证比单方论证更有说服力
- 产业基金折价认购权需量化稀释影响
- 算力服务/新业务模式用表格替代长段论述
- 每个风控提示后直接建议交易文件条款
- 大预审版需为投委会答辩准备，投资方案和保障条款评价单列
- 二轮特有风险维度：对赌触发风险、回购期限临近、可转债融资影响、产业基金特殊权利

## 大型企业孵化公司报告的特殊结构

> **适用场景：** 由大型企业集团（汽车/互联网/制造等）孵化的创业公司投资项目，存在集团资源支持与独立性矛盾，可能计划由有实控人转为无实控人状态。

### 结构调整
1. **独立性四维度分析**（核心风险章节）：
   - 人员独立性：财务负责人/知识产权人员等劳动关系是否在公司
   - 资产独立性：专利是否与关联方共有、核心商标/域名是否在关联方名下
   - 业务独立性：关联收入占比、关联交易趋势、独立面向市场获取业务能力
   - 财务独立性：关联借款金额及清理计划、关联方免费提供资产
   - 每个维度先列问题，再给整改建议和期限
2. **无实控人方案可行性论证**（如适用）：
   - 公司计划（控股股东转让老股+外部股东下翻+引入新投资人增资）
   - 法律约束（《首发注册管理办法》两年稳定运行期+一致行动人锁定36个月）
   - 时间成本量化（最早两年后可申报IPO）
   - 建议（如接受一致行动人，约定IPO申报截止日自动解除机制）
3. **核心牌照/资质风险**（如适用）：
   - 牌照获批进度和不确定性
   - 获批前对公司商业化的制约
   - 建议：将获证作为交割前提条件
4. **前轮投资人特殊权利全景表**：
   - 优先清算权（顺位/金额计算方式）
   - 估值调整机制/对赌条款（触发条件/调整方式/补偿方式）
   - 优先退出权（触发条件/权利内容）
   - 公司治理权（董事提名/一票否决/沟通尊重意见）
   - 对后轮投资人的影响评估
5. **历史融资事项清理**（如适用）：
   - 上层投资人股权下翻进度和风险
   - 子公司层面财务投资人风险敞口
   - 关联借款一揽子清理方案
6. **股权激励代持与股份支付**（如适用）：
   - 代持方式法律风险
   - 未计提股份支付费用影响
   - 公司拒绝提供激励明细的风险提示
7. **资质申请合规性**（如适用）：
   - "人员挂靠"法律风险（引用具体法律条文+执法案例）
   - 社保公积金代缴合规风险

### 写作要点
- 独立性分析用四维度框架逐项呈现，避免遗漏
- 无实控人方案需完整论证：计划→法律约束→时间成本→建议
- 前轮特殊权利用全景表替代文字描述，一目了然
- 核心牌照建议作为交割前提条件，实操性强
- 关联交易占比做趋势预判（当前X%+业绩承诺→可能突破30%审核阈值）
- 资质申请合规风险引用具体法律条文和近期执法案例，增强说服力
- 投资方案保障条款评价用条款/内容/风控评价三列表格
- 核心建议每条都指向具体交易文件条款——风控报告直接服务于交易谈判
- 大企业孵化公司风险重心在独立性，独立创业公司风险重心在业务和财务真实性
