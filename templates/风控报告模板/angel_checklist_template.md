# 基金投资天使项目风控意见核查表（法律部分）模板

> **适用场景：** 天使期/早期项目，替代完整风控报告的快速核查清单。
> **格式说明：** 三列表格（序号/法律关注事项/本轮投资风控复核结果），每项含核查事实+风控提示。

## 二、各核查项详细核查要点

### 1. 商业模式的合法性

**核查方法：**
- 查阅投资建议书中的业务描述
- 访谈管理层确认主营业务和产品
- 对照同行业可比上市公司，核查是否需要特殊资质
- 关注当前经营阶段（如中试/量产）对应的合规要求

**常见核查结论写法：**
```
根据投资建议书，目标公司主要从事{业务描述}，主要产品为{产品列表}。
经访谈管理层及对照同行业可比上市公司，目标公司从事相关业务{无/有}
特殊资质要求。

目标公司当前为{经营阶段}阶段。随着{业务发展节点}，后续应{合规要求}。
```

**天使项目特别关注：**
- 公司是否处于中试/送样阶段，尚未规模化生产
- 规模化后需要的资质（环评、安评、消防等）
- 是否涉及特许经营或特殊行业准入

### 2-4. 创始团队与原单位关系（竞业+劳动争议+合同签署）

**核查方法：**
- 访谈创始团队确认竞业限制情况
- 确认核心成员与前雇主的关系状态
- 核查合同签署完备性

**高校教授创业特别关注：**
- 教授创业在天使/早期项目中非常常见
- 与高校之间通常不存在竞业限制
- 但需关注高校教授持股和兼职的合规性（见序号10）
- 已从高校离职的全职创始人需特别确认竞业和保密义务

**常见核查结论写法：**
```
创始团队为{背景描述}，与原单位之间{不存在/存在}竞业限制。
经访谈确认，创始团队及核心成员与原单位{不存在}未决劳动争议，
{不存在}侵害原单位知识产权或商业秘密的情形。
```

**风控提示写法：**
```
风控提示：作为交割前提条件，要求公司与创始团队就保密与竞业限制
签署单独的协议。
```

### 5. 创始团队个人财务状况

**核查方法：**
- 要求提供个人征信报告
- 访谈确认负债、对外担保情况
- 关注创始人在其他公司的担保/负债

**常见风险：**
- 创始人为其控制的其他公司提供担保（或有负债）
- 创始人对外大额负债可能影响对公司投入

### 6. 股权分布及股权激励

**核查方法：**
- 查阅工商登记股权结构
- 确认持股平台设置和GP/LP安排
- 确认实控人认定和控制比例
- 核查代持关系
- 确认ESOP安排

**天使项目特别关注：**
- 创始人持股平台表决权计算
- 是否签署一致行动协议
- 员工持股平台是否为预留池
- 是否有股权成熟（vesting）机制
- 非正式的股权激励承诺（如录用通知单中的期权约定）

**常见风控提示：**
```
风控提示：
1. 建议要求创始团队及员工持股平台之间签署一致行动协议，确保控制权的稳定性。
2. 建议设置创始团队的股权成熟机制，确保创始团队持有公司股权在公司早期发展阶段予以锁定。
3. 要求公司在达成一定里程碑后实施令投资人满意的员工激励计划。
```

### 7. 知识产权的合法性

**核查方法：**
- 核查IP来源（自研/高校受让/许可）
- 查阅转让合同和评估报告
- 核查转让程序合规性（高校审批、公示等）
- 评估转让定价公允性
- 确认侵权风险
- 核查专利申请状态

**高校技术转让特别关注（天使项目高频场景）：**
- 高校科技成果转化程序合规性（审批+公示+评估）
- 转让价格是否公允（评估值 vs 实际研发投入 vs 未来价值）
- 国家课题资助经费与转让价格的差异
- 转让合同是否覆盖公司所需的全部技术
- 公司成立后新申请的专利是否归公司所有

**风控提示写法：**
```
风控提示：前述转让在形式上是合规的，有审批和公示、也有评估支持。
但{转让定价的公允性风险}有待未来进一步论证，{具体风险情景}，
极端情况下不能排除目标公司需要采取一定补救措施。
```

### 8. 前轮投资协议特殊条款

**核查方法：**
- 核查种子轮/天使轮融资历史
- 确认前轮投资人是否享有特殊权利
- 确认前轮估值

**天使项目特别关注：**
- 种子轮投资人通常为自然人或小型机构
- 前轮可能未设定股东特殊权利（无回购、无优先清算等）
- 本轮投资通常是首次启用完备的股东协议

### 9. 涉诉情况

**核查方法：**
- 访谈确认
- 公开信息查询（企查查等）

### 10. 其他法律事项

**常见补充事项：**
- 高校教授持股和兼职的合规性
- 实缴出资情况
- 核心技术保密措施
- 其他行业特殊事项

**高校教授持股特别关注：**
```
风控提示：作为交割后义务，要求创始团队承诺适时取得高校关于持股
和兼职的备案或批准文件。
```

**实缴出资特别关注：**
```
风控提示：作为交割前提条件，要求创始团队完成实缴出资。
```

## 三、天使项目 vs 标准风控报告的差异

| 维度 | 天使项目核查清单 | 标准风控报告 |
|------|---------------|------------|
| 格式 | 三列表格（序号/事项/核查结果） | 完整章节正文 |
| 篇幅 | 通常2,000-5,000字 | 通常8,000-20,000字 |
| 核查深度 | 快速核查，关注核心风险 | 深度分析，含法律依据和案例引用 |
| 风险等级 | 通常不设五级分类 | 五级风险分类（高/中高/中/中低/低） |
| 风险矩阵 | 无独立风险矩阵表 | 有标准风险矩阵表 |
| 投资方案评价 | 简要提示（如"启用完备股东协议"） | 独立章节逐条分析 |
| 素材来源 | 投资建议书+访谈+有限尽调 | 外部律所LDD+投资建议书+访谈+补充尽调 |
| 适用阶段 | 天使/种子轮 | Pre-A轮及以后 |

## 四、跨境天使项目特别核查要点

> **适用场景：** 目标公司涉及跨境运营、创始人有海外高校/企业背景、需设计跨境架构的天使项目。
> 以下为可选核查项，按项目实际业务勾选适用，不预设某一项目全部命中。

### 跨境项目额外核查项（在标准10项基础上追加）

**1a. 跨境运营架构设计**
- 核查融资主体与运营主体的母子架构（融资与运营主体分设两地时，核查业务与资金路径安排）
- 业务和技术架构拆分方案是否合理
- 各运营主体注册地选择的合规考量（如美国不同州法律差异）

**1b. 目标市场经营资质映射**（涉食品/自动售货类业务适用）
- 按业务形态梳理取证链条与时间表（临时许可、正式认证、设备类许可等，按目标市场法规适用选取）
- 目标市场内部的地域法规差异（如联邦制国家的州级差异）
- 食品安全保障措施（食材采购合规、SOP、质量控制体系）

**1c. 数据跨境合规**
- 系统是否实现本地化部署和本地存储
- 是否存在个人数据跨境传输
- 是否符合中国《个人信息保护法》和美国各州隐私法

**1d. 出口管制评估**
- AI技术/设备跨境转移是否涉及EAR管制清单
- 跨境技术合作前的合规机构评估计划

**3a. 海外高校IP归属**（海外高校背景创始人适用）
- 创始人与海外高校的IP关系处理方式（付费协议/兼职协议等）
- 是否有高校不主张IP权利的书面确认函
- 创始人过往专利通过个人还是公司申请

**5a. 外籍创始人征信替代方案**
- 中国个人征信报告对外籍人士不适用
- 要求提供当地适用的个人信用报告
- 将不存在大额负债或对外担保作为投资协议的陈述与保证条款

**10a. 股权代持安排**（跨境项目高频）
- 代持背景与动因（按项目访谈了解，不作预设）
- 代持协议签署状态
- 代持解除条件和时间表
- 创始人对代持安排相关风险的陈述与保证

**10b. 开源模型/软件商业化合规**（AI项目高频）
- 核心产品使用的开源模型/软件及对应协议（MIT/Apache/GPL等）
- 商业化使用是否受限制
- 二次开发和分发的合规性

跨境项目整体上比境内天使项目增加跨境架构、多法域资质、跨境数据与出口管制、海外背景人员IP与征信替代、更复杂的代持与主体设立状态等核查维度，篇幅与证据要求相应上升。
