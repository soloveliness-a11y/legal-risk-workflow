# 交易文件模板（自备范本接入）

本仓库不附交易协议范本。请使用有权使用的机构范本，或具有明确许可的公开示范文本（如市场监管总局/行业协会示范文本）。

## 接入方式

- 常见条款结构与核查要点见 `knowledge-base/reference/transaction_clause_library.md`
- txn-docs 模式一「自备范本接入」：将你的机构范本放入本目录（不入库），按映射规则填充
- `templates/clause_mapping_rules.json`（风险→条款映射规则，方法论性质）已随仓库发布

详见 [docs/EXCLUSIONS.md](../../docs/EXCLUSIONS.md)。
