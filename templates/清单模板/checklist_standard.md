# 标准模式清单框架

> 供 dd-prep Skill 生成尽调清单时参考。已对齐 2025.12 修订版（对照 2022 基线逐项核验的新增项已并入；"海关监管货物""发明人任职"等字段系 2022 基线原有项保留）。

## 17模块清单（含5个条件触发专项）

| 序号 | 模块 | 核心要点 | 条件触发 |
|------|------|---------|---------|
| 1 | 基本资料及历史沿革 | 营业执照、工商档案、股权结构图（完整反映控制权及对外投资，列明各关联企业与公司/实控人的关联关系）、中国人民银行企业征信报告、出资凭证（非现金出资附评估报告及权属转移证明；历次股转附转让款支付凭证、溢价转让纳税凭证、资金来源说明）、历次融资文件（对赌/回购/反稀释等特殊条款已履行或待履行情况说明）、境外架构/ODI | - |
| 2 | 股东和实际控制人 | 5%+股东身份（含通过持股平台间接持股的自然人穿透）、一致行动、信托/代持/质押、创始人征信及负债、核心团队个人征信报告（核实回购义务人经济实力）、个人对外担保/关联负债、同业竞争 | - |
| 3 | 公司治理情况 | 三会决议、组织架构图、核心团队简历（含前雇主竞业限制/保密协议履行情况）及兼职、高管变动、股权激励 | - |
| 4 | 主要资产 | 自有/租赁物业、知识产权四件套（合作开发 IP 的合作协议、商业秘密保护措施书面说明、核心技术人员与前任职单位职务发明及竞业纠纷说明、IP 质押/许可/被许可/转让协议）、在建工程、设备、资产受限 | - |
| 5 | 主营业务及主要业务合同 | 主营业务、资质证照（含申请中资质进度、即将到期资质续期计划与进展）、行业政策、重大合同（前十大或占比较大、优先框架协议；说明潜在赔偿、质保义务、连带责任条款）、技术开发/委托研发/服务外包合同（与业务合同分列）、外协/代工模式与主要供应商的关联关系及定价公允性、反商业贿赂合规、营销费用真实性、第三方推广服务商合规性 | - |
| 6 | 主要债权债务 | 企业征信报告（债权债务部分再索取最新版）、类金融全口径债务（金融借贷/融资租赁/保理/供应链金融/民间借贷/股东借款/大额承兑票据）、民间借贷金额利息、股东对公司的借款和占款明细、往来款明细、贷款及担保明细、对外担保（附担保清单表）/资金占用 | - |
| 7 | 税务及财政补贴 | 税种税率、纳税申报（最近三年）、税收优惠及财政补贴占当年度利润总额比例+是否持续符合认定条件（如高新）、股转/股改纳税、欠税通知与补缴凭证 | - |
| 8 | 环保、产品质量与安全生产 | 环保：排污/环保设施、三同时、环保检测报告（近三年）、危废处理合同及资质、危废转移联单、危废处理发票、碳排放/ESG。**质量与安全生产（独立核查块）：** 质量体系认证、产品/技术标准处罚文书、重大质量/安全事故+处罚决定书+整改报告及验收文件、客户质量纠纷、安全生产资质与事故 | - |
| 9 | 劳动和社会保障 | 员工构成（含派遣/外包/实习生/退休返聘人数统计）、劳动合同签订率、保密和竞业协议签订率（是否覆盖创始人及核心团队和技术骨干）、社保公积金缴纳（附未足额缴纳原因）、劳务派遣/外包合规（≤10%）、竞业限制有效性、欠缴社保行政处罚文书 | - |
| 10 | 诉讼、仲裁、行政处罚和重大纠纷 | 近三年全部诉讼仲裁清单（含涉案金额）、实控人/董事长/总经理未决诉讼、近三年多部门行政处罚、知识产权维权函收发情况、客户投诉/劳动争议等其他重大争议 | - |
| 11 | 关联交易及同业竞争 | 关联方名单（操作性定义：控股股东、实控人、5%+股东、董监高、核心技术人员及其近亲属，及前述人员控制/施加重大影响/任董事高管的企业）、九类关联交易明细（采购、销售、委托研发、资金垫付、劳务、租赁、相互担保、关联收购、其他资金往来）及内部决策批准文件、上下游/竞争关系 | - |
| 12 | 行业专项合规 | 强监管行业触发提示（医疗、教育、游戏、直播、电商、增值电信、金融等）、数据安全与个人信息保护文件（隐私政策、数据跨境传输协议）、行业特许/许可证、境外业务合规（出口管制、海外子公司登记） | - |
| 13 | 知识产权深度（职务发明专项） | 高校背景创始人职务发明归属、大厂/科研院所背景创始人前雇主IP索赔风险、核心技术人员参与前雇主项目期间的发明归属 | 高校/大厂背景创始人 |
| 14 | 数据合规专项（SaaS/AI/电商触发） | 数据出境安全评估/标准合同备案、算法备案证明、重要数据识别清单、隐私政策、个人信息保护影响评估 | SaaS/AI/电商行业 |
| 15 | 国资/外资/VIE专项 | 国资：32号令/审批/评估备案；外资：安全审查/负面清单；VIE：合规性/37号文外汇登记 | 国资/外资/VIE标签 |
| 16 | 重大合同关键条款核查 | 排他性/独家/竞业禁止条款、控制权变更条款（CoC）、终止条款和违约金条款、合同转让同意条款 | 有重大合同 |
| 17 | 境外子公司合规 | 境外子公司经营合规、外汇/税收/数据出境合规、境外投资备案（ODI） | 境外架构 |

## 清单生成规则

```
if 无前轮报告:
    发完整清单模板（17模块，含条件触发专项）
else:
    发补充清单（基于前轮 + 已知信息 + 行业特性 + 轮次特性做增补）
```

## 标准回复口径（随清单发送的必备条款）

公司对每一清单项的答复仅允许五类：①提供资料；②不适用；③无——须注明"未取得"或"遗失"原因；④待查——须注明预计提供时间；⑤叙述性书面说明。空白答复、笼统"无异常"视为未答复，按未提供处理。

## 附表清单（随清单一并索取）

| 附表 | 关键字段 |
|------|---------|
| 担保清单表 | 被担保方 / 担保方式 / 担保金额 / 履行状态 |
| 主要经营设备清单 | 是否属于海关监管货物 |
| 专利清单 | 发明人及其目前任职情况（职务发明检测） |
| 社保缴纳表 | 未为全体员工缴纳、未足额缴纳原因 |

## 轮次差异化

| 轮次 | 清单范围 | 关注焦点 | 预期项数 |
|------|---------|---------|---------|
| 天使 | 精简版：人/IP/协议 | 创始人背景、技术来源、前轮条款 | 15-20项 |
| 成长期 | 标准17模块 + 行业专项 | 独立性、投资保障、治理 | 30-40项 |
| Pre-IPO | 全量 + 上市专项 | 上市可行性、对赌清理、审核红线 | 50+项 |
