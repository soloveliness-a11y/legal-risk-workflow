# 知识库版本记录

> 本文件记录知识库各模块的功能性变更，供 Skill 加载时确认知识库版本。

## 2026-09-18 法律数字治理（v0.2.0-hardening）

修正两用物项出口管制条例名称/令号/罚则口径（国务院令第792号；罚则为出口管制法第34条三情形分档）与港股18C市值门槛（现行40/80亿港元为短期修改值，适用至2027-08-31）；统一18C表述；经济性裁员触发条件改为法定口径；环评重大变动、央企基金比例、IPO分红触发器等不可核验数值软化为运行时核验提示；新增 `法律数字来源索引.md` 集中登记刚性数值来源（✅已核验/🔍待复核状态），行业库与沉淀 README 挂接索引指针。

## 2026-09-18 发布范围整改

按发布安全审计整改：行业专项检查库按资质、IP、治理和交易条款重组检查点；删除个案状态、成套内部参数、访谈原话与来源关联；报告模板示例改为占位字段；交易条款库重写为通用结构与检查点；公开声明与公开范围对齐（通用方法、空白模板、明确标注的示例）。

## 2026-09-17 法律索引重构 + 证据裁决框架

① 法律法规索引 3 文件重构为 Issue Map 格式（issue spotting + Authority 检索 + last_verified）：去除静态条号断言（条号由 legal-research 适配器运行时获取，见 CONTRACT §7.5），证券法文件逐项标注 knowledge_type（statute/exchange_rule/practice）。② 参考规范新增 evidence_resolution_framework.md（证据冲突六维度裁决 + 4 类裁决输出 + 6 场景速查，配套 CONTRACT §2.5 Evidence Registry）。

## 更新规范

- 每次知识库文件变更时更新本文件对应行，只记录功能性变化，不记录条目分发位置

- 新增公开条目须删除个案关系链与未公开状态，并做跨文件组合复核
