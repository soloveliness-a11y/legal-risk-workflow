# 案例学习笔记（不随本仓库分发）

> **设计决策**：从真实项目报告提炼的案例笔记信息密度高，匿名化后仍存在组合识别风险，**不随开源仓库分发**——本仓库只开源方法（行业检查库/写作范式/评级框架），不开源案例数据。
> 笔记保存于维护者**仓库之外的私有知识库**，与公共源码隔离；私有库内容只有经人工发布审核、去除个案信息的通用方法才可进入公共知识库。

## 本目录保留物

- `writing_patterns.md`：跨案例写作规律（已蒸馏、无可识别信息）——risk-report / report-review 技能加载

## 使用者自建指南

用你自己的历史报告搭建私有案例库（建议覆盖不同轮次与结局类型——含未投资与退出案例）：

1. 每个项目一份笔记：概况（匿名）/风险发现/写法要点/复盘教训；条件允许时补「风险兑现回看」（报告判断 vs 实际结局）
2. 编号稳定（每项目一个固定编号），供你自己的写作范式与检查库交叉引用
3. 纪律：金额量级、日期年份、人名角色化——即使私有库也建议维持匿名化习惯（防误传 + 练习脱敏）
4. 私有笔记的通用方法先沉淀到你的私有写作范式库；如需贡献到本公共仓库，须去除个案信息并经独立发布审核，不得由工具自动写入公开位置
