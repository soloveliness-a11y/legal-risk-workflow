# 子基金与FOF投资（交易类型模块·草稿）

> 特别说明：本模块是"交易类型"维度而非"行业"维度——适用于母基金/FOF 出资子基金、审核 GP 及其 LPA/Side Letter、投后 Call 款与清算退出等场景，与行业专项模块（01-15）正交互补。
> 本模块为通用核查框架：只提供"核查什么、如何判断"。费率、比例、期限等参数一律按使用者自身投资政策、基金合同及交易文件确定，本模块不内置任何数值标准。
> 定位：作为 dd-prep / txn-docs / post-invest-check 在 FOF 出资场景下的检查框架。

---

## 一、子基金尽调维度（GP 核查）

### 管理人（GP）法律尽调核心项
1. 拟注册地址：能否满足母基金自身及政府引导基金 LP 对注册地的要求（工商/税务/返投口径）
2. GP 股权结构：实际控制人、团队持股、是否存在金融机构/信托资金等特殊股东
3. 历史沿革与关联公司：股东背景、关联基金（在先基金/平行基金/联结基金）
4. 组织架构：前中后台人员配备，是否与关联方共用人员
5. 潜在风险：诉讼、重大债务、监管调查、行政处罚记录
6. GP 出资：在子基金中的出资比例是否按 {母基金投资政策} 设定，且与其资金实力匹配
7. 基金架构：特殊 LP、投资载体嵌套情况；关联交易与利益冲突规则
8. 其他 LP 构成：政府引导基金（政策性限制/返投）、国资（权益登记）、三类股东（契约型基金/信托计划/资管计划，影响被投项目上市）、外资成分
9. 薪酬体系与激励机制（carry 覆盖范围是否与前中后台职责匹配）
10. GP 及基金在中基协登记备案状态

### 历史业绩核查（财务维度）
- 复核 IRR/MOC/DPI 三指标；现金回流能力（DPI）与账面估值并重
- 估值方法合理性：审计报告与项目估值是否吻合；抽查现时估值依据（最近一轮融资文件/公开信息/专家访谈）
- 业绩波动性与项目失败率
- 抽取代表性成功与失败案例复盘投资逻辑；失败案例从法律风控角度找漏洞

### 负面清单核查
- 母基金是否按自身投资政策设定 GP 不投情形清单；如有，逐项对照目标 GP。清单应来自使用者自身政策，不照搬外部机构清单

### 决策流程核验
- 旁听子基金投委会或预审会：看参会人员层级、讨论充分度、正反方交锋、关键风险把握
- 可以先以项目跟投合作验证团队配合度/专业度/成熟度（是否采用按 {母基金投资政策} 决定）

## 二、LPA 关键条款审查要点

逐条核对条款是否存在、机制是否明确、与母基金投资政策是否一致。下表为核查维度，数值标准一律以 {母基金投资政策} 与 {LPA 文本} 为准：

| 条款 | 核查要点 |
|------|---------|
| 存续期 | 子基金存续期与母基金剩余存续期的匹配；延长的程序与母基金同意权；投资期/管理退出期划分 |
| 首交割与后续募集 | 后续募集期长度；延期补偿金的承担；其他 LP 补偿金豁免的同意权 |
| 合伙企业费用 | 基金承担的费用范围；筹建费与存续期合伙费用是否设上限；项目尽调费用的分担与返还安排 |
| 管理费 | 投资期/退出期的计费基数与费率；后续认缴追缴的起算日 |
| 出资进度 | 分期 Call 款的投放进度门槛；母基金认缴与每期实缴占比上限；超募/减募时的调整规则 |
| 关键人士 | 关键人士定义、触发情形（离职/失能等）与投资期中止机制；替代方案的审议程序与时限 |
| 利益冲突/关联交易 | 定义与处置机制；在先基金已投项目的受让/牵头/定价限制；同策略新基金设立限制；关联交易的审议程序 |
| 顾问委员会 | 母基金席位与职权（延期、利益冲突豁免、估值等）；有投票权成员的独立性 |
| 投资限制 | 单项目集中度、过桥余额上限、禁止投资类别、闲置资金运用范围 |
| 分配机制 | 返本→优先回报→GP 追补→分成的顺序与计算方式；分配时点；部分退出的单独结算 |
| 回钩/回拨 | LP 返还义务的上限；清算终止后追偿的时限及除外情形 |
| 报告与合伙人会议 | 定期报告的种类、时限及是否经审计；合伙人会议的职权边界 |
| 权益转让/退伙 | GP 权益转让限制；LP 违约认定与退伙程序（说明义务、第三方意见、期限）；母基金退伙的同意安排 |
| 特殊条款 | 简版工商协议与完整协议冲突的处理；LP 陈述保证的范围；上层权益变动承诺的边界 |

## 三、Side Letter 核心谈判点

- 募资返还/服务费：是否存在按母基金实缴额一定比例返还固定服务费的安排（比例按 {谈判} 确定）
- 收益分成让渡：GP 超额收益让渡的比例；LPA 未设门槛收益率时是否在 Side Letter 单独设定
- 认缴/实缴额度限制与调整机制；GP 对调整导致的违约责任是否兜底
- 项目跟投：跟投额度比例（按 {母基金投资政策}）、GP 储备项目披露频率、跟投不落实时的升级机制
- 参与决策：投委会观察员席位、会前项目决策资料提供
- 信息披露与投后配合：定期报告+托管报告+按约定口径出估值报告+投后系统填报+现场走访
- 退出保护：GP 严重违反义务（费用返还/跟投/披露/Call 款条件等）时母基金减认缴或退伙的权利、免责及损失承担
- 投资排除、延期补偿金豁免的否决权、管理层免责补偿限额

## 四、投后 Call 款与运营

### Call 款前置条件核查
首期付款前逐项确认：投委会决议→LPA/SL 签署→GP 完成管理人登记→收到缴款通知书→基金完成中基协备案→GP 及其他 LP 首期缴款凭证（豁免情形按约定）→分期募集按当期规模折算→其他约定付款条件。
后期 Call 款另核：前期出资到位情况、最新投资清单、募资费用返还到位、跟投落实、最终募集规模确定及认缴调整、信息披露义务履行、咨询委员会配合。

### 投后运营核查要点
- LPA 变更管理：地址/执行事务合伙人/关键人士变更须经基金变更决议与全体合伙人文件程序，并同步中基协备案；关键人士变更时跟踪替代人选资历
- 咨询委员会/合伙人会议议案：关联项目投资、延期、关键人士更换均以议案形式行使 LP 权利，表决前复核与 LPA/SL 程序一致性
- 管理费口径：GP 收费基数（认缴 vs 未退出成本）口径变化应以说明函书面澄清并对照 LPA 复核
- 返投核查：政府引导基金 LP 的遴选办法/管理办法对返投倍数、认定口径、注册地、国资出资比例的要求，投后按年度核验达成进度

## 五、退出与清算情形

- 存续期届满前要求 GP 提前提交全项目退出方案及 DPI 计划（分项目列明状态/成本/退出路径/时间表）
- 退出路径矩阵：IPO 减持（关注解禁日/减持新规对减持节奏的限制）、老股转让、回购（被投企业违约时可仲裁/诉讼主张本金+约定收益）、并购、新一轮融资中转让
- 延期决策：以 DPI 测算为依据（在投项目可分配额 vs 延期成本），经合伙人会议决议；延期次数与期限对照 LPA 及母基金自身存续期匹配
- 项目回购违约处置：未按约定触发回购的，及时启动争议解决程序并主张回购价款+资金占用利息；跟踪被执行人偿付能力
- 清算触发：存续期届满未延期、投资目标不能实现、GP 被吊销/注销；清算方案须覆盖未退出项目的处置与分配顺序；涉及国资 LP 的履行国资审批备案程序
- 母基金自身到期早于子基金：通过退伙/份额转让退出并约定 GP 兜底违约责任
