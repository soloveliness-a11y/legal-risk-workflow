# 风控专有术语表（精简版）

> 本表仅收录机构专有术语、工作流特有概念和案例提炼的非常规术语。

> 使用方式：按需查阅，不必全量加载。

## 一、股权与投资交易（机构专有）

| 术语 | 解释 |
|------|------|
| 回购义务承担顺序 | 公司先行承担→创始人兜底承担，创始人责任以已变现股权所得为限 |
| 回购集中触发 | 多轮融资的回购条款同时到期，公司面临集中偿付压力 |
| 二次交割 | 投资款分期支付，第二期需满足特定条件（如技术指标达成） |
| 低价优先退出权 | 其他投资人以低于本轮价格转让股权时，前轮投资人有权优先出售自身股权 |
| 可转债投资 | 以可转换债券方式替代直接增资，适用于公司重组未完成、风险尚待确认的情形 |
| 折价优先认购权 | 与业务贡献等挂钩的估值折扣认购权安排（参数按交易文件） |
| 统一股东协议 | 各轮投资人签署的同一份股东协议，约定权利顺位和行使方式 |
| 1元/注册资本转让 | 未实缴注册资本的股权转让常用对价，但可能被税务局认定为收入偏低 |

## 二、公司治理与控制权（案例提炼）

| 术语 | 解释 |
|------|------|
| 十倍表决权 | 大股东享有10倍于其他股东的表决权，可单方控制公司决策 |
| 一人一票制 | 有限合伙企业合伙协议约定的表决方式，GP无法独自决定表决结果 |
| 股权下翻 | 上层持股主体的投资人股权/投资款转移至运营主体层面的操作 |
| 关联主体重组 | 对公司众多关联主体逐一制定保留/注销/转股的处理方案 |
| 股权调整机制 | 创始人之间约定按贡献程度调整持股比例的安排，IPO申报期需解除 |
| 外部人员持股平台 | 区别于员工持股平台，为外部顾问设立的持股平台，需关注定价公允性 |
| 高管任职三重不一致 | 工商登记/内部花名册/股东协议三方记录关于高管职务的信息互相矛盾 |
| ESOP超授权 | 实际授予的激励股权数额超过股东会已审议通过的数量，需追认 |
| 股份支付 | 股权激励的会计处理，需按公允价值分摊确认费用，未计提将导致追溯调整增加亏损 |

## 三、股权归属与代持（案例特有模式）

| 术语 | 解释 |
|------|------|
| 代持设立 | 创始团队通过亲属等代持人名义设立公司，通常为规避竞业限制或法律风险 |
| 配偶代持 | 由创始人配偶代为持有公司股权，常见于规避政治风险或签证限制 |
| CEO代持 | CEO代替实际激励对象持有股权激励份额，需在IPO前完成工商变更 |
| 代持ESOP | 员工期权由创始人代为持有，非通过持股平台直接持有 |
| 穿透实缴 | 计算持股平台层面合伙人需实际出资的金额，需考虑平台对目标公司的认缴比例 |
| 虚拟股权 | 非工商登记的激励安排，通常仅享有分红权，无表决权和转让权 |
| 股权收益权 | 享有股权对应的分红和变现收益，但不包含投票权等管理权利 |
| 录用通知单约定期权 | 在招聘录用通知中承诺给予股权激励的非正式做法，缺乏法律约束力 |

## 四、知识产权与科技（案例特有）

| 术语 | 解释 |
|------|------|
| 职务发明（前雇主） | 离职后一年内完成的与原单位业务相关的智力成果，可能被认定为前雇主职务发明 |
| 掏空条款 | 合资/合作协议中赋予对方无偿或优先使用公司未来知识产权的权利 |
| 技术同源性 | 核心技术来源于同一母公司/前雇主，可能引发IP权属或制裁传导风险 |
| 收益法评估 | 基于资产未来预期收益折现确定评估价值的方法，常用于IP出资评估 |
| 追溯评估 | IPO前对历史非货币出资重新进行评估，验证出资充实性 |

## 五、法律合规与监管（非常规术语）

| 术语 | 解释 |
|------|------|
| 关联实体原则 | 美国制裁中，若母公司被制裁，存在技术/资金关联的子公司/兄弟公司可能被纳入 |
| 国有股权程序瑕疵 | 国有股权转让/增资未经法定评估、备案、审批程序 |
| 转贷 | 企业在无真实交易背景下，将银行贷款资金通过第三方账户走账回流至企业的违规行为 |
| 独立性四维度 | 场地/技术/人员/业务四方面的独立性审查 |
| 关联采购占比攀升 | 关联采购金额和占总投资比例快速攀升，反映业务独立性不足 |
| 同业竞争"除外但限制"条款 | 允许创始股东保留现有竞争业务但限制其扩大到与目标公司相同的技术路线 |

## 六、上市与IPO（案例特有）

| 术语 | 解释 |
|------|------|
| 私募基金架构拆除 | 将私募基金持有的股权还原为基金LP直接持有，以满足IPO实控人认定要求 |
| 折价增资权 | 控股股东按低于最近一轮估值的约定价格增资的权利（折扣按交易文件） |
| 两年运行周期 | 《首发注册管理办法》要求IPO最近两年控制权稳定 |
| 业绩对赌踩线 | 对赌期间实际业绩仅略高于触发线，存在审计调整导致触发的风险 |
| 政府补贴返还风险 | 政府合作协议约定考核指标，未达标或提前迁移可能触发补贴返还 |
| 收入确认方式争议 | 交付验收后一次性确收vs按服务期分摊，IPO审计可能比年审更严格 |
| 验收单据 | 客户确认交付的签字/盖章文件，IPO审计对验收单据完整性有严格要求 |

## 七、招商引资与地方合作

| 术语 | 解释 |
|------|------|
| 招引返投 | 地方政府引导基金要求被投企业在当地落地法人主体并实缴注册资本的投资条件 |
| 返投承诺 | 投资人要求被投企业在指定地区设立子公司、实缴注册资本、实体化运营的条件 |
| 返投驱动子公司 | 因各地政府招商引资返投要求而新设的全资子公司，可能导致注册资本实缴压力和架构复杂化 |

## 八、风控等级定义

| 标记 | 含义 |
|------|------|
| 🔴 高 | 现实存在的重大风险，直接影响上市审核或交易交割，必须解决 |
| 🟠 中高 | 现实存在的风险，交割前需解决或制定明确整改计划 |
| 🟡 中 | 存在一定合规瑕疵，目前实际影响有限，需持续关注 |
| 🔵 中低 | 实务中常见的合规瑕疵，未上市企业普遍存在，实际影响极低 |
| 🟢 低 | 无实质障碍或影响极有限，属于常规管理范畴 |

## 九、商业航天

| 术语 | 解释 |
|------|------|
| 地面站建设审批链条 | 土地取得→规划许可→施工许可→消防备案，商业航天项目常存在多项缺失 |
| 境外地面站合作模式 | 合资（共享收益共担风险）、自建托管（自负盈亏）、外协（按需租用），风险差异显著 |
| 军工/科研院所离职确认函 | 核心团队来自军工单位时，向原任职单位确认"离职创业不存在争议"的书面文件 |
| 一致行动"双轨制" | 部分一致行动人签署专门协议+设违约后果，部分仅在股东协议中约定无单独文件，后者稳固性较弱 |
| 子公司回购义务传导 | 子公司融资时母公司作为回购义务主体，将子公司的回购风险传导至母公司 |

## 十、智能驾驶与汽车电子

| 术语 | 解释 |
|------|------|
| 体外公司 | 因法规限制（如外资不能持有ICP牌照），由关联方代为持有的独立法人主体 |
| 城市合伙人 | 公司与地方合作伙伴合作投放运营设备的模式 |
| 车规认证 | 汽车行业质量管理体系认证（如IATF16949），供应商进入汽车供应链的必要资质 |
| 客户代采 | 核心零部件通过大客户而非直接向原厂采购的供应链模式 |

## 十一、AI/语音/多模态/算力

| 术语 | 解释 |
|------|------|
| 委外研发壳公司 | 参保人数0-2人、成立时间短、自然人股东的受托方，可能为开票主体或资金通道 |
| 关联方蛛网识别 | 通过工商留档电话/邮箱/地址/人员四维度交叉比对，识别隐性关联关系 |
| 双头交易 | 同一主体既为公司供应商又为公司客户，交易真实性存疑 |
| 首次市场化融资 | 公司历史上从未接受过市场化机构投资，无外部投资人约束 |
| 算力调度平台 | 对异构算力资源进行二次池化、虚拟化、任务调度和负载均衡的核心系统 |
| 税率适用争议 | 合同中"租赁"表述可能使增值税从6%（信息技术服务）变为13%（有形动产租赁）（税目依据财税〔2016〕36号，适用前按现行税目注释核验） |

## 十二、新能源/新材料

| 术语 | 解释 |
|------|------|
| 分拆设立 | 实控人在原公司内部预研技术后终止业务、转让资产、另行设立新公司的模式 |
| BT模式（建设-移交） | 先由公司负责项目全流程开发建设，建成后移交予业主的商业模式 |
| 无偿转让+自行拆除 | BT合作协议中的严苛终止条款 |

## 十六、港股18C上市

| 术语 | 解释 |
|------|------|
| 港股18C | 联交所《上市规则》第18C章，专为特专科技公司设立的上市通道 |
| 营业记录期 | 主板一般需3个完整财政年度营业记录；18C在特殊情况（如研发周期长的特专科技业务）下可接受较短期限，以联交所现行指引为准 |
| 联交所预沟通 | 递表前与联交所就特殊事项进行的预沟通 |
| 领航资深独立投资者 | 18C要求的资深独立投资者类型之一：管理资产≥150亿港元，或在特专领域投资≥50亿港元（上市前至少2名） |
| 未商业化公司 | 港股18C章定义，最近一个会计年度收入低于2.5亿港元的特专科技公司 |
| 已商业化公司 | 港股18C章定义，最近一个会计年度收入≥2.5亿港元的特专科技公司 |

> 现行市值门槛：已商业化公司上市时最低市值40亿港元（另有最近年度收益≥2.5亿港元要求）、未商业化公司80亿港元。40/80亿为香港证监会与联交所2024-08-23联合公告的短期修改值（原为60/100亿），适用期2024-09-01至2027-08-31，使用前须核验是否延续或再修订。来源：HKEX监管公告240823news；核验2026-09-18。

## 十七、出海/跨境

| 术语 | 解释 |
|------|------|
| 产地变更 | 为规避关税加征，将产品组装地转移至第三国，需符合原产地规则 |
| Section 301关税 | 美国《1974年贸易法》第301条授权的关税，针对中国商品的额外关税 |
| 中国行动计划 | China Initiative，美国司法部针对中国背景研究人员的审查计划（已 formally ended 但影响持续） |
| 融资赛→交付赛 | 具身智能行业从2025年开始竞争重心从融资规模转向实际交付能力 |
