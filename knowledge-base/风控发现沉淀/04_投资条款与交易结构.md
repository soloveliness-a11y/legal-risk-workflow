# 主题4：投资条款与交易结构

> 本主题用于通用问题识别：不得据本文件推断任何特定企业存在所列问题。
> 适用于交易文件审查阶段。
> 涵盖：回购权设计、对赌与业绩承诺、前轮特殊权利、可转债与投资结构、返投承诺。

---

### 4.1 回购权设计

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 多轮回购集中触发 | 多轮回购权均已到期 | 统一对齐各轮到期日，或作为交割先决条件 |
| 回购能力不足 | 公司承担回购义务，创始人仅以股权变卖对价为限 | 关注实际履行能力 |
| 回购触发事件过少 | 仅3种触发情形，缺少实控人变更、业绩大幅下滑等 | 谈判阶段合理增加回购触发情形 |
| 回购义务仅公司承担 | 回购义务人仅为公司，创始人无连带责任 | 争取创始人承担连带回购义务 |
| 回购可执行性受限 | 虽有回购条款，但公司现金流和监管要求可能限制回购执行 | 评估回购条款的实际可执行性 |
| 回购权仅为"尽力协助" | 表述为"尽最大努力协助出售或退出"，无强制执行效力 | 争取具有法律约束力的回购权条款 |
| 回购权未包含合格上市情形 | 触发情形仅包括创始人离职/重大违约/IP侵权，缺少合格上市时间 | 后续融资中补充 |
| 创始人回购义务有上限 | 以届时直间接持有的已变现股权变现所得为限 | 评估上限条款对回购保障力度的限制 |
| 在先投资人回购未决 | 在先轮回购已触发但部分投资人尚未签约解决 | 将在先投资人回购完成作为交割先决条件 |
| 回购仅挂钩上市申请/受理 | 触发事项目前仅与上市申请及受理挂钩，未与上市成功挂钩 | 争取将触发事项与上市成功相结合，进一步保障退出权利 |
| 新业务股权平移权 | 投资人以0对价取得新业务所在公司/组织的相应比例股权 | 评估对创始团队新业务激励的影响 |
| Warrant认股权证作为ODI过桥 | 境内人民币基金资金先入境内主体，出资至境外子公司需办理ODI，通过Warrant体现境外权益 | 确认为资金出境过桥机制，不产生额外稀释；纳入估值考量 |
| 前轮投资标的转换 | 种子轮/Pre-A投境外主体，本轮投境内主体；公司放弃境外架构 | 确保前轮投资人在原投资标的的权益（含Warrant项下）在境内主体层面得到妥善承接 |
| 纯固定期限回购条款 | 仅约定"某日期前有权回购"而不挂钩经营/上市事件 | 纯附期限回购易被认定为明股实债而无效；触发事件应与合格上市、业绩、重大诚信问题等挂钩 |
| 与公司对赌的可履行性 | 公司回购须先完成减资程序；金钱补偿以存在可分配利润为前提 | 回购主体至少含实控人/创始股东；公司不承担回购的应提供连带担保并经股东会决议（关联股东回避）；可要求提前取得附条件生效的减资配套决议 |
| 创始人责任上限条款 | "以持有股权为限"或"以股权价值为限" | 上限条款削弱保障，应审慎接受；必须接受时明确以本轮估值计算股权价值，并排除故意/重大过失/欺诈情形（列举账外收入、内控漏洞等） |
| 回购顺位劣后 | 各轮回购权存在优先劣后安排 | 劣后顺位应审慎接受；无顺位安排时明确按相对持股比例分配 |
| 回购权行使期限与诉讼时效 | 回购条件成就后怠于行权可能被认定丧失权利 | 条件成就后尽快书面主张并留痕（书面通知函/邮件，避免仅微信/短信）；2024.9 最高法答疑后口径收紧——未约定行权期限的回购权也应在"合理期间"内行使，已触发项目须逐一梳理发函情况、及时发函锁定权利，防止被认定超合理期间权利灭失；回购权变更/展期须在补充协议中明确"原协议行权期限限制对本安排不适用" |
| 回购价款参照价保护 | 按本金+固定收益计算可能远低于公司届时价值 | 约定回购价不低于届时净资产或市场价格；明确是否扣除已分红、已补偿款项 |
| 不可抗力条款过宽 | 融资方要求将疫情、行业政策变动纳入不可抗力 | 疫情/政策变动属商业风险，不接受写入不可抗力；对方抗辩时核查其通知证明义务及因果关系 |
| 老股转让回购权承继 | 回购权能否随股权转让转让存在争议 | 转让文件将回购义务人列为签约方或取得其单方承诺；明确受让股权对应的回购金额口径（是否含溢价） |
| 目标公司破产下的回购 | 公司破产将导致回购履行不能、担保责任难以支持 | 发现破产风险第一时间书面主张回购行权 |
| 违约金标准过高 | 日千分之一违约金获支持概率极低 | 标准应结合谈判地位、期限与可执行性确定（市场常见按日万分之五量级约定）；明确律师费/仲裁费/保全费由违约方承担 |
| 投资人过度参与经营影响行权 | 回购义务人可能抗辩投资人滥用一票否决权导致业绩不达标 | 交易文件明确投资人参与经营管理不影响回购权行使；谨慎行使否决权并留痕 |
| 公司回购减资程序时限链 | 公司回购条款无配套减资程序，触发后无法落地 | 内嵌完整链条：收到回购通知后 5 日内提交回购/减资方案并发出股东会通知 → 20 日内召开股东会 → 审议当天出具决议 → 会后 10 日内发债权人通知/公告 → 决议后 30 日内（法定公告期不计）完成程序并付款；配套：减资费用由公司承担、控股股东/创始团队及关联方承诺投赞成票、代权利人提案并召集股东会的义务、未表决/反对/不执行者以回购（减资）总额为基准承担全部赔偿责任；程序性安排须载入公司章程而非仅放股东协议 |

### 4.2 对赌与业绩承诺

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 业绩对赌踩线达标 | 收入仅小幅超出承诺线（达标冗余极小） | 评估审计调整导致对赌触发的概率 |
| 对赌+回购叠加触发 | 业绩不达标可能同时触发业绩对赌和回购 | 评估创始人实际偿付能力 |
| 估值调整机制（前轮投资人） | 约定期限内未完成既定规模融资→估值按约定幅度下调（期限与幅度按交易文件） | 评估触发概率及对新投资人的稀释影响 |
| 业绩承诺挂钩关联方销售 | 承诺期内向关联方销售设定大额下限（金额按项目数据） | 关注业绩承诺驱动关联交易增长的矛盾 |
| 业绩承诺可行性 | 承诺多年合计大额净利润，但交割前提要求短期内大额回款（金额按项目数据） | 审慎评估实现概率 |
| 创始人偿付能力不足 | 创始人尚欠缴注册资本，对赌/回购保障力度有限 | 条款层面可争取创始人连带+个人资产担保 |
| 审计口径冲突 | IPO申报审计数据与对赌审计报告不一致 | 约定投资人有权选择最有利的审计报告执行/补充执行业绩承诺 |
| 业绩补偿与回购并行主张 | 部分法院以逻辑矛盾/重复计算为由不支持同时主张 | 协议明确约定可同时主张、回购价款不扣减补偿款；补偿定性为估值调整而非违约金；金额设计避免被公平原则调减 |
| 现金/股权补偿公式 | 补偿计算方式约定不明 | 现金补偿=投资款×（1-实际业绩÷承诺业绩）；股权补偿比例=投资后股权比例×（承诺业绩÷实际业绩-1）；研发型企业可改用里程碑指标（流片/临床/许可） |

### 4.3 前轮特殊权利

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 第一顺位优先清算权 | 前轮投资人以第一顺位优先分配 | 评估对后轮投资人剩余资产的挤压效应 |
| 低价优先退出权 | 其他投资人以低于本轮价格转让→前轮有权优先退出 | 评估该权利对我方退出安排的限制 |
| 治理否决权 | 特定事项须与前轮投资人"充分沟通并尊重其意见" | 评估"尊重意见"条款的实际效力范围 |
| 后轮受让老股无回购权 | TS已明确投资人受让老股不设回购权保障 | 争取其他保障条款 |
| 控股股东折价增资权 | 控股股东有权按低于最近一轮估值的约定价格继续增资（折扣按交易文件） | 评估该权利对后续融资估值的影响 |
| 清算顺位持续劣后 | 控股股东清算顺位与每轮新投资人保持最优 | 争取本轮投资人清算顺位不劣于控股股东 |
| 控股股东转让不受限制 | 除控股股东外其他创始股东股权转让受限 | 约束控股股东股权转让行为 |
| 非主要投资人保护不足 | 无一票否决权、无反稀释保护、无董事席位 | 评估side letter的法律效力 |
| 创始人锁定期即将届满 | 创始人持股平台锁定期临近届满（时点按项目核查） | 关注锁定期届满后的减持计划 |
| 高倍表决权 | 大股东表决权倍数显著高于持股比例（倍数按交易文件） | 争取限制表决权事项范围 |

### 4.4 可转债与投资结构

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 分级转股估值折扣 | 不同时点转股对应不同估值 | 评估各时点转股估值对新投资人股权比例的影响 |
| 到期双选择权 | 到期后可要求偿还本息或按估值转股 | 评估到期对公司现金流或股权结构的影响 |
| 优先权利不劣后条款 | 未来转股后享有不劣后于其他低估值投资人的特殊权利 | 明确特殊权利的具体内容 |
| 现有投资人投反对票 | 前轮投资方（含其关联基金）对议案投反对票 | 关注反对票对可转债效力的法律影响 |
| 可转债投资建议 | 风控主动建议以可转债方式投资 | 评估公司重组进度，设定转股条件和时限 |
| 创始人安慰函无约束力 | "尽力配合投资人实现退出" | 争取具有法律约束力的表述 |
| 缺少分红权条款 | Pre-IPO公司现金流良好但未约定分红权 | 建议增加分红权条款 |
| 招引返投 | 要求在投资人行政区域内落地法人主体并实缴 | 地方政府招商引资要求 |

### 4.5 返投承诺

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 多地区返投要求冲突 | 多个投资方分别要求在不同地区落地返投或限制迁址（金额按项目数据） | 梳理各地返投要求的兼容性 |
| 注册地址限制 | 投资方C要求持有期间不得变更注册地址 | 评估地址限制对未来业务拓展的影响 |
| 投资方分期出资挂钩指标 | 分期出资（金额与期数按项目约定），后期出资挂钩指标要求 | 将该投资方第2期交割作为交割先决条件 |
| 返投安排 | 要求投资交割后半年内在指定区域设立子公司 | 关注返投安排的可行性和违约后果 |
| 返投倍数与认定口径 | 政府引导基金返投倍数多为1.5-2倍；认定口径除直投外可含被投企业迁入/当地设子公司/当地企业控股的外地子公司 | 谈判时争取宽口径认定（迁入/子公司/并购均计入），返投口径与倍数匹配 |
| 引导基金出资上限与让利 | 引导基金出资多不超过子基金认缴20%-30%；超60%引导基金在收益/返投达标后让利 | 让利前提（收益水平或返投达成）与计算基数应在协议中明确；争取让利挂钩返投完成度 |
| 国资出资比例限制 | 部分引导基金限制子基金国资合计出资不超50% | 募资结构设计时提前测算国资占比，避免触碰上限影响备案 |
| 引导基金出资顺序 | 通常要求政府出资不先于社会资本到位、增资平价进入 | 出资顺序条款与Call款计划匹配，避免违约 |

### 4.6 早期项目特殊条款（天使轮差异化设计）

> 新增日期：2026-09-16 | 来源：2023 年专项研究（早期项目特殊条款汇总）

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 天使投资人退出配合条款 | 天使基金受存续期限制需在IPO前择机退出，仅靠"择机"表述无强制力 | 要求创始人承诺配合老股转让（披露转让信息/告知融资动态/促成交易），可升级为股东会议案投票承诺 |
| 优先跟投权与投资平移权 | 创始人再创业设立新公司，原投资人无抓手 | 约定同等条件优先投资新公司或按比例股权置换；清算/回购未收回情形下五年内新项目优先投资——天使项目应必备 |
| 天使项目信息权加码 | 仅常规年度/季度报告难以掌握资金用途 | 争取季度预算及决算报告，了解所融资金用途 |
| 反稀释模式选择 | 完全棘轮对投资人最有利但谈判阻力大 | 优先完全棘轮；退让时用加权平均；配合Pay-to-play（后轮投资人未按比例跟进则反稀释降级/丧失权利）作为制衡 |
| 限制性股权兑现机制 | 创始人中途离职带走全部股权 | 4年分批兑现（每年25%）；离职时未兑现部分以最低价回购，已兑现部分按最近一轮融资价格折扣回购 |
| 视同清算事件定义过窄 | 仅覆盖法定清算，控制权变更/资产出售/核心IP转让未纳入 | 扩展视同清算：控制权变更、全部/实质全部资产或IP转让处置、创始人重大违约致经营恶化 |
| 最优惠待遇缺失 | 前轮或后轮投资人获得更优权利 | 约定自动跟随机制：在先股东更优权利自动适用，后续融资更优条件自动适用于本轮 |
| 合格上市定义粗放 | 未排除北交所/未设市值与融资额门槛 | 明确交易所范围（含北交所需特别说明）、最低市值、最低融资额（扣除承销费）及并购情形标准 |
| 业绩对赌指标单一 | 研发型早期公司无收入利润可对赌 | 改用里程碑：芯片流片、临床分期、药械许可、产线建设/量产阈值 |

### 4.7 回购触发后的处置模式

> 来源：处置实践复盘（模式表述）

| 模式 | 结构要点 | 适用/提示 |
|------|---------|----------|
| 延期+单利补偿 | 回购延期数年，按年化单利补偿部分本金 | 短期无支付能力但有恢复预期 |
| 分期回购+逐期选择权 | 分期回购且投资方各期享回购选择权（可进可退）；放弃部分股权回购的可将义务人变更为仅公司、实控人退出担保 | 满足创始人降责诉求同时保留灵活性 |
| 换股承接 | 持股转换至并购/重组后主体 | 重组交易中保住敞口 |
| 股权平移 | 以主张回购金额折算取得实控人新创业项目股权，同时保留回购权 | 实控人另起炉灶场景 |
| 仲裁+财产保全 | 提起仲裁并冻结创始人所持股权 | 有财产线索时的施压手段 |
| 限高后执行和解 | 胜诉+限高≠回款；执行和解往往需全体投资人配合解除限高 | 多投资人项目提前协调 |
| IPO 豁免/中止+重签 | 触发回购但企业申报 IPO 的豁免或中止特殊权利；IPO 路径明确而暂不行权的，按新一轮增资条款重签回购补充协议锁定权利 | 防行权时效经过 |

**估值调整的法律限制速查：** 公司分红补偿受制于未分配利润+股东会决议+现金；定向分红需有限公司全体股东约定；定向转增需资本公积充足+股东会决议（现金退出还需减资）；创始人股权补偿受制于可补偿数量+协议转让限制+其他投资人平权补偿压力。
