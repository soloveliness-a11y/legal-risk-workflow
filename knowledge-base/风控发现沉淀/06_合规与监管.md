# 主题6：合规与监管

> 本主题用于通用问题识别：不得据本文件推断任何特定企业存在所列问题。
> 按项目阶段筛选：早期重点关注税务/社保，Pre-IPO 重点关注资质/数据合规。
> 涵盖：税务合规、劳动与社保、商业贿赂、资质许可、数据合规、ODI/外汇、国资/高校合规、公司治理、IPO路径与审核、境外运营合规。

---

### 6.1 税务合规

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 税务核算不规范 | 历史税务核算存在瑕疵，需补缴大额税款+滞纳金 | 要求尽快完成税务补缴，创始股东对交割前税务责任兜底 |
| 高新企业资质维持 | 研发费用占比可能不满足监管要求 | 核查研发费用归集准确性，评估补税金额 |
| "转贷"行为 | 银行贷款通过员工和外部人员账户走账（金额按项目数据） | 要求公司和创始股东做陈述与保证 |
| 合同表述引发税率适用风险 | "租赁"→13% vs "服务"→6%（财税〔2016〕36号税目） | 评估两种税率适用的量化影响 |
| 财政返还型税筹可持续性 | 落户/迁址至财政奖励地区（个别园区按纳税额20%-36%阶梯返还） | 政策可能停止兑现甚至要求返还已发补贴；"实质性经营"要求趋严（人员/场所/社保）；测算时按保守口径并预留返还风险 |
| 合伙企业定向分配障碍 | 合伙协议约定不同利润来源按不同比例分配至低税负平台 | 财税[2008]159号禁止全部利润分配给部分合伙人；部分税务机关要求申报比例与工商份额一致或启动反避税调整；提前与主管税务机关书面确认 |
| 服务费/虚开发票型税筹 | 通过关联服务采购、虚构业务套取资金回流 | 三流不合一即构成偷税风险（补税+滞纳金+0.5-5倍罚款，《税收征收管理法》第63条）；杜绝无真实服务背景的费用安排，真实服务须业务流/发票流/资金流一致并留存成果交付证据 |
| 股权投资亏损抵扣方案 | 高额投资后低价转让制造亏损用于税前抵扣 | 无真实经营失败证据的低价转让面临纳税调整；虚构标的配合资金流转构成虚开发票 |
| 关联交易预提费用 | 年末预提关联方服务费推迟纳税 | 须有真实服务与协议支撑；被调整时按特别纳税调整补税加收利息（非滞纳金），仍应作为最后备用手段 |

### 6.2 劳动与社保

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 社保不足 | 按最低基数缴纳、试用期未缴纳 | 补缴计划+创始人兜底 |
| 竞业缺失 | 核心技术人员未签竞业协议 | 交割前签署 |
| 劳务派遣违规 | 比例超10%（用工总量，《劳务派遣暂行规定》第4条）、非"临时性/辅助性/替代性"岗位 | 转为直接雇佣或调整岗位 |
| 高管任职"三重不一致" | 工商/花名册/股东协议显示的职务不一致 | 梳理全部人事记录，确定真实管理架构 |
| 高管频繁变动且未及时变更 | 短期内多任总经理，每次变更均滞后 | 规范高管任免机制，设定变更时限 |
| 竞业限制多层缓释 | 核心团队整建制来自同行业的，按证据链评估竞业风险：前雇主补偿金支付情况、前雇主无争议确认文件、离职交接与协议解除安排、新签竞业/IP协议 | 多层独立证据叠加时方可下调风险等级（如天使项目自高降至低） |

### 6.3 商业贿赂

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| CSO推广费 | 向第三方推广服务商支付高额费用，服务商资质可疑 | CSO背景调查+费用合理性分析 |
| 宣传推广费合规性 | 应客户要求向指定第三方支付大额宣传推广费 | 逐笔核查推广费真实性和商业合理性 |

### 6.4 资质许可

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 外商创始人ICP牌照限制 | 创始人为外籍，公司无法直接申请ICP/EDI等增值电信业务牌照 | 通过体外公司持有牌照+独家业务合作协议 |
| 体外公司整合 | 因牌照限制设立体外公司，需纳入合并或清理 | 评估法规变化后直接持证的可行性 |
| 目标市场经营资质不全 | 仅取得部分/临时许可，规模化所需认证仍在申请 | 持续跟进资质获取进度 |
| 生产线环评缺失 | 唯一生产线应当办理环评及验收、排污许可但未办理 | 交割后限期补办 |
| 项目公司未持运营资质 | 项目公司未持有《电力业务许可证》 | 确认运营资质安排可行性 |
| 资质申请"人员挂靠" | 为申请乙级测绘资质，临时协调测绘行业人员缴纳社保 | 评估资质被撤销及行政处罚风险 |
| 《测绘法》处罚严厉 | 以欺骗手段取得资质→吊销资质证书+没收违法所得+罚款 | 建议尽快招聘自有专业人员替代挂靠 |
| 地面站建设审批链条缺失 | 遥感卫星地面站未报国家发改委核准（仅省级审批）+缺规划许可/消防备案 | IPO前取得发改委合规函或处罚豁免函 |
| 租赁农用地/林地建地面站 | 租赁集体林地建设商业地面站，违反土地利用总体规划 | 承诺上市前找到合规替代土地 |
| IDC经营许可证待申办 | 云服务/数据中心业务需IDC许可证，目前未取得 | 承诺取得前不得开展相关业务 |
| 保密资格即将到期 | 武器装备二级保密资格即将到期 | 关注续期进度 |

### 6.5 数据合规

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 用户语音数据无保护 | AI硬件收集用户语音数据，未加密/脱敏存储 | 交割后限期建立数据合规体系 |
| UGC侵权责任 | 浏览器插件类工具，用户可能上传侵权/违法内容 | 完善用户协议，技术上对用户输入内容审核 |
| 个人信息保护规模 | 境内个人用户超百万级 | 按要求履行报送义务 |
| 内容生态知识产权合规 | 付费课程/明星动作还原→涉及肖像权/版权授权 | 在产品规模化前引入专业IP机构进行FTO审核 |
| 产品部署合规 | 体育器械在公共场所部署→产品质量安全/电气安全 | 关注产品认证进度（3C/CE等） |
| 境外云服务DPA确认 | 前次核查仅获取通用协议，后公司补充完整DPA（含SCC/子处理者管理/安全措施Annex） | 跨境数据存储+DPA可将数据合规风险从高降至低 |
| 消费硬件跨境数据（不回传） | 位置/心率等用户数据存储于境外云服务，境内外版本分离运营 | DPO/DPIA义务在用户基数较小时未触发，用户规模增长时适时指定 |

### 6.6 ODI/外汇

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| ODI及外汇不合规 | 境外子公司设立未办理ODI手续，历史存在外汇处罚记录 | 要求补办ODI手续 |
| 协议控制瑕疵 | 约定股权质押给目标公司但未办理质押登记 | 补办质押登记或纳入兜底条款 |
| 跨境"对敲"换汇 | 以外币偿还人民币/以人民币偿还外币，资金境内外单向循环无物理流动 | 属非法买卖外汇（变相买卖外汇），不以直接买卖为必要；尽调发现即要求停止并评估处罚风险 |
| 非法买卖外汇处罚量化 | 非法买卖外汇罚款为违法金额30%以下（《外汇管理条例》第45条），具体幅度按《外汇管理行政罚款裁量办法》（2021）分档，"多次实施"属较重情节 | 按违法金额30%上限做压力测算；行政处罚时效2年（自行为终了日起算，《行政处罚法》第36条），涉金融安全且有危害后果的延长至5年 |
| 非法换汇刑事红线 | 变相买卖外汇扰乱市场秩序、情节严重构成非法经营罪；数额标准500万/违法所得10万 | 自用且非营利目的刑责风险较低，但通过地下钱庄/虚拟货币/改装POS对敲为打击重点；触碰红线的作重大风险提示 |
| 外汇瑕疵的IPO处理 | 实控人历史违规换汇超2年时效仍被审核关注 | 参照过会案例：尽早停止违规行为+取得外管部门书面确认不再处罚+公安检察法院不构罪确认 |
| 内保外贷未登记 | 签约后15个工作日内未办理外管登记 | 担保合同效力不受影响，但无法办理履约购汇及对外支付（履约实质受阻）；登记义务人为担保人，未登记可处罚（机构30万/个人5万以下） |
| 内保外贷资金回流套利 | 虚构贸易背景通过内保外贷获取境外资金回流境内赚息差 | 构成骗购外汇罪/逃汇/非法经营等刑事风险；核查担保设立背景与资金真实用途 |

### 6.7 国资/高校合规

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 国资程序瑕疵 | 国有股权转让未经评估/备案 | 协调国资监管部门补正确认 |
| 国资老股受让合规 | 拟受让国资股东部分老股，需履行国资转让程序 | 在陈述与保证或交割前提中确保已履行国资转让合规程序 |
| 高校教授创业持股合规 | 教授在公司持股但未全职任职，高校报备不完整 | 交割后义务：适时取得高校关于持股和兼职的备案或批准 |
| 高校技术转让定价公允性 | 以低价从高校受让核心技术（金额按项目数据），有评估支持但远低于国家课题资助经费 | 形式合规但实质公允性待论证 |
| 高校教授IP口头确认 | 声称与高校已"达成协议"但无书面确认函 | 推动获取高校不主张IP权利的书面确认 |
| 科技成果转化配套兼职 | 向高校支付技术许可费实际是为办理兼职审批而配套 | 确认转化定价公允性、审批程序完备性 |
| 外部顾问未签单独顾问协议 | 第一类外部顾问基于校企合作关系提供服务，未签个人协议 | 建议签署书面顾问协议，明确服务范围和IP归属 |

### 6.8 公司治理

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 投资人保护条款不足 | 仅4项事项需投资人50%同意 | 争取增加核心IP处置、关联交易超阈值等 |
| 董事会构成失衡 | 大股东委派多数董事 | 争取增加投资人董事席位 |
| 无一票否决权 | 投资人不享有一票否决权 | 争取核心事项的投资人保护性否决权 |
| 陈述与保证责任主体模糊 | 协议中陈保由"各方"共同做出 | 要求创始股东和目标公司单独作出陈保 |
| 反稀释无补偿机制 | 反稀释条款存在但无对应的补偿条款 | 补充反稀释的具体补偿执行机制 |
| 创始人合规意识薄弱 | 创始人对关联交易/财务规范性认知不足 | 投资人享有一票否决权，投资款分期支付 |
| 股权架构未定型 | 融资前同步进行创始团队股权权重调整 | 以完成架构调整为投资前提或可转债转股条件 |

### 6.9 IPO路径与审核

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 未盈利企业IPO | 计划以未盈利指标申报，但实际审批极审慎 | 充分论证IPO路径可行性 |
| 突击入股锁定期 | 申报前12个月新增股东需锁定36个月 | 测算锁定期对退出时间表的影响 |
| 无回购/对赌 | Pre-IPO项目中目标公司不接受回购和业绩对赌 | 评估无保障条件下退出的不确定性 |
| 资产来自上市公司 | 拟IPO企业资产来源于上市公司（非分拆上市） | 核查资产取得程序、信息披露 |
| 同业竞争认定 | 控股股东/实控人控制的其他企业存在相似业务 | 论证不构成重大不利影响的同业竞争 |
| 关联交易占比 | 与关联方存在大额关联交易 | 持续关注是否超过30%审核关注线（《监管规则适用指引——发行类第4号》：超30%需专项论证独立性） |
| 客户集中度过高 | 前五大客户收入占比超80% | 结合行业特征论证业务独立性 |
| 政府补助依赖 | 补助占利润总额超100% | 分析补贴持续性 |
| 估值攀升过快 | 短时间多轮融资、估值快速攀升数倍 | 分析行业是否已从"融资赛"转向"交付赛" |
| 私募基金存续期风险 | 控股股东为私募基金（有存续期安排） | 交易文件中约定基金架构拆除时间表 |
| 实控人变更影响IPO时间表 | 无实控人→需拆除基金架构→两年稳定期 | 合理预估IPO时间线 |
| 基金股东已届清算期 | 拟IPO企业基金股东进入清算期引发审核问询 | 基金存续期应覆盖上市筹备/审核+限售期+预计减持期，不足则提前展期并履行程序；清算期股东须出具审核期及上市后一定期间内不减持承诺；持股5%以上的减持计划披露要求以现行减持规则为准 |
| 申报后基金清算致股权变动 | 申报后清算分配产生新股东原则上终止审核 | 清算方案预先设计份额承继安排并取得全体承诺；新股东承诺36个月锁定 |
| 股东穿透核查执行困难 | 大型基金上层为政府引导基金/央国企/金融机构，逐层出函配合度低 | 以说明函模式应对：阐明基金设立背景、投资人类型结构、合规监管状态、在先上市配合记录，配合提供股权穿透表/验资/主体证照；主张核查应与"两层以上无实际经营且入股价格异常"等触发前提挂钩 |
| 基金群关联关系与一致行动认定 | 同一管理人旗下多只基金合计持股，IPO中被问是否构成一致行动人 | 从投资者构成差异、设立目的、实际控制与决策机制独立性论证非一致行动；提前准备各基金LP结构对照表 |
| 对赌回购的会计处理 | 股改基准日存在公司回购条款→投资款须确认金融负债，或致净资产不足折股 | 股改前终止公司回购义务（自始无效+签署日期在财务报告出具日前）；保留实控人回购等模式；涉及未生效恢复文件等特殊安排的，核查其披露合规与效力风险 |
| 对赌清理三种模式 | 彻底清理/调整义务人并附效力恢复/抽屉协议 | 抽屉协议不符合披露监管要求；优先"仅终止公司对赌保留实控人附条件回购"等披露合规模式；含未生效恢复文件类安排须评估披露义务与效力风险 |

### 6.10 境外运营合规

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 境外站点建成后无法运营 | 东道国政治/政策变化（如军方因素、政府换届）致站点被禁用，建设成本沉没 | 选址前第三方尽调+政治风险评估，交易文件中设置相应安排 |
| 境外合作模式多样风险差异大 | 合资（共享收益共担风险）vs 自建托管（自负盈亏）vs 外协（按需租用） | 评估不同模式下的资产安全+合规风险+退出成本 |

### 6.11 出口管制与两用物项


| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 两用物项出口管制风险 | 公司产品具有军民两用属性，出口目的地为敏感地区，终端用户可能涉及军事用途（产品与收入规模按项目核查） | 交割后限期完成出口合规评估及许可申报，交易文件设置出口管制陈述与保证和赔偿条款 |
| 出口定价异常 | 出口单价显著高于国内同类售价，反映终端用户军购溢价可能 | 作为"知道或应当知道"的间接证据，推动公司主动合规 |
| 公司对两用属性认知不足 | 不按相应口径立项、向民品方向表述 | 核查认知与整改情况，交易文件设置相应承诺 |
| 出口管制法律框架 | 《中华人民共和国两用物项出口管制条例》（国务院令第792号，2024.12.1施行）、《两用物项出口管制清单》（四部门公告2024年第51号，2024.12.1实施）、《出口管制法》第34条 | 三层判断框架：①产品是否具有军事用途设计②技术参数是否落入管制清单③出口经营者是否"知道或应当知道" |

**法律依据（核验2026-09-18，以现行有效文本为准）：**
- 《中华人民共和国两用物项出口管制条例》（国务院令第792号，2024年9月30日公布，2024年12月1日施行；官方文本：中国政府网、商务部官网）
- 《两用物项出口管制清单》（商务部、工业和信息化部、海关总署、国家密码局公告2024年第51号，2024年11月15日发布、12月1日实施）
- 《中华人民共和国出口管制法》（主席令第58号，2020年12月1日施行）第34条
- 法律责任（出口管制法第34条，适用于未经许可擅自出口、超许可范围出口、出口禁止出口物项三类情形）：没收违法所得；违法经营额50万元以上的并处违法经营额5-10倍罚款，没有违法经营额或不足50万元的处50万-500万元罚款；情节严重的责令停业整顿直至吊销相关管制物项出口经营资格

**交易文件映射：** 交割后承诺（6个月合规评估+许可申报）+ 陈述与保证（出口合规）+ 赔偿条款（行政处罚赔偿）

### 6.12 基金运营与出资人监管（管理人侧）

> 新增日期：2026-09-16 | 来源：2023 年专项研究（基金对外借款合规、信托资金入股管理人、国资及政府资金登记、上市公司与国企投资受限）

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 基金对外借款超限 | 私募基金财产用于借贷，余额超实缴金额20%或期限超1年 | 《关于加强私募投资基金监管的若干规定》（证监会公告〔2020〕71号）第8条：仅可为被投企业提供1年以内借款/担保，到期日不晚于股权退出日，余额≤实缴20%；违规将被责令改正/警示 |
| 借款流向不合规 | 基金借款给管理人自身、实控人或第三方；未经全体投资者签字确认 | 借款对象限于被投企业；向管理人/关联方借款须全体投资者同意并履行披露；留存认可文件 |
| 变相借贷不被备案 | 通过委托贷款/信托贷款/SPV从事经营性放贷，或设置无条件刚性回购（收益不与经营挂钩） | 属"明股实债"类安排，中基协备案规则不予备案；政府投资基金另受政府出资产业投资基金管理规定的名股实债禁令约束（发改财金〔2016〕2800号；以现行有效文件为准） |
| 职业放贷人风险 | 同一主体2年内向不特定对象出借10次以上 | 构成经常性放贷的，借贷合同可能被认定无效，情节严重涉非法经营罪；基金放贷仅限过桥性质 |
| 信托资金入股管理人 | 信托公司直接登记为管理人数量锐减；信托入股管理人遭中基协反馈追问意图与主管部门批准 | 核查管理人股东中信托计划/资管产品持股的合规性；协会关注出资架构清晰度与冲突业务 |
| 政府投资基金双重监管 | 政府直接/委托出资的产业投资基金除中基协备案外须在发改委登记系统填报 | 认缴协议签订后20个工作日内由管理人完成发改登记；母子基金模式由母基金统一登记，子基金填报信息；每年4月底前提交年报/审计/托管报告 |
| 国资LP权益登记 | 国资企业对有限合伙出资形成权益 | 按《有限合伙企业国有权益登记暂行规定》协助LP在30个工作日内办理占有/变动/注销登记，每年1月31日前更新实缴及对外投资信息 |
| 上市公司LP财务性投资限制 | 投资产业基金/并购基金属财务性投资，超合并净资产一定比例（实践参考线30%）影响再融资 | 上市公司作为LP出资前核查其财务性投资余额；董事会决议日前6个月至发行前新增财务性投资从募集资金中扣除（比例与口径以现行再融资规则为准） |
| 央企基金业务限制 | 央企对参投基金的出资比例上限、投资方式（项目直投等）受国资委现行央企基金管理规定约束 | 募资接触央企时预判其出资上限与投资方式限制（具体比例以国资委现行有效文件为准）；存续期延长与费率安排同样受限 |
