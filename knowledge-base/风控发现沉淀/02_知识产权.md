# 主题2：知识产权

> 本主题用于通用问题识别：不得据本文件推断任何特定企业存在所列问题。
> 适用于有核心技术/高校背景的项目。
> 涵盖：职务发明与前雇主IP风险、IP权属不清与转让瑕疵、专利诉讼与IP防御。

---

### 2.1 职务发明与前雇主IP风险

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 创始人来自高校/大厂 | 核心技术可能属前雇主 | 创始人担保+前雇主放弃声明 |
| 离职后一年内职务发明条款 | 核心专利密集申请于离职后1-2年 | 无法完全排除风险，上市前聘请FTO分析 |
| 保密协议范围过于宽泛 | 机密信息涵盖工艺/技术/算法，保密期限不限于任职期间 | 确认已建立信息隔离机制 |
| 前雇主未启用竞业限制 | 未实际支付竞业补偿金，但永久保密义务仍然存在 | 在交易文件中设置陈述保证 |
| 高校教授+博士后+实习生参与研发 | 存在利用高校物质技术条件完成发明的风险 | 督促IPO中介梳理IP权属 |
| 前司竞业限制已过时效 | 创始人离职已久，追诉时效已过（按实际离职时间核验） | 综合判断风险低 |
| 军工/科研院所核心团队离职确认 | 核心团队来自某航天科研院所等，已取得"离职创业不存在争议"确认函 | 如因IPO需要，核心人员应及时向前任职单位补充确认 |
| 同行业整建制离职+多机构排雷 | 核心团队多来自同行业企业，专利发明人集中于同行业背景 | 前雇主正式决议确认无违约+外部IP机构排雷检索（覆盖核心专利）+内部IP归属协议→构成多层缓释 |
| FTO报告费用性价比 | 排雷检索已做但正式FTO报告留存于外部机构，获取需另行付费（核验报告可取得性） | 结合前雇主无违约确认+排雷结论+已登记专利，可接受缺失 |

### 2.2 IP权属不清与转让瑕疵

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 合作研发未约定归属 | 委托开发未签协议 | 签署IP归属确认协议 |
| IP受让附带限制 | 从母公司受让专利但附带回购权、免费使用权 | 评估限制条款对资产独立性的影响 |
| IP许可掏空条款 | 向合资公司授予无偿/优先使用未来IP的权利 | 评估IP约束对公司未来发展的影响 |
| 委外合同未约定IP归属 | 多份委外合同仅约定成果交付 | 梳理全部委外合同，签署补充协议 |
| 未经许可使用算力资源 | 使用高校/关联方闲置算力进行模型训练，无书面授权 | 要求补签使用协议或停止使用 |
| 高校合作IP归属不明 | 与多所高校有算法合作，部分未签署书面IP归属协议 | 要求补签IP归属确认协议 |
| IP转让进行中未完成 | 应转专利/专利申请权仅部分完成转移（逐项检查应转与已转差异） | 将IP转让完成作为交割后限时承诺 |
| 分拆协议不完整 | 仅签署资产转让协议+IP转让协议，缺全面分拆协议 | 要求母公司对分拆事项进行确认 |
| 委托研发关系留尾巴 | 部分成果仍留在母公司 | 明确委托研发的IP归属 |

### 2.3 专利诉讼与IP防御

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 海外巨头专利狙击 | 行业龙头在多国同时发起专利侵权诉讼 | 逐案追踪诉讼进展 |
| UPC统一专利法院 | 裁决可在全部签约国同时生效 | 特别关注UPC管辖范围 |
| 新产品规避设计 | 开发新一代产品规避涉诉专利 | 要求提供涉诉管辖区专利律师FTO报告 |
| 多法域平行诉讼 | 同一专利族在多个法域同时进行 | 制定多法域应诉策略 |
| 保密协议泄露指控 | 外国公司主张通过NDA披露的技术信息被不当使用 | 审查NDA范围，评估独立研发证据链 |
| 中国专利无效宣告 | 成功将对方中国专利全部无效，但对方已提起行政诉讼 | 跟踪行政诉讼进展 |
| 海外IP布局缺失 | 仅有国内专利，无海外专利布局 | IPO前完成海外专利布局和FTO分析 |
| 开源模型商业化合规 | 核心基于MIT协议开源模型，需确认二次开发合规性 | 核查开源协议条款 |
