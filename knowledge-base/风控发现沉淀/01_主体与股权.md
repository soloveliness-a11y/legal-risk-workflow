# 主题1：主体与股权

> 本主题用于通用问题识别：不得据本文件推断任何特定企业存在所列问题。
> 适用于几乎所有项目。
> 涵盖：股权代持、出资与股权质押、实控人认定与控制权、股权激励与持股平台、历史股东退出与股权纠纷。

---

### 1.1 股权代持

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 创始人代持员工期权 | 虚拟股/代持ESOP，非标准架构 | 制定清理计划（转标准ESOP），创始人兜底历史纠纷损失 |
| 家族成员/配偶代持 | 因跨境身份等安排由亲属代持（背景与协议按项目核查） | 要求陈述与保证，明确解除条件和赔偿条款 |
| 多组代持并行 | 公司+持股平台层面多组代持并行（亲属/同事/顾问等多类主体） | 全面清理历史代持，签署解除协议+工商变更 |
| 代持因税务无法变更 | "股权转让税费较高无力缴纳"导致无法履约 | 交割前完成税务缴纳和工商变更，或作为交割前提 |
| 代持引发诉讼 | 外部投资人因代持未变更起诉 | 本次融资时清退纠纷股东 |
| 股权代持规避竞业 | 创始团队通过亲属代持设立公司规避前司竞业风险 | 确认代持已全部解除，IPO前完成清理 |
| 子公司层面代持未清理 | 某外省子公司层面仍存在股权代持 | 纳入交割后承诺，IPO前完成清理 |
| 代持还原风险 | 历史股权转让涉及代持还原，可能被认定为国有资产流失 | 核查是否纳入重整资产范围，评估权属纠纷风险 |
| 科技成果转化奖励形成代持 | 科研院所成果转化中部分权益由院所出资平台代持（比例安排按项目核查） | 要求适时解除代持，确保IPO前股权清晰 |
| 技术转化团队内部二次代持 | 技术转化平台份额集中由单一负责人代持 | 逐一确认各被代持人权益，签署代持解除协议 |
| CEO代持全部激励份额 | 全体激励对象份额集中由单一高管代持 | 要求IPO前完成代持规范，工商变更至各员工名下 |
| 配偶代持无代持协议 | 代持安排已确定但代持协议尚未签署 | 尽快签署代持协议，明确解除条件和赔偿条款 |
| 多层代持因架构需要 | 架构、融资与政策申报等需求叠加形成多层代持（背景按项目核查） | 计划清理代持转回创始人名下，纳入交割后承诺 |
| 外资转内资1元转让 | 境外主体以名义对价向境内主体转让多数股权（实缴情况核查），税务申报及外汇注销未办理 | 纳入交割后承诺；准备商业合理性说明应对税务核定风险 |

### 1.2 出资与股权质押

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 出资不实 | 知识产权出资评估虚高、货币出资未实缴 | 补足出资或调整估值 |
| IP出资专利被驳回 | 用于出资的发明专利被驳回，存在出资不实嫌疑 | 要求创始股东承诺以现金补足出资差额 |
| 收益法评估盈利预测未达标 | IP出资时采用收益法评估，实际收入未达预测目标 | IPO前聘请有证券资格评估机构追溯评估 |
| 股权质押 | 创始人股权质押给银行/前轮投资人 | 交割前解除或取得质权人同意 |
| 100%股权质押 | 全体股东将100%股权质押给银行 | 要求尽早归还贷款解除质押，至少在交割前解除 |
| 子公司100%股权被质押 | 子公司股权质押给银行（大额综合授信，金额按项目数据） | 确认质押对融资变更的影响 |
| 实缴出资多层穿透不足 | 持股平台认缴额与穿透后实际到账存在缺口（比例按项目数据计算） | 设置交割前提或交割后承诺 |
| 自然人股东被执行+限高+股权质押 | 小比例股权全部已质押，系被执行人 | 评估对IPO股权清晰性的影响 |
| 未实缴出资缺口大 | 下属平台认缴与实缴缺口大（金额与比例按项目数据计算） | 关注后续实缴安排 |
| 返投驱动子公司过多 | 多轮次新设返投主体注册资本合计较大且部分未实缴（金额按项目数据） | 结合上市计划落实或调整，避免影响上市安排 |

### 1.3 实控人认定与控制权

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 无实际控制人 | 控股股东为私募基金，GP层面均无法单独控制 | 评估无实控人对IPO的影响，制定架构拆除方案 |
| 有实控人→无实控人转换 | 控股股东通过老股转让/股东下翻/新投资人增资等安排调整持股与表决结构 | 确保两年稳定运行期后申报IPO |
| 一致行动人比照实控人锁定 | 多名股东签署一致行动协议、合计形成控制，可能被要求比照实控人锁定36个月（以监管规则适用指引及个案认定为准） | 评估锁定对投资退出流动性的影响 |
| 一致行动争议 | 一致行动协议条款模糊、到期未续签 | 明确一致行动范围和期限 |
| 一致行动协议缺失 | 创始人控制高比例表决权但未与持股平台签署一致行动协议 | 签署一致行动协议+设置股权成熟机制 |
| 一致行动人协议终止 | 创始人与退出股东的一致行动人协议已终止 | 评估实控人认定是否受影响 |
| 持股平台一人一票制 | 创始人作为GP无法独自决定持股平台投票 | 要求签署一致行动协议 |
| 控制权比例临界 | 剔除代持后实控人仅控制略高于50%的股权，贴近50%临界线 | 评估一致行动协议签署后的实际控制比例 |
| 控制权1元转让 | 母公司以名义对价转让股权（对应注册资本与实缴情况核查） | 评估1元转让的公允性和税务风险 |
| 一致行动"双轨制"稳固性差异 | 部分一致行动人签署专门协议+设违约后果，部分仅在股东协议中约定无单独文件 | 要求所有一致行动方签署专门协议并设置违约后果 |
| 董事席位暂控但可变 | 实控人暂控董事会过半（因某股东未委派），但该股东后续行使委派权即不足半数 | 与未委派董事的股东明确席位安排 |

### 1.4 股权激励与持股平台

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| ESOP外部人员任GP | 员工持股平台的GP/执行事务合伙人为非员工 | 要求尽快收回外部人员份额 |
| ESOP外部投资者混入 | 员工持股平台中存在非员工个人投资者 | 交割前将外部投资者转出至独立持股平台 |
| ESOP离职员工未退出 | 离职员工仍登记为持股平台合伙人 | 交割前完成离职员工份额回收 |
| ESOP实际授予超授权 | 期权池实际对应注册资本超已审议数量 | 要求股东会一并审议追认 |
| ESOP未税务备案 | 股权激励方案未向主管税务机关报送备案 | 交割后承诺中约定咨询财税顾问 |
| ESOP比例过高 | ESOP股权池占比过高（比例按项目数据） | 评估ESOP对投资人持股比例的稀释影响 |
| 股权激励条件过激进 | 行权条件约定过于激进的融资里程碑 | 审视激励条件合理性，制定新的ESOP方案 |
| 录用通知单约定期权 | 非正式股权激励（双位数比例股权），无正式ESOP方案 | 设置正式ESOP，将非正式承诺纳入规范框架 |
| 未计提股份支付费用 | 公司尚未就股权激励计提股份支付费用 | 评估追溯调整对历史各期净利润的影响 |
| 外部顾问获授价格差异 | 外部顾问获授价格与内部员工存在差异 | 引用证监会境外上市备案标准，要求提供贡献证据 |
| 虚拟股权+代持并存 | 融资顾问同时持有实际股权（代持）和虚拟股权 | 实际股权部分还原，虚拟股部分清理或正式化 |
| 拒绝提供激励明细 | 公司拒绝提供具体授予人员及股权明细 | 在风险提示中强调该不确定性 |
| 激励退出争议（金额小占比低但影响稳定性） | 离职员工退出定价与激励计划约定存在差异（退出价格机制按计划核查） | 尽快处置+签署保密文件，防范泄密风险 |
| 子公司预留代持待授予 | 子公司股权预留池由创始人代持（比例按项目数据），部分预留待后续授予 | 结合上市计划清理，IPO前完成代持规范 |
| ESOP零对价赠送无正式协议 | 期权池部分份额已零对价分配但尚未签署正式ESOP协议，以代持形式体现（比例按项目数据） | 聘请律师进行ESOP方案合规梳理 |

### 1.5 历史股东退出与股权纠纷

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 历史股东减资退出 | 退出安排含对价与上市挂钩、加重违约责任、个人连带或担保等强约束条款 | 评估履约敞口，建议在IPO申报前提前清偿或解除 |
| 退出过程存在多项历史诉讼 | 某历史股东曾就股东知情权/劳动争议等提起诉讼 | 审查全部诉讼最终处理结果 |
| 自然人股东股权冻结 | 因家庭纠纷股权被冻结，后达成和解解除 | 关注冻结是否完全解除 |
| 历史股权转让零对价 | 设立初期存在代持，解除时转让价格为0元 | 确认个人所得税纳税申报已办理 |
| 1元股权转让税务风险 | 历史股权转让对价多为1元/注册资本 | 要求创始股东承诺转让合法合规 |
| 工商变更严重滞后 | 多名合伙人入伙持股平台均未办理工商变更 | 本次融资时集中清理 |
| 投资方式中途变更 | 投资人先入伙持股平台，后改为另设平台 | 解除原入伙协议，退回投资款至新平台 |
| Pre-B轮终止后续 | 某轮融资终止但工商变更未完成 | 敦促完成退出手续和工商变更 |
| 溢价增资财务入账错误 | 一笔溢价增资应计入资本公积，但全部计入实缴资本 | 要求财务调整 |
