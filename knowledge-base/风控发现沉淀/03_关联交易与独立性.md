# 主题3：关联交易与独立性

> 本主题用于通用问题识别：不得据本文件推断任何特定企业存在所列问题。
> 适用于几乎所有项目，尤其是大企业孵化/分拆设立/部门分拆项目。
> 涵盖：大型企业孵化独立性、分拆设立独立性、部门分拆合规、客户-供应商重叠与供应链依赖、委外研发"壳公司"与财务真实性。

---

### 3.1 大型企业孵化独立性

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 人员独立性瑕疵 | 财务负责人及知识产权人员劳动关系在母集团 | 要求限期完成劳动关系转移 |
| 资产独立性瑕疵 | 大量专利与关联方共有（绝大多数申请于数年前），核心商标在关联方名下 | 要求核心商标/域名过户+共有专利权属确认 |
| 业务独立性瑕疵 | 关联收入占比较高，且存在向关联方销售的大额承诺 | 监控关联交易占比趋势与审核阈值 |
| 财务独立性瑕疵 | 大额关联借款（控股股东），关联方无偿提供土地/资产 | 制定关联借款归还计划 |
| 四维度综合分析框架 | 人员/资产/业务/财务四维度逐项分析 | 报告中应按四维度结构化呈现 |

### 3.2 分拆设立独立性

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 核心IP从实控人原公司受让 | 公司从实控人原关联企业受让核心业务相关资产 | 审查转让定价公允性 |
| 核心部件完全依赖关联方代工 | 关键部件完全委托实控人原关联企业生产 | 要求自建产线计划及时间表 |
| 关联采购占比快速攀升 | 关联采购占比呈持续快速上升趋势 | 设定关联交易占比上限 |
| 场地/技术/人员/业务四维度独立性瑕疵 | 与关联方同一楼层办公+技术来源于关联方+创始团队来自关联方 | 作为交割后承诺要求持续规范 |
| 实控人从已挂牌公司分拆业务 | 在新三板公司内部预研技术，后终止业务并转让给新公司 | 审查原公司决策程序合规性 |
| 同业竞争模糊地带 | 公司产品与关联方同类产品有差异但IPO审核需实质判断 | 提前论证不构成同业竞争的商业逻辑 |
| 子公司独立融资回购义务传导至母公司 | 子公司Pre-A轮股东协议含回购条款，母公司为回购义务主体 | 评估回购触发概率及对母公司金融负债/股东权益的影响，确保后续融资经股东会审议 |

### 3.3 部门分拆合规

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 分拆后运营不独立 | 在母公司办公区（无租赁协议）+法务IT系统依赖+工资过渡 | 评估独立性整改时间表 |
| 未进行资产评估 | 分拆及资产转移安排未进行过资产评估 | 关注低价转让是否构成利益输送 |
| 核心人员解约协议模糊条款 | "仍需遵守原单位规章制度及既往协议" | 要求创始团队就因既往任职单位事项承担赔偿责任 |
| 从大企业分拆独立 | 前身为大企业事业部，分拆后独立运营 | 全面核查独立性（技术、人员、业务、财务、机构） |
| 关联交易繁杂 | 与母公司/兄弟公司存在研发、采购销售、资金拆借、人员借调 | 逐项梳理关联交易 |
| 核心人员劳动关系在关联方 | CEO/高管仅签顾问协议，劳动关系在关联方 | 要求核心人员全职加入 |
| 测绘/地图服务依赖关联方 | 核心业务依赖关联方提供的测绘/地图服务 | 评估替代方案 |

### 3.4 客户-供应商重叠与供应链依赖

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 客户与供应商重叠 | 同一主体既为第一大客户又为第一大供应商（收入/采购占比按项目数据计算） | IPO重点关注是否构成重大依赖 |
| 核心零部件代采模式 | 关键部件供应商集中或独家，通过大客户代采 | 推动取得独立采购资格 |
| 应收账款高度集中 | 第一大客户应收账款占比与其收入占比基本相当 | 定量分析应收账款账龄和回收风险 |
| 大客户发展自有品牌 | 核心海外客户同时发展自有品牌产品 | 关注合作协议续签 |
| 定价不公允 | 向关联方采购价格显著高于市场价 | 定价调整+关联交易决策程序 |
| 资金占用 | 实控人借用公司资金、关联方往来款 | 交割前归还+禁令条款 |
| 关联主体众多 | 关联主体数量多，部分系"配合园区政策"设立 | 要求逐一制定处理方案 |
| 关联方未如实披露 | 公司未向投资人主动披露受托方的关联关系 | 要求完整披露，交割后承诺定期更新 |

### 3.5 委外研发"壳公司"与财务真实性

| 发现模式 | 典型表现 | 风控建议 |
|---------|---------|---------|
| 受托方为"壳公司" | 参保人数畸少、成立时间短、自然人股东 | 逐一核查受托方工商信息 |
| 委外研发与核心业务重合 | 委托内容为公司主营业务核心环节 | 区分"核心外包"和"辅助环节外包" |
| 受托方与公司疑似关联 | 工商留档电话/邮箱/地址/人员存在交叉 | 建立关联方蛛网识别矩阵（四维度交叉比对） |
| 委外费用与实际服务不匹配 | 委外研发费用规模与交付成果不匹配，疑似费用性质另作他用 | 核验合同、交付成果、收款方与资金用途，必要时专项审计 |
| 受托方同时为客户 | 同一主体既为供应商又为客户 | 穿透分析交易实质 |
