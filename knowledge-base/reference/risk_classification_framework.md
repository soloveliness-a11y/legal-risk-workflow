# 风险分类体系（17大类55+子类）— 参考框架

> **来源：** risk-report 外化参考｜基于法律风控实践与通用报告结构归纳（不包含案例编号与个案信息）
> **定位：** 本分类体系覆盖芯片、智能驾驶、AI、医疗、新能源、商业航天、Web3、装备制造等17个细分领域。它是风险识别的参考框架和检查清单，**不是每份报告的必填模板**。具体项目中，应根据实际情况选取相关大类、合并关联风险、新增特殊风险，不拘泥于完整覆盖。

| 大类 | 子类 | 典型问题 | 示例 |
|------|------|---------|------|
| **① 主体与股权 - 实际控制人** | 无实控人、控制权不稳定、一致行动 | 如：重整后主体无实控人认定 |
| | **股权架构调整** | 整合、减资、架构拆除、VIE | 架构拆除可行性、成本 |
| | **历史瑕疵** | 代持、出资不实、评估虚高、国有程序 | 如：股权转让瑕疵 |
| **② 上市合规 - IPO路径** | 未盈利、18C、对赌临界、板块选择 | 如：未盈利企业IPO可行性 |
| | **锁定期** | 突击入股（6/12/36个月） | 如：36个月锁定期分析 |
| | **回购条款** | 已触发、到期、利率、与上市冲突 | A轮回购已到期需展期 |
| **③ 业务与资产 - 业务独立性** | 关联交易、人员独立、同业竞争 | 如：关联交易比例高 |
| | **客户/供应商集中度** | 客户集中>50%、单一供应商依赖 | 如：第一大客户占比{X}% |
| | **知识产权 - IP权属** | 职务发明、IP权属争议、合作研发 | 如：兼职教授职务发明 |
| | **核心资产** | 特殊资质、重大订单、固定资产 | ICP资质、医疗器械许可 |
| **④ 公司治理 - 股东权利** | 特别表决权、投资人保护条款 | 如：高倍表决权 |
| | **决策程序** | 三会决议缺失、代持未登记、期权未备案 | 如：未按要求提交审批 |
| | **董监高变动** | 核心人员频繁变动、关键岗位空缺 | 近三年高管变动 |
| **⑤ 财务与税务 - 税务合规** | 欠缴税款、高新资格、股转代扣代缴 | 如：欠税+高新资格风险 |
| | **外汇合规** | ODI、外汇登记、处罚 | 如：未办ODI、外汇登记 |
| | **收入确认** | 一次性确认、业绩压力、会计准则 | 如：收入一次性确认占比{X}% |
| | **财政补贴** | 补贴依赖性强、不连续风险 | 如：收入依赖国补占比{X}% |
| **⑥ 外部风险 - 诉讼风险** | 海外专利诉讼、合同纠纷、行政处罚 | 如：国际巨头专利诉讼 |
| | **制裁/政策** | 技术同源、出口管制、行业监管 | 如：集团关联制裁传导 |
| | **环保/安全** | 环保处罚、安全事故、三同时 | 近三年安全事故 |
| **⑦ 投资保障 - 对赌/回购** | 触发条件、可执行性、与上市冲突 | 如：无对赌→退出风险 |
| | **兜底责任** | 创始股东偿付能力、赔偿范围 | 如：税务/外汇瑕疵兜底 |
| | **信息权/知情权** | 定期财报、重大事项通知 | 季度/年度信息披露 |
| **⑧ 行业特殊 - 特殊资质** | 医疗许可、ICP/IDC、金融牌照、A13 | IDC牌照申请中 |
| | **供应链风险** | 代工依赖、关键部件单一、断供 | 核心芯片100%依赖进口 |
| | **海外FTO** | 专利侵权、出口管制、海外合规 | 未做海外FTO调查 |
| | **政策敏感度** | 补贴退坡、行业准入、数据监管 | 如：收入依赖国补占比{X}% |
| **⑨ 商业道德** | 销售费用合规、商业贿赂、虚开发票 | 推广费支付给指定第三方 |
| | **算力资源使用** | 无许可侵占、高校资源使用 | 使用高校闲置算力 |
| | **知识产权债务** | 对赌性许可、掏空资产、排他性专有许可过宽 | 合资公司IP无偿使用权、未来IP优先使用权 |
| | **军工客户集成商模式** | 穿透核查最终客户、收入真实性、集中度+高变动性 | JG客户通过集成商间接采购 |
| **⑩ 新经济特有** | AI监管（大模型备案、数据出境） | 调用境外大模型未备案 |
| | **Web3合规** | 代币属性、多牌照 | 代币可能被认定为证券 |
| | **早期特征** | 虚拟股、代持集中、回购到期 | 多轮回购已到期 |
| **⑪ 劳动与社保** | 社保公积金缴纳不足、劳务派遣违规 | 未按全额缴纳 |
| | **竞业限制** | 未签署、覆盖不完整 | 核心技术骨干未覆盖 |
| **⑫ 环保与安全生产** | 环评批复缺失、危废处理不规范 | 三同时文件缺失 |
| **⑬ 数据合规** | 个人信息保护、数据跨境传输 | 隐私政策不完备 |
| **⑭ 关联交易** | 关联方资金占用、定价不公允 | 关联方交易占比过高 |
| **⑮ 重大合同** | 潜在赔偿责任、质保义务、连带责任 | 重大合同不利条款 |
| **⑯ 境外架构** | ODI未办、外汇登记缺失、VIE合规 | 境外架构搭建合规性 |
| **⑰ 知识产权债务与FTO** | 开源合规、第三方IP依赖、侵权风险 | 使用开源协议未审查 |
