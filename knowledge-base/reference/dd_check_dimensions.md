# T2 交叉比对必查项（9 维度）

> **用途：** dd-check T2 触发点执行交叉比对时的必查维度清单
> **权威定义：** dd-check SKILL.md「9 维交叉比对（权威定义）」——两者不一致时以 SKILL.md 为准
> **更新日期：** 2026-09-15（开源重构：补第 9 维董监高画像，数据源表述中立化）

---

每个维度至少完成 1 项交叉比对，不可跳过：

| 维度 | 必查项 | 数据源 | 典型不一致 |
|------|--------|--------|-----------|
| 工商信息 | 注册资本/实缴资本 | 工商数据源 cache vs 营业执照/章程 | 注册资本不一致 |
| 股权结构 | 全体股东名单及比例 | 工商数据源 cache vs 股东名册 | 股东数量差异、代持未披露 |
| 对外投资 | 合并范围公司名单 | 工商数据源 cache vs 公司说明 | 未披露子公司/体外循环 |
| 诉讼仲裁 | 重大诉讼列表 | 工商数据源 cache vs 公司披露 | 遗漏重大诉讼 |
| 知识产权 | 专利/商标/软著数量 | 工商数据源 cache vs IP 清单 | IP 数量差异、权属纠纷 |
| 行政处罚 | 处罚记录 | 工商数据源 cache vs 合规声明 | 未披露处罚 |
| 关联交易 | 关联方清单 | 工商数据源 cache vs 公司披露 | 遗漏关联方 |
| 经营异常 | 异常名录记录 | 工商数据源 cache vs 合规声明 | 未披露经营异常 |
| 董监高画像 | 高管名单/兼职/对外投资/同业 | 工商数据源 cache vs 公司披露、公示信息 | 兼职关联企业未披露、同业竞争、离职未变更挂名 |

---

> **使用说明：** 本表为 T2（清单回复正向匹配）触发点的必查基准，T1（预扫描）和 T3（补充资料）根据资料覆盖情况酌情参考。
> 工商数据源 cache 指统一 schema 的采集结果（CONTRACT §7.1），无论 API 自动采集还是手工填录。
