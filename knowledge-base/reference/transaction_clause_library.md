# 交易文件常见结构与条款检查点

> **用途：** txn-docs 起草/修订交易文件时引用的条款结构说明与检查点。本文件只提供"常见结构、要素与核查要点"，不内置任何机构范本原文或底线参数；具体表述、数值与期限以使用者有权使用的机构范本及本项目交易文件为准。
> **范本接入：** 本开源包不附交易协议范本（见 `templates/交易文件模板/README.md`）。使用者应接入自己机构的范本（txn-docs 模式一「自备范本接入」）。

---

## 一、常用交易文件构成

按投资方式组合使用，范本路径均指向使用者自备文件（`{用户范本路径}`）：

| 序号 | 文件名称 | 核心用途 | 范本路径 |
|------|----------|---------|------------------|
| 1 | `增资协议` | 增资条款、估值、出资方式、交割条件 | `{用户增资协议范本路径}` |
| 2 | `股东协议` | 投资人特别权利、治理结构、保护性条款 | `{用户股东协议范本路径}` |
| 3 | `股权转让协议` | 老股转让、价款、陈述保证、交割条件 | `{用户股权转让协议范本路径}` |
| 4 | `股东名册` | 股东名册更新，确认权利归属 | `{用户股东名册模板路径}` |
| 5 | `出资证明书` | 出资确认，签发凭证 | `{用户出资证明书模板路径}` |

**注意：** 实际交易中使用的文件类型取决于投资方式：
- **纯增资：** 增资协议 + 股东协议 + 股东名册 + 出资证明书
- **纯老股转让：** 股权转让协议 + 股东协议修订 + 股东名册
- **组合方式（增资+老股转让）：** 投资协议（合一版）或分别签署两份 + 股东协议 + 股东名册 + 出资证明书

### 1.1 增资协议常见结构

| 条款编号 | 条款名称 | 核心内容 |
|---------|---------|---------|
| 第一条 | 定义 | 术语定义 |
| 第二条 | 本次交易及文件交付 | 投前估值、投资款、认购比例（含充分稀释说明）、交割安排、交割日股权结构、放弃优先认购权 |
| 第三条 | 交割前提条件 | 先决条件清单（详见附件）；交割期限（{约定期限}） |
| 第四条 | 投资款的缴付和用途 | 公司账户信息、出资证明书/股东名册交付、资金用途限制（{主营+流动资金等约定范围}）、理财限制 |
| 第五条 | 投资后义务 | 工商变更（{约定期限}）、商务/外汇备案、合规运营、核心人员协议签署（{约定期限}+竞业+保密+IP归属）、信息权、重大事项通知 |
| 第六条 | 陈述和保证 | 主体资格、股权清晰、知识产权、税务合规、关联交易公允、劳动社保、诉讼仲裁、重大合同、重大不利影响、完整披露 |
| 第七条 | 各方义务 | 投资人缴款义务、公司/创始方配合义务 |
| 第八条 | 改制 | 整体变更为股份公司的安排 |
| 第九条 | 合同终止 | 终止情形、终止后处理 |
| 第十条 | 违约责任 | 赔偿范围、交割前事项赔偿、交易费用承担、逾期违约金 |
| 第十一条 | 保密 | 保密义务及例外 |
| 第十二条 | 适用法律和争议解决 | {适用法律、约定争议解决机构} |
| 第十三条 | 通知 | 通知方式、送达日期认定 |
| 第十四条 | 其他 | 完整协议、弃权、权利转让、条款效力、语言文本 |

**附件常见构成：** 交割前提条件、陈述和保证、披露函、公司基本信息、核心员工、通知地址

**交割前提条件常见要点：**
陈述保证真实准确、履行承诺事项、第三方同意许可、尽职调查满意、内部审批完成、股东会/董事会批准（含优先购买权放弃、章程修改）、交易文件签署、无重大不利影响、核心人员协议签署、交割证明签署

### 1.2 股东协议常见结构

| 条款编号 | 条款名称 | 核心内容 |
|---------|---------|---------|
| 第一条 | 定义 | 术语定义，与增资协议共用 |
| 第二条 | 股权结构 | 交割后股权结构表、股权分类（各轮投资人股权）、每股价格定义及调整机制 |
| 第三条 | 股东会 | 定期/临时股东会召开、重大事项表决（{约定表决比例}）、投资人保护性规定（一票否决事项清单） |
| 第四条 | 董事会 | 董事席位分配、投资人董事任命权、董事会职权及表决 |
| 第五条 | 监事 | 监事席位、投资人监事任命权 |
| 第六条 | 股权激励 | ESOP设立（规模、方式、审批） |
| 第七条 | 投资人特别权利 | 回购权、反稀释、优先购买权、共同出售权、优先清算权、优先认购权、最惠国待遇（详见第二章） |
| 第八条 | 信息权 | 定期财报、年度审计报告、业务计划/预算、重大事项通知、查阅权 |
| 第九条 | 不竞争 | 创始人竞业限制、关联方不竞争 |
| 第十条 | 其他特别约定 | 创始人股权锁定、创始人新项目补偿、创始人行为约束 |
| 第十一条 | 保密 | 保密义务 |
| 第十二条 | 违约及违约赔偿 | 赔偿范围、交割前事项、违约金 |
| 第十三条 | 适用法律和争议解决 | {适用法律、约定争议解决机构} |
| 第十四条 | 效力、修订及其他 | 完整协议（取代前轮）、弃权、权利转让、条款效力 |

**保护性规定（一票否决事项）常见范围：**
重大资产处置（{金额阈值}）、合并/收购/重组/分立/解散/清算、发行新股/期权/可转债、修改章程、超预算支出、核心业务变更、关联交易、利润分配、IP转让或独占许可

### 1.3 股权转让协议常见结构

| 条款编号 | 条款名称 | 核心内容 |
|---------|---------|---------|
| 第一条 | 定义 | 术语定义 |
| 第二条 | 股权转让 | 转让标的、转让价格（含税）、转让前后股权结构、交割和付款（{付款安排，如分期+完税凭证}） |
| 第三条 | 交割前提条件 | 条件清单、交割期限 |
| 第四条 | 转让后义务 | 工商变更登记（{约定期限}）、合规运营、核心人员协议 |
| 第五条 | 特别约定 | 不竞争、信息权、投资人权利确认 |
| 第六条 | 陈述和保证 | 与增资协议基本一致 |
| 第七条 | 各方义务 | 各方配合义务 |
| 第八条及以后 | 通用条款 | 违约责任、保密、争议解决、通知、其他 |

### 1.4 股东协议常见补充条款

| 条款 | 内容要点 | 适用场景 |
|------|---------|---------|
| **业绩承诺与补偿** | 承诺净利润目标、补偿方式（现金/股权）、审计确认机制 | 有业绩对赌的项目 |
| **上市终止/恢复条款** | 申报IPO时特殊权利条款终止，被否决/撤回后于{恢复窗口期}内自动恢复 | Pre-IPO项目 |
| **连带担保条款** | 共同承诺方（创始人+实控人）对目标公司义务承担连带责任，担保范围含主债务+利息+违约金+实现债权费用，担保期限{约定期限} | 常见条款 |
| **股权回购** | 触发事件、回购价格（{计算公式}）、回购义务人（公司+创始人连带等）、回购顺位、公司回购程序（减资方式）、未收回投资款的新项目补偿机制 | 常见条款 |

## 二、常见条款要素与核查要点

### 2.1 基础条款

| 条款 | 内容要点 | 实操要点 |
|------|----------|---------|
| **投资方案** | 增资额/转让额、投资款支付安排（一次性/分期）、投前/投后估值 | 关注付款条件是否与交割条件挂钩 |
| **先决条件** | 交割前必须满足的条件清单 | 逐项核对：工商变更、陈述保证真实、第三方同意、关键人员签署协议等 |
| **陈述与保证** | 公司及创始方对现状的声明 | 范围覆盖：主体资格、股权结构、财务数据、税务合规、劳动用工、知识产权、诉讼仲裁、重大合同、关联关系 |
| **交割** | 交割日确定、交割文件清单、交割方式 | 交割文件通常包括：工商变更证明、股东名册更新版、章程修订版等 |

### 2.2 投资人特别权利（核心条款）

> 条款要素按市场常见做法归纳；优先级与具体参数由使用者按机构政策与谈判地位确定。

| 条款 | 常见条款要素 | 风控关注要点 |
|------|-----------------|-------------|
| **回购权** | 触发事件：①未能按期上市（{期限+估值条件}）；②重大违反交易文件；③虚假陈述/重大遗漏；④创始人诚信问题（{约定情形清单}）；⑤其他投资人要求回购；⑥停业/破产<br>回购价格：{计算公式，常见为投资款+约定收益-已分红}<br>回购义务人：{公司/创始人及其责任形态}<br>回购顺位：{轮次顺位安排}<br>公司回购程序：按公司法减资程序办理（通知债权人、公告等法定时限）<br>公司担保范围：{是否含付款义务与股权回购义务的区分}<br>未收回投资款的创始人新项目补偿机制 | 关注：①上市期限是否合理；②回购收益率是否过高；③公司回购程序是否符合公司法；④创始人回购能力是否充足；⑤回购顺位安排是否损害本轮利益 |
| **反稀释** | 触发：新一轮增资/老股转让价格低于本轮<br>补偿方式：{定向分红/资本公积转增/低价转让等约定机制}<br>目的：确保本轮投资人的每单位股权价值不被稀释 | 关注：①补偿方式是否可执行；②例外情形是否合理（员工期权池通常除外） |
| **优先购买权** | 程序：转股股东发转让通知 → 投资人{答复期}内答复 → 行权人按出资比例认购 → 第二次答复期<br>例外：{经批准的员工激励等约定情形} | 关注：①答复期是否合理；②是否允许按比例购买；③例外情形是否合理 |
| **共同出售权** | 触发条件：投资人未行使优先购买权<br>共售份额公式：按{约定公式}计算<br>控制权变更是否受限、违约转让惩罚：{按约定价格购买+差额补偿等} | 关注：①共售公式是否合理；②违约转让保护是否充分 |
| **优先清算权** | 触发条件：公司解散清算、控制权变更（{表决权转移阈值}）、重大资产处置<br>清算顺序：{按轮次顺位与约定分配额}<br>剩余财产按股权比例分配<br>法律障碍时的补偿机制 | 关注：①清算顺序是否合理；②收益率与回购条款是否一致；③创始人新项目补偿条款 |
| **保护性规定** | 一票否决事项清单：<br>• 重大资产处置（{金额阈值}）<br>• 合并/收购/重组/分立/解散/清算<br>• 发行新股/期权/可转债<br>• 修改公司章程<br>• 超过预算的重大支出<br>• 核心业务变更<br>• 关联交易<br>• 利润分配<br>• 知识产权转让或独占许可 | 关注：①否决事项范围是否合理；②是否影响公司正常经营；③是否与创始人控制权有冲突 |
| **知情权** | 公司提供义务：<br>• 定期财报（资产负债表、损益表、现金流表）<br>• 年度审计报告<br>• 年度/季度业务计划和预算<br>• 重大事项通知（诉讼、行政处罚、股权变动等）<br>投资人查阅权：财务信息、经营数据、现场走访 | 关注：①报送时间要求；②信息范围是否全面；③违约责任是否明确 |
| **最惠国待遇** | 未来若给予新投资人更优权利，本轮投资人有权自动享有同等或更优权利 | 关注：①适用范围是否明确；②是否限于同等条件 |
| **优先认购权** | 公司新增注册资本时，本轮投资人按当前股权比例优先认购 | 关注：①行使期限；②定价机制 |

### 2.3 陈述与保证条款（风控转化核心）

> **此条款是将风控报告发现的问题转化为合同保护的关键桥梁。**

| 风控发现类型 | 对应陈述保证条款 | 实操要点 |
|-------------|-----------------|---------|
| 股权代持 | "公司股权不存在代持、信托安排，所有登记股东均为实际持有者" | 若存在代持，增加代持披露和解除承诺 |
| 历史沿革瑕疵 | "公司设立、历次变更均已依法履行批准/备案程序" | 若有瑕疵，增加整改时间表和赔偿责任 |
| 税务风险 | "公司已依法申报并缴纳各项税款，不存在重大税务违法、违规" | 若有欠税，增加补缴时间和兜底责任 |
| IP 权属 | "公司对其核心知识产权拥有合法、完整所有权，无权属争议" | 若有职务发明风险，增加创始人担保 |
| 劳动社保 | "公司已与全体员工签署劳动合同，依法足额缴纳社保公积金" | 若有不足，增加补缴承诺时间表 |
| 诉讼争议 | "公司不存在未披露的重大诉讼、仲裁、行政处罚" | 列出已披露的清单，未披露的由创始人担责 |
| 关联交易 | "关联交易的定价公允，不存在利益输送" | 增加关联方清单和关联交易承诺 |
| 数据合规 | "公司数据处理活动符合《个人信息保护法》等法律法规" | AI 项目重点 |

### 2.4 交割后义务条款

| 义务类型 | 典型条款 | 期限 |
|---------|---------|------|
| 工商变更 | 完成本轮增资/股权转让的工商变更登记，更新股东名册 | {约定期限} |
| 章程修订 | 修改公司章程以反映新的股权结构和治理结构 | {约定期限} |
| 关键人员协议 | 核心人员签署劳动合同、竞业限制、保密协议、知识产权归属协议 | {约定期限} |
| 资质办理 | 取得/续期经营资质（ICP、药品许可等） | 约定期限内 |
| 风险整改 | 根据尽调和风控指出的问题进行整改 | 约定具体期限 |
| ESOP 设立 | 按约定规模设立员工持股平台 | {约定期限} |
| 信息披露 | 定期提交财务报告和业务数据 | 按知情权约定 |

### 2.5 创始人限制性条款

| 条款 | 内容 | 实操要点 |
|------|------|---------|
| **创始人股权锁定** | 未经投资人同意，创始人不得转让、质押或以其他方式处分其直接或间接持有的公司股权 | 关注间接转让是否覆盖（持股平台层面） |
| **非竞争承诺** | 创始人及其配偶、直系近亲属不得从事与公司相竞争的业务 | 关注竞业期限和地域范围 |
| **创始人新项目补偿** | 若创始人从事新项目，投资人有权按{约定机制}取得新项目权益，创始人承担相应出资义务 | 这是非常重要的退出保护机制 |
| **创始人行为约束** | 重大个人诚信问题的具体情形（如账外销售、伪造财务资料、侵占资产、竞争行为、犯罪行为、关联交易损害、占用资金等），按范本逐项定义 | 该等条款在回购触发中有实际价值 |

### 2.6 违约责任条款

| 条款 | 内容 |
|------|------|
| **赔偿范围** | 直接损失 + 间接损失（包括律师费、审计费、调查费、诉讼费） |
| **交割前事项赔偿** | 交割日前存在的风险事项，无论是否披露，由保证方连带赔偿 |
| **交易费用** | 若因虚假陈述/重大差异导致交易终止，投资方交易费用（审计/法务费，上限{约定金额}）由公司承担 |
| **逾期违约金** | 回购逾期：{约定的逾期违约金标准} |
| **违约转让保护** | 创始人违约转让股权，投资人有权要求创始人按不低于该价格购买投资人全部股权，差额补偿，实控人/控股股东承担连带责任 |

### 2.7 争议解决

| 条款 | 常见安排 |
|------|-----------------|
| **适用法律** | 中华人民共和国法律（跨境交易按架构约定） |
| **争议解决** | 仲裁（按约定选择仲裁机构）或诉讼（约定管辖法院） |
