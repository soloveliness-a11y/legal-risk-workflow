# 法律法规索引

> 风控工作流中常用的法律法规模块化 Issue Map，按尽调维度分类。
> 各子 Skill 在涉及对应法律问题时按需加载。
>
> **格式**：所有文件为 "Issue Map + Authority 检索 + last_verified" 结构——只提供 issue spotting（该查什么）与检索关键词（去哪查），不硬编码条号与条文内容；具体条文由 legal-research 从法源适配器（CONTRACT §7.5）运行时获取现行版本。

## 文件清单

| 文件 | 覆盖范围 | 使用场景 |
|------|---------|---------|
| `公司法要点.md` | 实控人认定、股权代持/转让/出资、公司治理、减资回购、优先权、章程特殊条款 | Phase 1-3 全流程（主体架构、历史沿革、治理结构） |
| `证券法上市要求.md` | 板块选择与上市条件、发行条件、锁定期、审核红线、分拆上市、退市风险 | Pre-IPO项目重点（Phase 1 Step 1.2 / Phase 3 Step 3.3） |
| `数据合规法规.md` | 个人信息合法基础、数据出境、敏感个人信息、等保、算法与自动化决策、行业特殊数据 | 涉及数据处理的项目（Phase 3 Step 3.3 / Phase 2 dd-check） |
