## 板块选择与上市条件

### 风控问题
- 各板块适用性判断（按企业特征匹配，门槛数值以现行规则为准）：
  - 硬科技/未盈利 → 科创板（参考锚点：市值导向标准约 40亿元量级的未盈利套标准）[exchange_rule]：科创属性论证难度、研发投入占比
  - 创新型成长企业 → 创业板（参考锚点：两年累计净利润约 5000万元量级）[exchange_rule]：创新性论证、"三创四新"定位
  - 传统盈利企业 → 主板（参考锚点：三年累计净利润约 1.5亿元量级）[exchange_rule]：盈利质量、持续性论证
  - 专精特新中小企业 → 北交所（参考锚点：两年净利润约 1500万元量级 + 新三板挂牌 12个月前置）[exchange_rule]
  - 港股特专科技公司 → 港股 18C（参考锚点：已商业化公司市值约 40亿港元 + 最近年度收益约 2.5亿港元；未商业化公司约 80亿港元。40/80亿为 2024-09-01 至 2027-08-31 适用的短期下调值）[exchange_rule]：适用行业限定、豁免条件复杂
- 门槛数值随规则修订频繁调整，项目判断时必须由 legal-research 拉取现行上市规则核对，禁止沿用本文件锚点数值直接下结论

## 锁定期与突击入股

### 风控问题
- 申报前 6个月内新增股东：锁定 36个月（自上市之日起）——Pre-IPO 项目必须计算投资时点与预计申报时间的间距 [exchange_rule]
- 申报前 12个月内新增股东：部分情形锁定 36个月；增资/受让均需关注，受让自实控人的更严格 [exchange_rule]
- 其他股东：12个月；需确认股东分类，不同身份锁定期不同 [exchange_rule]
- 股东身份分类核查：控股股东/实控人/突击入股/定增各自适用不同锁定期规则 [exchange_rule]

关键词：突击入股 锁定期 / 控股股东 锁定 / 定增 限售 / 股东分类

## 审核红线与风险定性

### 风控问题
- 股权代持：必须在申报前彻底清理；核查代持协议、还原程序、纠纷风险；口头代持需书面确认函补强 [statute]
- 实控人变更：报告期内变更需运行满一定期间（历史参考值：2年/24个月）；评估变更原因、对公司影响；无实控人需论证治理有效性 [statute]
- 对赌协议：申报前需清理或确认不恢复效力；核查对赌条款清单、清理方案、是否存在恢复效力条款 [exchange_rule]
- 关联交易：需论证必要性、公允性、程序合规（参考阈值见"关联交易与客户依赖"节） [statute+practice]
- 同业竞争：实控人控制的其他企业不得同业竞争；核查范围含实控人近亲属控制企业；区分"同业"与"不竞争" [statute+exchange_rule]
- 行政处罚：重大违法违规一定期间内不得申报（历史参考值：36个月）；区分"重大"与"一般"：罚款金额、主管机关认定、整改情况 [statute]
- 独立性缺陷：资产完整、人员独立、财务独立、机构独立、业务独立；大企业分拆项目四维度逐一核查（研发/采购/资金/人员） [statute]

关键词：股权清晰 / 实际控制人 稳定 / 对赌 清理 / 同业竞争 / 独立性 五独立 / 重大违法 违规
可能涉及：首发注册管理办法 / 监管规则适用指引 / 招股说明书准则 / 证券法

## 分拆上市

### 风控问题
- 监管趋势：新"国九条"后持续从严（2024-2025），多家 A 股公司终止分拆上市 IPO；从"数量扩张"转向"质量提升"，更强调子公司的技术壁垒和盈利独立性 [practice]
- 成功案例集中在高端装备、新能源、智慧物流等高成长性行业；个别特殊性过会案例参考意义有限 [practice]
- 大企业分拆项目必须在报告开篇即评估分拆上市可行性 [practice]：
  - 母公司分拆动机和决策程序合规性
  - 子公司资产完整性、业务独立性
  - 是否属于"从严监管"的高风险类型

### Authority 检索
关键词：分拆上市 / 从严监管 / 上市公司分拆规则
可能涉及：上市公司分拆上市相关规定 / 新"国九条"及配套政策 / 交易所审核动态

## 资产来自上市公司

### 风控问题
核查清单 [exchange_rule]：
1. 发行人取得上市公司资产的背景、决策程序、审批程序与信息披露
2. 发行人及关联方董监高在上市公司的历史任职情况及合法合规性
3. 是否存在违反竞业禁止义务
4. 资产转让是否存在损害上市公司及中小投资者利益的情形
5. 资产置入时间、占比、对发行人生产经营的作用

### Authority 检索
关键词：资产来自上市公司 / 分拆 资产转让 / 竞业禁止
可能涉及：监管规则适用指引（发行类）/ 交易所审核问答

## 关联交易与客户依赖阈值

### 风控问题
| 指标 | 参考阈值（practice） | 风控建议 |
|------|---------|---------|
| 关联交易占比 | 30%（关注线） | 超过需详细论证公允性和必要性 |
| 单一客户依赖 | 50%（重大依赖认定） | 需论证合作稳定性、可替代性 |
| 前五大客户集中度 | 80%（需重点论证） | 行业特性与客户集中度的匹配分析 |
| 供应商集中度 | 70%（关注线） | 核查供应链替代方案和断供风险 |

> 阈值为审核实践参考线 [practice]，非法条数值，具体项目按交易所问询口径校准。

## 退市与风险警示

### 风控问题
- 已投或拟投项目退出路径受退市规则影响：财务类退市指标（利润/营收/净资产组合）、交易类退市（市值/面值）、重大违法强制退市 [exchange_rule]
- 风险警示（ST/*ST）情形对流动性、质押、回购条款触发的影响 [exchange_rule]
- Pre-IPO 项目需评估上市后持续满足上市条件的脆弱性（贴线达标企业的退市敏感度） [practice]
