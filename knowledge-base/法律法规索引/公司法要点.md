## 实际控制人与控股股东

### 风控问题
- 实控人认定路径（持股/表决权/实际支配）
- 共同实控与一致行动：
  - 一致行动协议的期限、解除条件、分歧解决机制
  - "隐性一致行动"识别（近亲属持股、共同委派董事等）
  - IPO 审核中一致行动关系稳定性是重点问询对象
- 无实控人架构：本身不构成上市障碍，但需论证公司治理有效性和决策稳定性；股权分散公司需关注争夺控制权的潜在风险
- 实控人变更：报告期内变更是审核红线，需运行满一定期间（历史参考值：主板 2年/创业板 24个月，以现行规则为准）；评估变更原因及对公司影响

### Authority 检索
关键词：实际控制人 认定 / 控股股东 定义 / 一致行动 / 无实际控制人 / 控制权稳定
可能涉及：公司法（控股股东/实控人定义条款）/ 公司法司法解释 / 《上市公司收购管理办法》（一致行动相关条款）/ 首发注册管理办法 / 交易所上市规则

## 股权代持与股权清晰性

### 风控问题
- 代持关系核查与还原：
  - 代持协议真实性与完整性，关注是否存在"口头代持"等无书面证据情形
  - 还原路径的税务合规性（代持还原可能涉及个税/印花税）
  - 出资责任穿透：名义股东未实缴的，实际出资人可能被追加承担连带责任
  - 多层嵌套代持或外资代持需额外关注外汇合规
  - IPO 申报前必须彻底清理，需披露代持形成原因、演变、解除过程及是否存在纠纷
- IPO 红线定性：股权代持必须在申报前彻底清理；口头代持需书面确认函补强

### Authority 检索
关键词：股权代持 效力 / 代持还原 税务 / 名义股东 出资责任 / 口头代持
可能涉及：公司法司法解释三（代持相关条款）/ 公司法（出资责任条款）/ 税法（代持还原税务处理）

## 股权转让

### 风控问题
- 转让程序是否履行（通知/同意/优先购买权）：
  - 逐笔核查历史股权转让是否履行通知程序、是否取得其他股东放弃优先购买权的书面确认
  - 未履行通知义务或损害其他股东优先购买权的，产生优先购买权救济、赔偿及交易履行风险；**不应仅因该程序瑕疵当然认定股权转让合同无效**，合同效力需结合其他效力事由判断
  - 程序瑕疵影响合同效力还是仅产生救济权（按现行规则与个案判断）
- 章程特别约定：关注章程是否有转让限制的特殊约定；新公司法允许章程对股权转让另行约定，可利用此设计转让限制

### Authority 检索
关键词：股权转让 通知程序 / 优先购买权 / 章程 另行约定 / 转让效力 / 股权转让合同效力 优先购买权救济
可能涉及：公司法（股权转让条款）/ 公司章程 / 公司法司法解释 / 民商事审判会议纪要（合同效力与救济的区分口径）

## 股东出资

### 风控问题
- 出资不实与虚假出资：
  - 核查实缴凭证（银行流水、验资报告），特别关注无形资产、股权等非货币出资的评估公允性
  - 法定实缴期限（新法限期实缴制）下是否存在补缴压力及对估值的影响
  - 抽逃出资核查：出资后短期内大额资金流向关联方
- 出资义务加速到期情形的识别

### Authority 检索
关键词：出资义务 / 实缴期限 / 非货币出资 评估 / 抽逃出资 / 加速到期
可能涉及：公司法（出资义务及加速到期条款、抽逃出资条款）/ 公司法司法解释三（出资责任条款）

## 公司治理（决议效力与董监高义务）

### 风控问题
- 决议瑕疵：
  - "三会运行规范性"核查重点：通知合规性、出席人数、表决比例
  - 区分决议无效/可撤销/不成立三种瑕疵类型
  - 决议效力瑕疵不影响公司与善意相对人形成的法律关系（善意相对人保护），为投资交易提供保护
  - 历史决议瑕疵需评估是否影响已执行交易的效力
- 董监高义务违反：
  - 重点关注董监高在关联方企业的任职及投资情况，核查是否履行了报告/回避程序
  - 董监高赔偿责任（忠实义务、勤勉义务、关联交易报告、竞业禁止）更明确，需评估董监高责任险必要性
  - 核查董监高是否利用职务便利从事利益输送，Pre-IPO 阶段尤需关注

### Authority 检索
关键词：决议无效 / 决议撤销 / 决议不成立 / 善意相对人 / 忠实义务 勤勉义务 / 竞业禁止 / 关联交易 回避
可能涉及：公司法（决议效力条款、董监高义务条款）/ 公司法司法解释四（决议效力条款）

## 减资与回购

### 风控问题
- 股权回购与减资退出：
  - 对赌协议回购条款设计：公司作为回购义务人需走减资程序，可能因债权人异议无法执行
  - 建议回购义务主体设定为创始股东个人，公司承担连带责任
  - 减资程序要求债权人在法定期限内有权要求清偿或担保（历史参考值：45日内，需预留充足时间）
- 异议股东回购请求权的适用情形

### Authority 检索
关键词：减资程序 债权人 / 异议股东 回购请求权 / 对赌 回购 可执行性 / 减资 异议
可能涉及：公司法（减资程序条款、异议股东回购请求权条款）/ 最高人民法院关于对赌协议的裁判规则与答疑口径

## 投资人优先权条款

### 风控问题
- 优先分红权：需在公司章程中明确约定，否则按法定比例分配
- 优先清算权：司法实践中效力存在争议，建议以"分配调节"方式设计
- 领售权（Drag-along）：中国法下效力尚不明确，需审慎设计
- 优先购买权与利润分配、解散清算的程序衔接

### Authority 检索
关键词：优先分红 / 优先清算 分配调节 / 领售权 / 清算顺序
可能涉及：公司法（优先购买权、利润分配、解散清算条款）/ 对赌与投资条款相关裁判案例

## 章程与特殊条款

### 风控问题
- 特殊表决权 / AB 股：
  - 类别股（新公司法新增制度）的章程设计
  - 特别表决权需在 IPO 前论证合理性，科创属性企业适用性更强
  - 关注日落条款（Event-based 和 Time-based sunset）
  - 每份特别表决权股份的表决权数量上限（历史参考值：不超过每份普通股的 10倍，以现行交易所规则为准）
- 投资人保护条款与章程衔接：
  - 否决权条款需确认是否写入章程或通过股东协议约定（章程对抗效力更强）
  - VIE/红筹架构下需关注章程与投资协议的效力层级

### Authority 检索
关键词：类别股 / 特别表决权 / 日落条款 / 章程效力 / 股东会职权
可能涉及：公司法（类别股、章程效力、股东会职权条款）/ 科创板上市规则（表决权差异安排章节）
