## 个人信息处理合法基础

### 风控问题
- 处理活动是否有合法基础（同意/合同必需/法定义务等法定事由），逐类业务映射 [statute]
- 同意质量：单独同意 vs 一般同意的适用情形、未成年人信息、撤回机制 [statute]
- 隐私政策完备性：是否包含处理目的、方式、范围、存储期限、用户权利等法定要素 [statute]
- 个人信息保护影响评估（PIA）机制 [statute]：
  - 触发条件：处理敏感个人信息、自动化决策、委托处理、跨境传输
  - 要求：事前评估、记录保存（历史参考值：至少 3年）
  - 核查是否建立 PIA 机制，尤其关注涉及用户画像、推荐算法的业务
- 个人信息保护负责人：处理个人信息达到规定数量的必须设置 [statute]

### Authority 检索
关键词：个人信息处理 合法基础 / 单独同意 / 隐私政策 法定要素 / 个人信息保护影响评估
可能涉及：个人信息保护法（合法基础、PIA 条款）/ 网络安全法 / 相关国家标准

## 数据出境路径（安全评估/标准合同/认证）

### 风控问题
- 出境路径选择（门槛数值为参考锚点，以现行办法为准）[statute]：
  - CIIO 或处理 100万人以上个人信息 → 安全评估（向国家网信办申报）
  - 累计出境 1万人以上敏感个人信息 → 安全评估
  - 未达安全评估门槛 → 标准合同（签署并向省级网信部门备案）
  - 通过数据保护认证的境外接收方 → 认证
- 是否涉及数据出境的事实核查：服务器位置、境外客户、境外 API 调用 [practice]
- 评估出境数据量和敏感度，确定适用路径 [practice]
- 未办理数据出境手续的，在报告中提示合规风险及整改时间表 [practice]
- 跨境模型调用：调用境外大模型 API 是否已完成数据出境手续 [statute]

### Authority 检索
关键词：数据出境 安全评估 / 标准合同 备案 / 认证 / 境外接收方
可能涉及：数据出境安全评估办法 / 个人信息出境标准合同办法 / 促进和规范数据跨境流动规定

## 敏感个人信息

### 风控问题
- 敏感个人信息识别（生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹及不满法定年龄未成年人信息）[statute]
- 敏感信息处理需取得单独同意，并具有特定目的与充分必要性 [statute]
- 健康医疗数据：属敏感个人信息，需单独同意 [statute]
- 人类遗传资源：涉及中国人类遗传资源的出境需审批 [statute]

## 算法与自动化决策

### 风控问题
- 算法备案与生成式 AI 合规 [statute+practice]：
  - 提供生成式 AI 服务前的安全评估申报、算法上线后的备案时限（历史参考值：10个工作日）
  - 核查目标公司是否已完成算法备案，未备案的评估合规风险和时间表
  - 备案主体与实际运营主体是否一致
  - 调用境外大模型 API 提供服务需额外关注数据出境合规
- 生成式 AI 服务安全要求（国家标准参考值）[practice]：
  - 训练数据安全评估
  - 生成内容安全测试（违法内容概率阈值参考值：<0.01%）
  - 抗攻击能力（Prompt 注入防御率参考值：>99.9%）
  - 以上两值为测试方案设计参考值而非监管硬性指标；正式引用阈值以《生成式人工智能服务安全基本要求》等现行国家标准/TC260 文件为准
- 备案统计背景（实践数据，用于判断监管覆盖密度）：截至 2025年底累计 748款生成式 AI 服务完成备案、435款完成登记，2025年全年新增 446款 [practice]
- 模型调用与知识产权 [practice]：
  - 基于开源模型商业化需审查模型许可证（GPL/AGPL 传染性风险）
  - 训练数据来源合法性核查（是否存在爬取未授权数据）
  - 模型输出内容的著作权归属需在用户协议中明确
- 自动化决策：透明度、公平合理、拒绝权与解释权 [statute]

### Authority 检索
关键词：算法备案 / 生成式人工智能 安全评估 / 自动化决策 / 开源模型 许可证
可能涉及：互联网信息服务算法推荐管理规定 / 生成式人工智能服务管理暂行办法 / 生成式人工智能服务安全基本要求（国家标准）

## 行业特殊数据合规

### 风控问题
- 智能驾驶 [statute]：
  - 测绘资质：高精地图采集需具备测绘资质，核查资质覆盖范围
  - 车辆数据出境：重要数据出境需安全评估，车内数据处理需脱敏
- 医疗器械/数字医疗 [statute+practice]：
  - 健康医疗数据处理（见"敏感个人信息"节）
  - 人类遗传资源出境审批
- AI/算力行业 [practice]：
  - 算力资源来源（见"数据安全等级保护"节）
  - 跨境模型调用的数据出境手续
