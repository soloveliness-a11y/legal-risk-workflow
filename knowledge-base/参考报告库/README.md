# 参考报告库（不随本仓库分发）

本仓库不附真实项目报告。真实报告、访谈与项目材料属于使用者私有数据，请保存于公共仓库之外的私有工作区，并确认使用权限。

## 使用者自建方案

1. 收集你自己经手的历史风控报告（覆盖不同阶段：天使/成长/Pre-IPO/二轮）
2. 按项目归档：`参考报告库/{项目名}-{阶段}项目/`（存放于你的私有工作区，不提交公共仓库）
3. 每个项目保留 docx 原件 + 一份 markdown「学习版」（提炼结构与写法，不复制敏感细节）
4. 案例学习笔记的 writing_patterns.md 就是从这类语料中提炼的写作规律

发行范围规则见 [docs/EXCLUSIONS.md](../../docs/EXCLUSIONS.md)。
